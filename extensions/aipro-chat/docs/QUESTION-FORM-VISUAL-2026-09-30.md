# 질문 폼과 디버그 설정 정리

사용자 결정에 따라 선택형 질문의 반복 안내를 제거했다. 직접 답변은 별도 화면 라벨 대신 입력란 안의 `또는 직접 답변` 또는 질문별 예시를 보여준다. 입력란은 흰 바탕과 한 겹 테두리로 정리하고, 접근성 이름과 오류 연결은 `CxField`로 유지한다. 따라서 이전 [폼 사용성 기록](FORM-USABILITY-2026-09-25.md)의 지속 힌트 결정은 이 폼에 한해 대체한다.

디버그 모드는 기존 CX 체크박스와 누비 아이콘, 설정 카드 토큰을 재사용해 한 영역에 묶었다. 기존 저장 값과 실행 진단 표시 범위는 유지한다. 새 폼 라이브러리나 아이콘 패키지는 도입하지 않았다. 단일 질문과 짧은 설정 항목에는 기존 컴포넌트로 충분하다.

검증: Office 공유 질문 계약 11개, Chrome 질문 흐름, 디버그 설정 저장과 재시작, Chrome 접근성 검사를 통과했다. 320px 질문 화면과 360px 설정 화면을 직접 확인했다. 브라우저 검사는 합성 모델과 격리된 프로필을 사용했으며 Office 실호스트 화면과 실계정 모델 응답은 이번 검증 범위가 아니다.
