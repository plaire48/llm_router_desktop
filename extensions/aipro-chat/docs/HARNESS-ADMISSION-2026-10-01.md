# 자동 비교 배정과 하네스 강화

2026-10-01. 사용자 요청에 따라 기존 원인 분석과 최신 공식 방법론, 실제 오픈소스 구현을 대조했다. 이번 적용은 **자동 분석에 필요한 원문이 없어졌을 때의 배정 격리와 명시적 복구**다. 별도 모델 런타임이나 패키지는 추가하지 않았다. NQ-53으로 추적한다.

## 판단 근거

[직전 H-07 비교](HARNESS-PHASE1-2026-10-01.md)에서 Luna 호출은 20→40, Sol은 21→45였다. Luna의 독립 정답 항목은 1/4→3/4, Sol은 4/4→4/4였지만 제품 전체 완료는 Luna 실패 유지, Sol 성공→미완료였다. 후보/모델별 1회이며 전체 품질 점수가 아니다. 하위 분석 수 확대보다 원문 범위, 위임 조건, 최종 검토와 호출 비용을 함께 확인해야 한다.

현재 소스에는 [NQ-51 검토 기록 보존 수정](FEATURE-REASSESSMENT-2026-10-01.md)이 이미 반영돼 있어 중복 수정하지 않았다. 이번에 발견한 원문 회수 문제는 독립적인 회귀 반례다. H-07 실패의 직접 원인이라고 단정하지 않는다.

## 재현과 변경

분석 조정기는 제한된 원문 캐시를 사용하며 진행 중이거나 미전달인 분석의 근거는 보호한다. 전달 후 오래된 근거는 회수될 수 있다. 자동 비교 스케줄러에는 그 ID가 남아 있었다.

1. 전부 회수된 page_content는 빈 evidence_ids로 요청돼 배치 전체가 거절됐다. 정상 동료 출처도 함께 실패할 수 있었다.
2. 일부만 회수되면 앞선 규칙을 조용히 빼고 새 예외만 보낸 뒤 규칙과 예외를 대조하도록 요청했다.
3. 표시용 출처도 유효성을 확인하지 않아 정상 출처와 함께 거절될 수 있었다.

수정 후 원문이 모두 남아 있는 작업만 자동 배정하며, 이 검사는 배정 슬롯을 자르기 전에 수행한다. 빠진 원문 개수와 needs_leader_review 상태 및 원문 재조회/명시적 재배정 안내를 주 실행기에 전달한다. 반복 flush로 모델 호출을 늘리지 않는다. 누락된 앞선 규칙을 생략한 채 부분 분석을 완료로 취급하지 않는다.

주 실행기는 현재 필요한 원문을 다시 읽고 유효한 ID로 명시적 위임하거나 직접 분석할 수 있다. 자동 상태는 해당 과거 스냅샷의 유실을 계속 알리며 자동 복원/작업 완료를 의미하지 않는다. captured_characters는 과거 확보량이고 현재 사용 가능한 원문량이 아니다. 사실 정확도, 현재 페이지, 승인과 쓰기 권한을 이 상태로 증명하지 않는다.

## 검증과 평가 범위

- 새 회귀 3개는 변경 전 모두 실패했다. 기존 9개와 새 3개, 실제 조정기의 60개 후속 관찰에 따른 회수/결과 전달 연결 검사 1개는 변경 후 13/13 통과했다.
- 연결 검사에서 유효 출처만 실제 Pi 실행기에 배정됐고 합성 모델 호출은 1회였다. 누락 출처 추가 호출 0회, 미완료 보고는 partial로 보존됐다.
- Chrome 회귀는 실제 긴 페이지의 원문/끝 예외/변경 해시를 읽고, 전달 뒤 회수된 규칙이 있는 후속 분석을 차단하면서 별도 유효 버전의 분석이 진행되는지 확인한다. 모델 응답은 합성이다.
- [증거 폴더](../verification/harness-admission-2026-10-01/)에 변경 전 소스, 실패/통과 로그와 후보 gate 결과를 기록한다. 최초 직접 node 실행은 npm 실행 경로 보호로 중단됐으며 제품 테스트 실패나 통과로 계산하지 않는다.
- 첫 npm gate는 단위/디자인 뒤 동시 작업에서 추가한 analysis-limits.js가 원본 ESM 배포 목록에 빠져 패키징 실패했다. 배포 목록 수정이 반영된 뒤 다시 검증했다. 그 변경은 이번 근거 회수 수정과 구분한다.
- 다음 Chrome 실행은 동시 반영된 긴 요청 fixture에서 합성 응답기가 이미 brief에 받은 evidence_reads를 무시하고 다시 읽어 예산을 소진했다. 현재 fixture는 호스트가 반환한 자료를 우선 사용하고 빠진 ID만 읽는다. 긴 요청 보존, 실제 반환 범위의 인용 검증 및 완료 조건은 유지했다. 별도 직접 Chrome 집중 검사는 통과했으며 실패 로그도 남겼다.
- 새 후보의 Luna/Sol/Qwen 품질 향상과 전체 30과제 성능은 이번 회귀로 입증하지 않는다. 배포하지 않았다.

최종 [고정 후보 검사](../verification/harness-admission-2026-10-01/frozen/extensions/aipro-chat/verification/pre-release-2026-09-30T21-41-31-785Z/report.json)는 **전체 단위 1,642개, 디자인, 후보 빌드, 선택 Chrome 11회** 모두 통과했다. comparison-continuation/analysis-delivery/review-recovery 각 3회와 research-source/analysis-retention 각 1회다. 실행 전후 입력/빌드 해시가 일치하고, 완료 시점의 현재 작업공간 입력도 같은 해시임을 [result.json](../verification/harness-admission-2026-10-01/result.json)에서 확인했다. 전체 핵심 gate나 전체 배포 매트릭스 통과를 뜻하지 않는다.

직전 비고정 gate도 Chrome 11회는 통과했으나 검사 중 다른 작업의 research-source-capture.js와 tests 변경으로 동일 후보 인증에 실패했다. 이 결과를 승격하지 않고 확장 및 관련 공유 패키지 소스를 별도 복사본에 고정해 위 검사를 완료했다. 후보 ZIP SHA-256은 `fe9eaa930f788dbc6f2faba24de5054a450b7ffe5e6d5f871f4ff53035f2413f`다. 공통 요청 길이/뒤쪽 조건 보존 NQ-54도 함께 들어간 후보이며 이번 NQ-53만의 실모델 효과로 분리할 수 없다.
