# 브라우저 기능별 품질 재평가

이후 H-07 실측과 파일/Wiki/A2A 변경을 반영한 현재 등급 및 검토 기록 보존 수정은 [최신 재평가](FEATURE-REASSESSMENT-2026-10-01.md)를 따른다. 아래 후보의 검사 수와 점수는 당시 이력이다.

2026-10-01. 상/중/하는 개선 우선순위가 아니라 현재 품질이다. 상은 **검증한 범위에서 안정적으로 동작**, 중은 기능은 있으나 실측 편차나 중요한 미검증 범위가 있음, 하는 반복 실패가 확인된 영역이다. 미측정은 실패로 합산하지 않는다. 제품 전체를 하나의 점수로 환산하지 않는다.

## 이번 적용: 하위 담당의 실제 읽기 범위 전달

원인: `analysis-agents.js`는 실제 조회 범위를 내부 `readRanges`와 주 실행기 인계에 보존했지만 최종 검토의 `analysis_execution`에는 호출/읽기 횟수만 실었다. 원문의 어느 부분이 하위 담당에게 반환됐는지 검토자가 알 수 없었다. 하위 분석의 offset은 직렬화된 도구 JSON 기준이고 원문 문자의 offset과 달라 그대로 합칠 수도 없다.

변경:

1. 호스트가 보관한 실제 읽기 원장에서 `source_reads`를 생성해 단계/최종 검토에 전달한다. 모델의 보고서나 인용 offset은 사용하지 않는다.
2. 유효한 `page_content`는 JSON의 구조 경로를 따라 반환된 텍스트를 URL/프레임/문서 해시와 원문 UTF-16 구간에 연결한다. 따옴표, 줄바꿈, 역슬래시, 이모지와 경계에 걸린 이스케이프를 처리한다. 같은 문자열이 인자나 다른 범위에 있어도 텍스트 검색으로 연결하지 않는다.
3. 실패/잘림/불일치 자료는 원문 구간 증거로 승격하지 않는다. 자료 8개, 범위 16개와 6,000자 한도를 넘으면 생략 수를 명시한다. 읽기 본문이나 보고서 내용을 새 기록에 복제하지 않는다.
4. 검토 안내는 기록이 있을 때만 추가한다. 저장된 관찰을 전부 반환했다는 상태와 전체 페이지/의미적 이해를 분리한다. 사실 정확도, 실제 변경, 승인에는 기존 독립 근거가 필요하다.

이 기록은 현재 실행 메모리의 역사적 반환 범위다. 모델이 내용을 이해했거나 최종 답변이 정확하다는 증거가 아니다. 과거 실행의 권한 복원, 탭 탐색 권한 확대, 하위 담당의 쓰기, 추가 모델 호출을 만들지 않는다. 여러 기관 조사 등급을 이 수정만으로 올리지 않는다.

## 방법론과 선택 근거

[Anthropic 평가 방법론](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)의 실행 기록과 최종 환경 결과 구분을 재확인했다. 이전 기록의 문맥 격리와 읽기 범위 추적 설계를 재사용하고, 모델 자기보고보다 호스트의 실제 반환 기록으로 검증한다.

기존 Pi 0.87.1, p-limit 7.3.3(MIT) 실행/병렬 제한과 Playwright 1.62.1(Apache-2.0) Chrome 검증을 유지한다. 외부 관측 SDK나 별도 에이전트 프레임워크는 채택하지 않았다. 이번 결함은 기존 읽기 증거의 전달 누락이고 새 런타임/외부 전송/추론 비용을 추가할 이점이 없다. `RESEARCH-WORKERS-2026-09-30.md`의 독립 조사 탭 설계는 이 수정과 별개로 권한/로그인/정리/소스 검증이 필요한 후속 구현이다.

## 전후 검증

- 수정 전: 실제 coordinator에서 새 회귀 4개 모두 `source_reads` 부재로 실패했다. [로그](../verification/feature-quality-2026-10-01/before.log).
- 수정 후: 원문 범위, 이스케이프, 잘림/실패 거부, 메타데이터만 읽기, 중복 문자열, 출력 상한과 사본 격리, 단계/최종 검토 전달을 검사한다.
- 실제 Chrome에서는 본문을 읽은 두 하위 담당의 기록이 최종 검토까지 같은 URL/해시/원문 범위로 전달되는지 확인한다. 실제 값 입력 1회와 제출 0회도 함께 확인한다. 모델 응답은 고정 fixture이며 실모델 성능 검사가 아니다.
- 최종 후보 검증 결과는 아래에 기록한다. 실패/중단한 gate도 삭제하지 않는다.

최종 결과: [동일 후보 보고서](../verification/pre-release-2026-09-30T18-19-59-230Z/report.json)에서 단위 **1,606개**, 디자인 검사, 후보 빌드, Chrome **19회**(6종 3회 반복과 보존 검사 1회), 총 22단계가 통과했다. 이번 원문 반환 범위 회귀는 6개다. 최종 후보 SHA-256은 `bfdc1cb4c82121e41b9e8e7a998a6100ece30eed315a22db2dc60942363acfcd`이며 [변경 파일 해시와 요약](../verification/feature-quality-2026-10-01/result.json)에 고정했다. 전체 배포 매트릭스, 이번 후보의 Luna/Sol 실측, Qwen 실계정 성공은 아니다. 배포/업로드하지 않았다.

초기 개선 검사는 주 실행기 인계에도 새 메타데이터를 중복 추가해 기존 1,500자 인계 상한 회귀가 실패했다. 이 중복을 제거하고 기존 인계 크기를 유지한 채 필요한 검토 경로에만 연결했다. 검토 지침 역시 해당 기록이 있을 때만 포함해 기존 문맥 예산을 유지했다. 전체 후보에는 공유 작업 폴더의 기존 변경도 포함되며, 이번 직접 변경은 위 요약의 다섯 코드/검사 파일과 관련 문서다.

## 남은 개선 순서

1. H-04: 기관별 요구 항목과 실제 원문 확보를 분리해 누락을 보충하고 통합 답변까지 완료. 독립 탐색 워커는 위 설계의 안전 경계를 검증한 뒤 채택 판단.
