# AI Pro 브라우저 에이전트 BP

조사일: 2026-09-21. 기본 엔진은 **Pi agent core**, 기본 모델은 **GLM-5.2-NVFP4**로 정한다. QWEN3.8-27B-FP8-256K를 포함한 AI Pro 모델 선택은 유지한다. 범용 작업 수행과 브라우저 적합성, 확장만 설치하는 조건을 함께 고려한 선택이다. 사내 모델로 하네스별 우열을 측정한 결과는 아니다.

OpenCode는 범용 개발 작업에 유용하지만 이 제품에서는 별도 실행 프로세스가 필요하다. Browser Use는 GLM의 브라우저 작업 성능을 비교할 기준으로 남긴다. **Pi의 공통 엔진을 재사용하고 현재 브라우저 도구를 연결하는 구성이 제품 조건에 가장 맞는다**는 것이 이번 판단이다. 스타 수를 만족도나 성능 점수로 환산하지 않는다.

## 0.6.0 적용 범위

- `@earendil-works/pi-agent-core`와 `@earendil-works/pi-ai` 0.86.1을 고정했다. Pi의 Agent가 대화 상태, 순차 도구 실행과 후속 턴을 관리한다.
- AI Pro의 SSO, 모델 목록, Bearer 인증과 SSE 파서는 기존 계약을 유지한다. Pi의 외부 LLM 서비스나 OAuth로 보내지 않는다.
- 브라우저 관찰과 입력은 확장 도구가 수행한다. 실패 결과를 모델에 돌려주며 잘못된 인자, 오래된 문서와 사용자 취소를 구분한다.
- 입력 후 검증, 반복 중단, 실행 예산과 이전 관찰 축약은 확장의 실행 정책으로 유지한다. 같은 응답 안의 여러 입력도 순차 처리하고 첫 입력을 취소하면 후속 입력을 막는다.
- 작업 기록에는 도구명과 상태만 남긴다. 실제 토큰 표시는 AI Pro 응답의 usage를 사용한다.
- CX 화면과 아이콘, 공유 스킬 형식은 유지한다. 엔진 선택 화면이나 추가 설정을 만들지 않는다.

Pi CLI의 전체 기능, Browser Use의 CDP 실행기, MCP, 임의 스크립트 실행을 포함한 것은 아니다. 이미지 입력 지원과 사내 사이트별 결과는 아직 확인하지 않았다. 창을 닫은 뒤의 자동 실행 재개도 이번 교체 범위에 포함하지 않는다.

## 품질 판단 기준

브라우저 작업 60%, 일반 도구 작업 25%, 지연과 토큰 효율 15%를 내부 평가 비중으로 제안한다. 이는 공개 벤치마크 점수가 아닌 제품 평가 기준이다.

실제 AI Pro 비교에서는 기존 0.5.0과 Pi 통합판을 같은 모델, 프롬프트, 도구, 시간과 토큰 예산으로 실행한다. GLM과 Qwen 각각 아래 10개 작업을 3회 반복한다. 배포 모델 ID와 실행기 버전을 함께 기록한다.

1. 라벨이 다른 폼에서 지정한 입력란 찾기
2. 선택지의 표시 이름과 실제 값을 구분해 입력
3. 사이트 업무 저장소의 값을 읽어 입력
4. 동적 변경 뒤 다시 관찰하고 입력
5. 읽기와 입력을 포함하는 여러 단계 처리
6. 잘못된 도구 인자를 결과에 맞춰 수정
7. 일시적인 도구 오류 뒤 재관찰
8. 사용자 취소 후 다른 인자로 재입력하지 않기
9. 긴 자료에서 요구된 항목만 추출
10. 도구 결과를 근거로 요약과 문서 작성

성공은 모델의 완료 문장이 아니라 기대한 DOM 값과 작업 결과로 판정한다. 서버 저장을 포함하는 작업은 저장 후 재조회 결과까지 확인한다. 실행 횟수, 오류 복구, 중복 동작, 소요 시간과 토큰을 별도로 남긴다. 합성 응답 테스트는 호환성과 회귀 확인이며 이 실모델 비교를 대체하지 않는다.

## 이번 검증

0.6.0은 단위 테스트 77개, 실제 Chrome에서 합성 AI Pro 응답을 사용한 페이지 작업 14개, 채팅 5개, native side panel 5개, 접근성 3개를 통과했다. 배포 manifest의 사이트 권한과 CSP를 그대로 사용했다. 디자인 검사와 배포 빌드도 통과했다. 회사망 로그인과 실제 GLM/Qwen 품질 비교는 이번에 수행하지 않았다.
