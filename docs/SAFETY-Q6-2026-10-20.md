## 비용, 인계와 남은 위험

새31시험 가운데30개가 새 파일5개,1개가 기존 workflow 고정 시험이다. 새 파일30시험은3.284초. 기존 파일의 추가1시험은workflow집중에서 확인했다.5파일의 집중 wall과 전체 집중 wall은 `q6-new-tests-final.log`, `q6-regression-final.log`에 남긴다. 실제 Office/PowerShell/COM/네이티브 프로세스 실행을 추가하지 않았다. 기존 안전107시험의 재사용은 fast ui에 약11.110초였고, 다음 CI의 추가 후 unit/ui 시간은 미측정이다. 기준17차 unit16:19/ui6:50,18차 unit16:12/ui8:07이며 로컬 시간을 CI 증가분으로 추정하지 않는다.

Q3 v2는 별도 frozen9파일 명세 `.superpowers/sdd/2026-10-20-release-acceptance/q3-v2-upload-inputs.json`의 실제 업로더 후보e37cd29a exit0이다. 현재 workflow/계획/AGENTS에는 Q6 후속이 있으므로 Q3만 올릴 때 현재 파일 대신 frozen 바이트를 사용한다. Q6 전체36파일/SHA는 같은 폴더의 `q6-upload-inputs.json`에 있고 아직 푸시하지 않았다. Q3 frozen 입력과 합친41파일은 실제 Claude 업로더를 RELEASE_INPUTS_GATE=1, --push 없이 실행해 exit0을 확인했다. 업로더 기본값/원격 브랜치는 바꾸지 않았다. 캡처는 `packages/nubi-desktop/verification/safety-q6/result-1280.png`, `result-440.png`이며 검사 보고서 화면이지 제품 UI/Windows 성공 증거가 아니다.

최초122통과/5형식 발견, 전체 소스84발견, 실제 payload579발견을 보존했고 이후 검토를 소급해 최초 무발견으로 바꾸지 않는다. 원본 archives와 lock/checksums를 검증했으며 현재 원격에서 다시 다운로드했다고 표시하지 않는다. 실제 Windows payload는 이 Mac 검증과 다르며 새로운/다른 해시 발견은 Windows gates-full에서 차단된다. Windows 설치/재실행/Office/NASCA/연결 모델/SSO는 미검증이다. 패턴 검사는 모든 알려지지 않은 비밀의 부재나 화면 픽셀 OCR을 증명하지 않는다. 로그인 캡처 생략은 계획대로 L2 뒤 추가한다. OSS 후보는 기존 Q6 사전 표대로 패턴 참고만이고 새 의존성0이다.
