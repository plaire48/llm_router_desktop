**로컬 구현과 집중 검증 완료. 업로드와 Actions 판정은 Claude.** 설계 §8 답12/14/16을 적용했다. CI13차39387314601(main63784e52)는14분54초로 첫 녹색이며 Q2 연속 녹색1/3회다. 시간 미판정16건(메일2/모션12/대화2)은 기능 통과와 구분한다. 다음 녹색은 W3 업로드 실행으로 이어 센다([CI 이력](CI-GATES.md)). W0 수용과 과거 실패 기록은 보존했다.

## 결과와 결정

위키 요청만 purpose/provider/model/connectionId/effort auto/도구8또는16호출을 사용한다. 인증과 카탈로그는 기존 호스트가 소유하고 임시 요청 세션으로 다른 대화의 선택을 보존한다. 검증된 호스트 우선순위가 없으면 현재 모델을 명시한다. 동시성1~4 기본3, 지원 제공자 페이지 상한 기본16,384를 실제 모델/서버 한도로 제한한다. ChatGPT Codex 전송은 응답 상한을 전송하지 않으므로 실제 적용값null과 ‘서버 기본’, 비활성 조절기를 사용한다. 저장한 희망값은 다른 제공자로 돌아오면 복원한다. SDK/인증을 바꾸거나 미확인 전송 필드를 넣지 않았다.

사용자 요청대로 기존 `ModelSelection`의 제공자 탭과 검색/키보드 선택을 위키 설정의 같은 모달 안에서 재사용했다. 기존 `ModelPicker`와 `ModelSelection`의 아이콘과 카탈로그 모델명을 그대로 쓰고, 위키 전용 아이콘/이름 장식을 제거했다. 새 선택 모달을 겹치지 않는다. AI Pro, ChatGPT, FabriX, Claude 네 탭을 항상 표시한다. 선택 중 위키 작업 카드는 숨기고 돌아오면 설정 초안과 초점을 보존한다. 형제 컴포넌트의 중복 React 키를 고유하게 수정하고 반복 선택 뒤 카드 한 개를 단언한다. 공통 컴포넌트의 새 선택 속성은 기본 동작을 바꾸지 않는다. 새 의존성0. 네 탭 복원 중 실제 Desktop 래퍼의 Claude 카탈로그 누락과 대화 제공자로 위키 요청이 잘못 전달되는 경로를 실패 시험5개로 재현해 수정했다. 요청의 provider/model/effort를 고정하고 대화 선택은 보존한다. Claude는 기존 CLI에 출력 상한 설정이 없어 서버 기본을 표시하며 안전 모드/도구 비활성/기존 일반 요청은 유지한다.
