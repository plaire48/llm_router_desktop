# 누비 IDE 워크스페이스 화면 시안

2026-09-23. HTML/CSS/JavaScript로 만든 설계 검토용 인터랙티브 시안이다. **실제 IDE, 모델, OpenWiki, 파일 쓰기, 서버 실행에는 연결되어 있지 않다.** 예시 파일과 검증 상태를 현재 저장소의 실행 결과로 해석하지 않는다.

- 개발 / 검토 레이아웃을 전환한다.
- 요구사항 / 연결 지도 / 코드 / 미리보기 / 비교 탭을 조작한다.
- 근거 상세, 문맥 설명, 하위 분석, 실행 기록을 펼친다.
- 전후 화면의 병렬/겹침과 서버 실패·기준 변경 상태를 확인한다.
- 키보드 탭 이동, 상세 Escape 닫기, 초점 복귀를 지원한다.

기존 누비 로고, CX 0.5.4 토큰/로컬 Noto Sans KR, `agent-deck.css`를 사용한다. React 컴포넌트를 실제 IDE에 이식한 결과는 아니다. 시안에 새 오픈소스 IDE 라이브러리를 설치하지 않았다. 자산은 로컬 원본에서 복사했으며 폰트는 사용한 문자의 subset과 OFL 고지를 포함한다.

[기반 선택과 근거](../../research/2026-09-23-nubi-ide-foundation.md), [실행·화면 명세](../../superpowers/specs/2026-09-23-nubi-desktop-workspace.md), [개발 전달서](../../plans/2026-09-23-nubi-desktop-implementation.md).

로컬 HTML을 열거나 이 디렉터리만 정적 HTTP로 제공할 수 있다. 앱 서버가 아니다. 실제 Windows 동작과 실모델 품질은 별도 구현/검증 대상이다.

검증: macOS Chrome에서 29개 상호작용·표시 확인을 통과했다. 탭/키보드, dialog 초점 복귀, 전후 겹침 복귀, 실패/오래된 기준, shell 선택 예시, 1280/1024/760/390px 가로 넘침과 좁은 화면 대화 전환을 포함한다. 브라우저 오류는 없었다. [검증 기록](verification.json), [개발 화면](preview-development.png), [비교 화면](preview-comparison.png).

CX 정적 검사 원본 exit code는 1이다. 새로 작성한 화면 파일의 지적은 0개이며, 복사한 공통 토큰/폰트 정의의 리터럴 718건이 검사기에 잡혔다. 전체 검사 통과로 표현하지 않는다. 제품 코드/기존 패키지/Windows 설치 빌드는 수행하지 않았다.
