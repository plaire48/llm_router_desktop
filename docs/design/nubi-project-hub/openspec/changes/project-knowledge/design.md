## Context

이 예제의 제품은 아직 구현되지 않았다. 실제 재사용 후보는 OpenWiki의 페이지 수명주기/Claims와 누비의 호스트별 Pi 실행기다.

## Goals / Non-Goals

목표는 문서 수정 보존, 소스 최신성 표시, 범위가 명확한 작업 전달이다. 첫 단계에서 여러 Agent framework, 조직 포털, 실시간 공동 편집 엔진을 추가하지 않는다.

## Decisions

Git의 3-way merge를 문서 변경안 계산에 사용하고 결과에 Claims 검사를 다시 수행한다. 명세/사람 지식과 생성 Wiki의 소유권을 구분한다. 로컬 실행 기록은 Git 문서와 분리한다. 호스트 adapter가 각 앱의 실행권한을 검증한다.

## Risks / Trade-offs

텍스트 병합 성공은 의미 일치를 보장하지 않는다. 오래된 소스, IDE 미저장 버퍼, 응답 유실과 재시작 상태를 별도로 검사한다. 기존 Office 메모리 상태만으로 영속 복구를 약속하지 않는다.

## Migration Plan

기존 프로젝트 문서 경로를 우선 매핑하고 읽기 연결부터 추가한다. 사용자 파일 이동과 실행용 지침 변경은 자동화하지 않는다.

## Open Questions

Windows 실호스트와 실제 모델에서 갱신 품질·전달 복구·문서 저장 결과 검증이 필요하다.
