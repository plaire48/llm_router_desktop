# PPT 우선 자동 검토와 수정 계약

사용자 승인: PPT 완성도와 Word/Excel/PPT 공통의 작성 후 자동 검토/수정 흐름을 가장 높은 우선순위로 구현한다. 기존 생성/파일/호스트 모델을 재사용하고 새 모델/인증/승인/저장 실행기를 만들지 않는다.

1. 새 평문 후보의 실제 바이트와 계획 해시를 호스트 검토 영수증에 고정한다.
2. 구조/사실/원천 및 비대상 보존/전체 렌더/배치/시각을 확인하고 Excel은 실제 계산도 요구한다.
3. PPT는 실제 PNG를 모델의 이미지 입력으로 전달한다. 실제 PDF 글리프와 개체 경계를 비교한다. 추정 텍스트 맞춤은 힌트로만 쓴다.
4. 모델은 실제 근거가 있는 계획 경로 안에서 최소 패치를 제안한다. 기존 reviseComposition과 생성기를 사용해 후보를 새로 만든다.
5. 새 후보를 전부 재검토한다. 과거 검토, 빠진 검토, 남은 주요 오류를 완료로 처리하지 않는다. 통과 검사 악화 시 이전 후보를 보존하고 종료한다.
6. 수정은 기본 2회, 최대 3회다. 같은 계획과 취소 후 늦은 응답으로 수정 성공을 만들지 않는다.
7. 호스트가 승인/최종 저장/영구 복구를 소유한다. 회사 암호화 파일은 열린 Office native 경계를 유지한다.
8. 평가에는 과거 실제 실패 PPT와 새로운 복합 업무를 넣는다. 최초/수정 성적과 검사기 오류를 보존한다. 공식 CLI의 실제 실행과 소스/계약 검사는 별도다.
