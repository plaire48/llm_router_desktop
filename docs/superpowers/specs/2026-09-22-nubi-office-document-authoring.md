# 누비 Office: 요구사항에서 완성된 문서 작성

2026-09-22 사용자 정정: “내가 원하는건 요구사항에 대해서 문서를 처음부터 끝까지 만들어내는거야.”

## 목적과 완료 조건

기본 단위는 **문서 전체**다. 사용자가 요구사항을 말하면 누비가 필요한 구성과 양식을 정하고, 본문·표·값·수식을 작성하고, 모든 요구사항과 실제 결과를 비교하여 보완한 뒤 사용할 수 있는 Excel 파일을 전달한다. 선택 셀 수정, 빈 양식, 작업 계획, API 성공만으로 완료되지 않는다. 기존 셀 도구는 이 목적의 부분 기능이다.

사용자는 셀 주소를 설계하지 않는다. 업무 정보의 부족과 편집 권한 승인을 구분한다. 인원·단가·기간처럼 꼭 필요한 사실이 없으면 질문하고, 문서의 일반적인 구조·제목·스타일은 에이전트가 결정한다. 빈 입력 양식 자체를 요청한 경우와 채워진 업무 결과물을 요청한 경우를 구분한다. 가짜 실적·출처·회사 정보를 만들지 않는다.

## 0.7.0 실행 경로

`문서 작성`이 기본 모드다. 기존 셀 모드와 분리한 document-agent가 원래 요구사항을 보존하고, 요구사항별 시트 연결을 검사한다. 계획 표시 확인 후에 누비 Pi가 시트별 문서 명세를 작성한다. 공통 제공자 연결과 원래 모델 ID를 그대로 사용한다.

선언형 명세는 셀 값/자료형, 허용 수식, 직접 서식, 병합 제목, 테두리, 행열 크기, 인쇄 영역을 표현한다. 원본 업무 데이터와 작성 내용은 코드로 실행하지 않는다. ExcelJS는 새 XLSX를 만들고 다시 읽어 직렬화 결과를 검사한다. 계산을 수행한 것처럼 표시하지 않는다.

DocumentPort는 worker가 전용 초안 폴더에 생성한 파일명·해시를 검사하고 Excel에서 연다. 매크로·외부 연결 패키지를 거부하며 기존 사용자 문서를 편집 대상으로 삼지 않는다. 생성 문서만 식별자로 관리한다. 지역 폰트에 따른 크기 해석은 실제 Excel의 행열 크기/인쇄 설정으로 맞춘 뒤 관찰한다. 여러 시트 계산, 수식 오류/순환 참조, 값, 서식과 레이아웃을 확인한다.

완료 여부는 두 단계로 판단한다. 실행기는 명세와 실제 값/수식/서식/계산 상태를 대조한다. 독립 AI 검토는 원래 사용자 요구사항 전체와 실제 문서 관찰값을 대조하며, 모델이 빠뜨린 요구사항도 찾도록 한다. 두 조건을 통과해야 파일을 저장한다. 저장 상태와 경로/파일 해시를 확인한 후에만 완료 카드를 표시한다. 독립 AI 검토도 정확도를 보장하는 장치는 아니므로 실모델 평가가 필요하다.

명세 오류는 Pi에 전달해 수정한다. 전체 검토 불충족은 해당 시트를 최대 두 차례 다시 작성·생성·관찰한다. 직접 변경된 초안은 충돌로 중단하고 덮어쓰거나 닫지 않는다. 열기/저장이 부분 또는 미확정이면 자동 재실행하지 않는다. 저장된 파일은 고유 이름을 사용한다.

## 검증과 남은 범위

생산 파일 생성기로 2개 시트와 연결 수식, 본문, 표, 스타일을 실제 XLSX로 생성했다. LibreOffice의 별도 계산 결과와 재열기, 한국어 PDF 출력을 확인한다. LibreOffice의 레이아웃 변환 차이는 기록하고 원본 양식과 계산 결과 캐시를 분리한다. 이 검사는 지정 명세 기준이며 실모델이나 Windows Excel 2016 검증이 아니다.

Windows Excel 연결과 실모델 인증은 현재 제공되지 않았다. 실제 Windows 설치/COM, 실모델 요구사항 누락률·계산 정확도·서식 품질, 사용자 직접 수정 반영 및 재시작 후 재개가 남아 있다. 기존 회사 양식 파일 가져오기/카탈로그 설계도 계속 필요하다. 0.7.0은 최대 8개 시트와 시트별 1,000셀의 새 문서 작성이며 Word/PPT·차트·피벗·매크로까지 완성했다고 표시하지 않는다.

기존 기업 양식 설계는 `2026-09-22-nubi-office-template-workflows.md`를 따른다. 이것은 문서 전체 작성에 입력 원본과 회사별 규칙을 제공할 확장이며, 문서 전체 작성 목표를 선택 셀 편집으로 축소하는 이유가 아니다.


## 0.8.0 실행 계약 갱신

Qwen 3.8 27B 기준, 자동 오류 수정/재호출, 분할 작성, HITL 및 질문 폼은 [현재 실행 계약](../../../packages/nubi-office/docs/HARNESS-BP.md)을 따른다. 이전의 전체 실행 시간·전체 호출 수·세 차례 보완 제한은 0.8.0에서 제거했다. 재시작 복구와 실모델 품질 검증은 별도다.
