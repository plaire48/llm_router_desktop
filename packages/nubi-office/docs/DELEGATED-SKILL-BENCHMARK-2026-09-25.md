# Office 하위 작업의 스킬 문맥 비교와 개선

2026-09-25. 기준은 Windows Office 2016과 선택한 Qwen 3.8 27B다. Microsoft Copilot 제품 설명과 공개 에이전트 소스는 구분한다. Copilot 본체의 비공개 소스를 내려받거나 분석했다고 주장하지 않는다.

## 발견한 결함과 반영

주 에이전트는 활성 작성 스킬을 알고 있었지만 하위 분석에는 요청, 계획, 이번 실행의 답변만 전달했다. 계획에서 스킬 조건을 빠뜨리면 하위 작업도 그 조건을 놓칠 수 있었다. 또한 같은 요청/계획에서 활성 스킬만 바뀌면 이전 분석을 재사용했다.

- 기존 Excel 범위 분석, 새 Excel 초안 전문 작업, Word/PPT 분석 및 역할별 작업에 활성 스킬 원문을 전달한다.
- 이름, ID, 버전, 지침 SHA-256, 패키지 해시와 이전의 명시적 답변을 구분한다. 이전 답변은 현재 사실이 아니며 현재 수정과 근거가 우선한다.
- 스킬 추가/제거, 버전/내용/답변 변경이 캐시와 진행 중 결과의 수용 기준에 반영된다. 버전만 같다고 같은 내용으로 간주하지 않는다.
- 스킬은 작성/검토 조건이며 업무 사실, native 권한, 저장 승인으로 사용할 수 없다. 하위 작업에는 도구나 인증을 주지 않는다. 필요한 질문은 부모가 기존 HITL로 처리한다.
- 최대 4개 활성 스킬의 원문을 자르지 않고 전달한다. 스킬 묶음 80,000자와 부모 문맥 96,000자 한도를 넘으면 위임을 거절한다. 보존된 분석은 폐기하되 부모 문맥 재구성은 계속할 수 있다. 모델에는 범위를 줄이거나 같은 규칙을 유지한 부모 도구로 진행하도록 안내한다. 문자 한도는 Qwen 토큰 한도 측정이 아니다.

기존 Pi, p-map, dependency-graph를 재사용했다. 새 프레임워크/패키지보다 기존 공통 분석 조정기의 조건 전달과 결과 수용을 보강하는 편이 Windows 배포 의존성과 유지보수 부담이 작다.

## 전후 검증

변경 전에 새 회귀 4개가 모두 실패했다. 규칙 누락, 변경 후 잘못된 재사용, 진행 중 이전 규칙의 결과 수용, 잘못된 스킬 문맥 허용을 각각 재현했다. 변경 후에는 동일 검사와 내용/과거 답변 변경 및 예산 초과 검사를 통과했다. 실제 Pi 루프를 호출하는 합성 제공자로 Excel 셀/신규 XLSX/Word/PPT 경로를 확인했다.

검사 수와 현재 파일 해시는 [검증 기록](../verification/delegated-skill-quality.json)을 따른다. 이는 계약 회귀이며 타사와의 모델 성능 순위나 실제 문서 정확도 점수가 아니다.

| 항목 | 현재 상태 | 다음 검증/개발 |
| --- | --- | --- |
| Office 2016 실작업 | 로컬 계약과 합성 호스트 검사 | Windows 11 설치 후 Excel/Word/PPT에서 실제 반영, 저장, 재열기 |
| 실제 Qwen 판단 품질 | 실계정 호출 미검증 | 동일 과제/정답의 반복 실행으로 요구 충족, 질문 필요성, 수식/양식 보존 평가 |
| 미지원 문서 편집 | 일부 차트/표/피벗 및 Word/PPT 요소 조작 제한 | native 기능별 작은 구현과 readback, 승인, 복구 검사 |
| 초대형 native 읽기 | worker의 구간 조회는 있으나 native lazy paging 미완료 | COM에서 큰 원문 전체 로드 없이 페이지별 회수 |
| 재시작 복구 | 실행 내 문맥과 재사용 중심 | 보호된 상태 저장과 실제 문서/영수증 대조 후 재개 |
| 하위 작업의 참고 파일 | 활성 SKILL.md는 전달, 부속 파일은 자동 복제하지 않음 | 부모가 필요한 자료를 조회해 지정된 근거로 제공하는 범위 확대 |
| 화면과 NASCA | 캡처/COM 경로는 구현, 실환경 미검증 | 원본 암호화 보존과 실제 표시/저장 확인 |

공유 질문 컴포넌트의 검토 기준 변경도 발견했다. 현재 소스를 검토하고 입력란 확장 뒤 포커스/초안 보존 검사와 정적 화면 검토를 완료했다. 전체 694개 회귀, 공통 UI 24개와 정적 화면 114개가 통과했다. 색 대비 일부는 자동 확인하지 못했다. installer/native 빌드나 릴리즈는 이번 변경 범위에 포함하지 않는다.
