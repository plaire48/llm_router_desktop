누비 for Excel

Windows Excel 2016에서 사용하는 별도 추가 기능입니다. Microsoft Copilot 제품은 아닙니다.

  1. 연결 서버를 실행한 상태로 Excel의 내 추가 기능에서 AI Pro를 엽니다.
  2. 브라우저 로그인 또는 AI Pro CLI 연결 정보를 입력합니다.
  3. 결과를 넣을 빈 셀을 포함해 하나의 연속 범위를 선택합니다.
  4. 분석만 또는 셀 수정을 선택하고 요청합니다.

한 번에 최대 1,000셀을 처리합니다. 셀 값, 같은 시트의 수식, 굵게, 배경색, 숫자 표시 형식을 지원합니다. 셀 수정은 바로 적용되므로 중요한 통합 문서는 복사본에서 시작하세요.

선택한 셀 내용은 연결한 AI Pro로 전송됩니다. 인증값은 연결 서버의 메모리에만 보관하며 서버 종료 시 제거됩니다. 대화는 화면을 닫으면 사라집니다.

오류가 나면 화면의 상태 메시지를 확인하세요. ‘일부 변경’ 메시지는 Excel에 변경이 남았을 수 있다는 뜻입니다. 셀을 먼저 확인한 뒤 필요한 부분만 다시 요청하세요.

실제 Office 2016, 회사 SSO, AI Pro 호출은 사용자 환경에서 추가 확인이 필요한 테스트판입니다.
