# 기억 관리와 대화 참조 — 2026-10-24

설정의 **기억**에서 저장된 내용을 검색하고 범위를 고른 뒤 10개씩 페이지를 이동한다. 페이지를 바꾸면 목록의 처음으로 돌아온다. 각 행의 연필은 내용 수정, 휴지통은 확인 후 삭제, `+`는 현재 대화의 초안에 연결한다. 입력창의 `+ → 기억 참조`로도 같은 목록을 연다. 자동 기억을 끈 공간에서도 사람이 명시적으로 선택한 기억은 참조할 수 있다. 선택만으로 메시지를 보내지 않는다.

## 오픈소스 참고 범위

기존 구현은 Mem0의 과거 ADD/UPDATE/DELETE 방식을 호스트 모델과 로컬 SQLite에 적용한 것이다. Mem0 SDK, 클라우드 서비스나 벡터 검색을 탑재한 구현이 아니다. 이번 변경도 기존 제공자 인증과 모델 전송, 프로젝트 저장소를 재사용한다.

2026-10-24에 확인한 공식 원본은 [mem0ai/mem0, 2c81af3](https://github.com/mem0ai/mem0/tree/2c81af3bbe27d9bccb09c772d583df9e9be72ee5)이다. 대조한 파일은 `mem0-ts/src/oss/src/memory/index.ts`, `mem0-ts/src/oss/src/storage/SQLiteManager.ts`와 Apache-2.0 라이선스다. 원본은 조사 자료로만 보관했고 제품 코드에 원문을 복사하거나 SDK 의존성을 추가하지 않았다.

현재 원본의 추출은 ADD 중심이며 역할 귀속을 구분하고 기존 UUID를 제한된 후보 ID로 매핑한다. 명시적 수정/삭제/범위 조회와 변경 이력도 제공한다. 이 원칙을 참고해 누비의 범위 조회, 명시적 관리와 후보 ID 검증, 변경 버전과 되돌리기를 보완했다. 누비의 기존 자동 UPDATE/DELETE는 관찰한 후보에 한해 유지한다. 검색 순위는 로컬 단어 겹침과 기존 사용자 범위 가중치이므로 임베딩 기반 의미 검색이나 Mem0 전체 품질과 같다고 표시하지 않는다.

## 저장과 수정 계약

- 이 PC의 기존 SQLite를 사용한다. 프로젝트 기억과 모든 프로젝트에서 공유하는 내 기억을 구분하며 범위당 200개, 내용당 300자를 유지한다. 프로젝트를 열기 전에도 내 기억을 조회할 수 있다.
- 답변 뒤 별도 호출에는 사용자의 요청 최대 6,000자와 관찰한 기존 후보 최대 60개만 보낸다. 답변 본문과 내부 `contextOnly` 메시지는 추출 자료에서 제외한다. 실제 사용자의 말인지에 대한 의미 판단은 모델에 남아 있다.
- 요청과 모델의 원문에 비밀번호/키 패턴 검사를 먼저 적용하고 그 뒤 길이를 제한한다. 이는 패턴 필터이며 모든 형태의 민감정보를 판별한다는 보장이 아니다. 자동 기억 사용 스위치는 현재 공간의 자동 저장과 자동 조회를 함께 제어한다.
- 수정과 삭제, 참조 선택에는 ID, 범위, 내용과 revision으로 계산한 해시를 대조한다. 늦게 열린 편집창은 최신 기억을 덮어쓰지 않고 입력을 보존한다. 기존 revision 없는 행도 수정할 수 있다.
- 자동 추출은 관찰한 후보 ID만 수정/삭제한다. 추출 중 직접 수정하거나 기억 사용을 끄면 그 추출 결과를 저장하지 않는다. 제공자/모델/연결, 프로젝트 세대가 바뀌거나 작업 중지/취소/종료가 발생해도 늦은 결과를 버린다.
- 백그라운드 저장 완료는 최신 task의 `memoryNotes`만 갱신한다. 예전 task 사본으로 새 대화, 상태나 메시지를 덮어쓰지 않는다. 실패가 기존 답변을 실패로 바꾸지 않는다.
- 최근 20회 변경의 되돌리기는 추가/수정/삭제와 용량 제한으로 밀려난 행을 함께 복구한다. 하나라도 이후에 바뀌면 아무 행도 되돌리지 않는다. 과거 형식의 저장 기록도 직접 수정한 내용은 지우지 않는다.

## 참조 계약

한 요청에 최대 10개를 선택한다. 서버가 현재 범위에서 원본을 다시 찾아 정규화하며 렌더러가 보낸 내용은 신뢰하지 않는다. 작업 생성, 대기열 등록, 시작과 중간 입력 소비에서 다시 대조한다. 바뀌거나 삭제된 참조는 전송을 거절하고 초안과 선택을 유지한다. 최신 기억을 다시 선택하면 같은 ID의 오래된 초안을 교체한다. 대기열 편집에서도 참조를 보존한다.

모델에 제공한 자동/명시적 기억은 답변 아래의 참고한 기억으로 표시한다. 클릭하면 대화에 연결한 시점의 내용, 범위와 시각을 본다. 이것은 **모델 문맥에 전달한 자료**이지, 답변의 모든 주장이 그 자료로 입증됐다는 인용 검증 결과가 아니다. 현재 요청과 실제 자료가 우선하며 기억은 승인이나 실행 권한이 아니다.

삭제한 행은 이후 조회와 새 참조에서 제외한다. 이미 대화에 보관된 참조 사본과 최근 되돌리기 기록을 대화 이력에서 일괄 삭제하는 기능은 아니다. 자동 추출로 저장될 사실의 정확성과 범용 업무 품질도 이 CRUD 검사만으로 통과시키지 않는다.
