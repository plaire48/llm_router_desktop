# Numbered answer sources

메일, 읽은 첨부와 위키의 근거는 답변 문장 뒤 숫자 출처로 연결한다. 기존 원문 열기, 원문 해시 검사와 접힌 출처 목록을 유지한다.

먼저 요청이 자료에 의존하는지 판단한다. 인사, 제공된 문장 다듬기와 아이디어 제안처럼 자료가 불필요하면 조회하거나 번호를 붙이지 않는다. 자료가 연결돼 있거나 앞서 읽었다는 이유만으로 인용을 강제하지 않는다. 생성 지침과 결과 검토에 같은 기준을 적용한다.

- 호스트가 실제 읽기 결과에 등록한 출처만 연결한다. 검색 제목과 읽지 못한 첨부를 근거로 추가하지 않는다.
- 처음 인용한 순서대로 번호를 정하고 반복 인용은 같은 번호를 쓴다. 저장된 답변 Markdown도 `[1](#nubi-cite-...)`로 정규화해 복사 결과와 화면의 번호를 맞춘다.
- 기존 공통 Markdown AST 라이브러리를 재사용한다. 코드 예시, 이미지와 이스케이프한 문자는 인용으로 오인하지 않는다. 등록되지 않은 출처는 기존 검토/복구 경로에서 다룬다.
- 숫자 연결은 출처 식별 검증이다. 내용이 결론을 뒷받침하는지는 기존 결과 검토가 별도로 판단한다.

검증: `answer-source-integrity`, `mail-knowledge`, `mail-attachment-recovery` 14개 자동 검사 통과. 메일 도구에서 원문과 개인 위키를 함께 전달하고 최종 답변에 숫자와 원문 해시가 저장되는 것을 모의 모델로 검사했다. 실제 회사 메일과 실모델 정확도, Windows 설치판 검증과는 구분한다.
