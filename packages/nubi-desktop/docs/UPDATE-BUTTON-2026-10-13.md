# 원형 업데이트 버튼 검증

새 버전이 있을 때 왼쪽 AI Workspace 바로 위에 원형 다운로드 아이콘을 표시한다. 최신 또는 더 낮은 배포 버전에는 숨긴다. 설정의 `업데이트 확인`은 새로고침 아이콘으로 조회만 수행한다. 클릭하면 실제 진행률 모달, 해시 검증, 유휴 상태 확인, 설치와 재실행으로 이어진다.

공통 버튼 규칙이 이름 없는 사이드바 버튼을 36px로 덮어쓰던 충돌을 48px 공통 클릭 영역으로 정리했다. 기존 AI Workspace와 같은 중심선과 20px 메뉴 간격을 유지하며 제목/텍스트 줄을 추가하지 않는다. 키보드 초점 안내와 접근성 이름을 보존한다.

- 업데이트 서비스 8개 검사 통과: 같은 버전/이전 버전은 조회만 하며 다운로드를 거부한다.
- 실제 Electron 렌더링 8개 검사 통과: 원형 48px, AI Workspace 바로 위 정렬, 최신일 때 숨김, 25% 수신 상태 표시, 검증 후 설치 1회 호출. 다운로드 전송은 합성이며 사내 서버 성공은 아니다.
- 디자인 검사 통과. 릴리즈 복사본은 격리 의존성 경계 때문에 원본 node_modules 심볼릭 링크를 사용한 전체 로컬 빌드를 거부한다. 우회하지 않고 Windows CI의 독립 설치와 빌드로 검증한다.
- 40문항 실모델 평가 동안 Agent/근거/어댑터 코드는 고정했고 평가 중 변경이 없음을 확인했다. 이 후속 변경은 업데이트 버튼과 사이드바 표시만 변경하며 최종 UI/설치 검사는 별도로 수행한다.
