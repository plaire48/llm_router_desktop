# Wave 2 Task 7: 편집 뒤 자동 검사

2026-10-18. 로컬 구현 및 검사. commit/push/릴리스는 하지 않는다.

## 동작

- 프로젝트 설정에 셸과 명령 하나를 저장한다. 기본 터미널 선택을 우선하며 빈 명령 저장으로 해제한다. 켜기 전 반영한 파일에 소급 실행하지 않는다.
- 현재 대화의 대기 제안이 모두 반영/취소되면 실제 반영한 파일 묶음에 검사 명령을 한 번 제안한다. 같은 확인 반복, 동시 확인, 거절한 명령은 재실행하지 않는다.
- 기존 `verify` 명령과 승인 흐름을 그대로 쓴다. 자동 모드의 기존 manifest 검사 명령 제한과 정확한 문자열 항상 허용 규칙을 유지한다. 모든 사용자 명령이 자동 실행되는 것은 아니다.
- 현재 반영 해시와 읽기 관찰을 묶는다. 모델 입력은 기존 참조 10개 한도를 유지하고, 10개가 넘는 호스트 묶음도 추가 인자로 같은 원문/승인 검사에 포함한다. 참조를 잘라내지 않는다.
- 준비 실패는 파일 반영 실패로 되돌리지 않는다. 대화의 짧은 안내와 `검사 다시 준비`로 파일을 다시 쓰지 않고 복구한다. 준비 중 프로젝트 전환/작업 삭제/업데이트/설정 변경을 막는다.
- 완료 게이트는 기존 `developmentChecks`, `bindDevelopmentEvidence`, `enforceDevelopmentEvidence`를 재사용한다. `result-review.mjs`와 공용 런타임은 바꾸지 않았다. 종료 코드만 보는 약한 예시 함수는 추가하지 않았다.
