# 3D 링 뒷배경과 브랜드 정렬

사용자가 메인/대화의 올가닉 그라데이션과 시작/진행 화면의 3D 표현을 구분하도록 정정했고, Liquid Glass 링의 파동/회전/부유 코드를 직접 제공했다. 이어 링은 뒷배경이어야 한다고 재확인했다. 별도의 링 삽화와 아래로 밀린 로고 초안은 폐기했다.

## 최종 화면

- 시작 로고/진행 바와 프로젝트 이동에만 실제 3D 유리 링을 크고 은은하게 깐다. 화면에 맞춰 일부가 잘리는 배경이며 중앙 로고/버전/진행 영역의 위치는 유지한다.
- 색이 보이지 않는다는 후속 피드백에 따라 원래 브랜드의 민트/아쿠아/하늘색/보라 팔레트를 표면에 직접 사용하고 흰색 혼합을 줄였다. 배경 불투명도는 .90, 재질 투과는 .65다. ACES의 추가 색 압축 없이 sRGB로 출력하고 조명과 환경 강도를 낮춰 회색으로 흐려지지 않게 한다. 팔레트는 링 둘레에서 순환 보간해 첫색과 끝색 사이의 경계를 없앴다.
- 메인/대화는 기존 여섯 색 올가닉 필드다. 가독성을 위해 불투명도를 메인 .48, 대화 .30으로 정리했다. 생성/연결 모달과 일반 준비 화면에는 링이나 새 배경을 추가하지 않는다.
- `WorkspaceBrand`를 시작/프로젝트/일반 준비/툴바에서 공유한다. 원래 누비 새와 워드마크를 사용하고 `Workspace`는 차분한 본문 계열 색으로 표시한다. 버전은 이름 아래 정렬한 작은 `v1.3.0` 문구로, 실제 빌드 버전에서 읽는다. 버전 번호를 임의로 올리거나 별도의 큰 파란 배지를 만들지 않는다.
- Pretendard/Noto Sans KR 계열을 유지하고 제품 이름은 툴바 15px, 큰 로고 18~24px, 버전은 각각 12/14px 토큰으로 구분한다. 메인 인사말은 22~28px/600과 본문 계열 색을 사용한다. 대화 본문의 읽기 크기는 유지한다.
- 실제 진행 값과 미확정 상태, 6px 공통 트랙과 채움 시간, ready/실패/취소를 보존한다. 채움 색은 기존 진한 아쿠아와 누비 파랑을 잇는 공통 그라데이션이다. 상태/제공자 고유 색은 변경하지 않는다. 기존 시작 비행의 흐름은 유지하며 빛과 배경 톤을 브랜드에 맞췄다.

## 실제 도입

`three@0.186.1`을 정확한 버전으로 잠그고 MIT 라이선스를 설치판 notices에 포함한다. 프로젝트 이동/시작 배경이 실제 필요할 때만 로컬 번들 청크를 읽는다. CDN, HDR 다운로드나 인터넷 그림 로더는 사용하지 않는다. 메일/모델의 네트워크 요구와 배경의 로컬 실행은 별개다.

`TorusGeometry(1, .29, 24, 96)`와 `MeshPhysicalMaterial`의 transmission/clearcoat/iridescence를 사용한다. 로컬 CanvasTexture 환경과 PMREM의 반사가 유리 표면을 읽게 한다. 공식 문서가 권하는 환경 맵과 고급 물리 재질의 픽셀 비용을 함께 고려했다. [재질](https://threejs.org/docs/pages/MeshPhysicalMaterial.html), [토러스](https://threejs.org/docs/pages/TorusGeometry.html), [렌더러](https://threejs.org/docs/pages/WebGLRenderer.html).

표면은 사용자가 준 세 파동과 .025/.012/.009 변위를 vertex shader에 적용한다. z 회전은 초당 .078rad이며 x/y는 작은 사인 진동, y 부유는 .06 ± .065다. 정지했던 시간만큼 재생을 건너뛰지 않는다. 일반 유체 역학 시뮬레이터나 iOS native 재질을 이식했다고 표시하지 않는다.

링 backing canvas는 기본 160,000/식별 가능한 소프트웨어 64,000픽셀 이하, 일반 필드는 64,000/24,000 이하로 구분한다. 물리 유리의 투과용 절반 해상도 타깃과 초기 환경 맵은 별도 자원이며 1 draw/frame이라고 표시하지 않는다. 그림자/추가 전경 장식은 두지 않는다. DOM 치수 읽기는 resize에서만 수행한다.

프로젝트 덮개가 비활성화돼도 렌더러를 재사용해 매 이동마다 Three.js와 환경 맵을 다시 만들지 않는다. 프레임은 활성 전경에서만 실행한다. 창 숨김/모달/화면 전환/가림, 해제와 context 손실/복구를 처리하며 지연 import 뒤 사라진 화면에는 자원을 만들지 않는다. 모션 감소/그래픽 부재는 정적 링, 강제 색상은 배경 숨김이다.

## 검증 범위

현재 소스의 로컬 결과는 `verification/workspace-atmosphere-2026-10-23/`, 실제 Electron은 `verification/project-switch-cover-2026-10-23/`에 기록한다. 이전 색 필드와 물결 표면/전경 링 초안의 결과는 최종 링 결과로 합치지 않는다. Windows GPU/드라이버/설치/업데이트와 실제 계정 검증은 별도다.

- 최종 색 보정 뒤 Electron 빌드, 디자인 검사와 관련 단위 검사 50개가 통과했다. 공통 진행 바 회귀 28개도 통과했으며 이후 수정은 링 재질/배경 색 보정이다.
- Chrome 기본 경로와 강제 SwiftShader의 1280/440px, DPR 1.5 검사 52개가 통과했다. CPU 4배 지연에서 3D 프로젝트 배경의 프레임 간격 P95는 각각 16.7/33.4ms, 채팅은 16.7/33.3ms였고 측정 구간의 긴 작업은 0개였다. 이를 모든 기기의 60fps 보장으로 표시하지 않는다.
- 화면 가림/모션 감소/강제 색상/ready 정지와 재개, context 손실/복구, 입력값/초점/위치 보존과 생성 폼 범위를 확인했다. 손실/복구 후 해제한 GL 버퍼는 각 조건에서 생성/삭제 52/52였다. WebGL이 처음부터 없으면 한 번 시도한 뒤 정적 배경으로 유지한다.
- 최종 빌드의 macOS Electron에서 메인/모델 연결 화면, 생성 모달과 실제 임시 Git 프로젝트 사이 이동을 렌더링했다. 3D 배경은 WebGL2/159,317픽셀이었고 전환 중 배경 정지, 실제 단계/경과 표시, 완료/실패 복귀와 입력 보호 검사가 통과했다. 제목은 본문 계열 색으로 표시되고 버전은 브랜드 아래에 남았다. 이 실행에는 실제 제공자 로그인이나 사용자 Windows 설치판을 포함하지 않는다.
- 새 Three 의존성으로 변경된 lockfile 전체를 검사하면서 기존 glob 7.2.3의 deprecated 안내에 들어 있던 연락처가 차단됐다. npm 원문과 기존 HEAD에도 있던 안내이며 버전/해시/의존성과 취약점 경고는 그대로 두고 지원 판매 연락 문장만 잠금 메타데이터에서 제외했다. 검사 규칙이나 공개 발견의 예외 범위를 넓히지 않았다.
