# 누비 Workspace Beta <다음 버전> 변경 안내 초안

문서 검토용 초안입니다. 버전 번호와 배포 일정은 아직 정하지 않았습니다. 1.2.10의 문서 작업 개선과 main `ddcb51d1`로 마감한 2차 물결을 함께 정리했습니다.

## 문서를 보고 고치기 — 1.2.10

- **바뀐 곳을 먼저 확인합니다.** Word의 페이지와 표, Excel의 셀과 수식, PowerPoint의 슬라이드와 메모를 변경 미리보기에서 살펴봅니다. 원본 비교, 변경 강조, 초안 수정과 Excel 계산 확인을 같은 승인 화면에서 이어갈 수 있습니다. Word와 PowerPoint 미리보기는 실제 Office 화면과 다를 수 있습니다.
- **수정한 부분을 놓치지 않습니다.** Excel의 수정된 셀과 PowerPoint의 수정된 개체에 옅은 음영을 표시합니다. 원본 보기에서는 음영을 숨깁니다. 미리보기를 접었다 펼쳐도 검토 위치를 이어갑니다.
- **PDF는 누비 안에서 편집합니다.** 일반 텍스트 입력란을 읽고, 승인 후 수정해 사본으로 저장합니다. 원본은 유지하고 같은 파일을 다시 열어도 편집 중인 내용을 보존합니다. 일반 본문, OCR, 서명과 주석 수정은 지원하지 않습니다.
- **연결한 문서의 상태를 대화에서 확인합니다.** Office와 Obsidian 문서는 기존 연결 흐름으로 사용합니다. 변경 검토, 적용 결과와 미저장 상태를 구분하며, 저장을 확인하기 전에는 저장 완료로 표시하지 않습니다. 메모장 앱 연결은 포함하지 않습니다.
- **좁은 창에서도 대화를 이어갑니다.** 채팅 입력을 시작하면 오른쪽 미리보기를 접어 입력 공간을 확보하고, 문서 연결과 편집 내용은 유지합니다.
- **출처의 숫자를 다시 대조합니다.** 선택한 첨부 스냅샷과 프로젝트 텍스트의 지정한 숫자 범위를 확인합니다. 원문이 바뀌거나 수치가 다르면 그대로 알립니다. 단위와 업무 의미까지 맞는지는 별도 검토가 필요합니다.

## 긴 작업을 더 쉽게 이어가기 — 2차 물결

- **챕터와 목차:** 작업 단계가 바뀌면 대화에 짧은 제목과 요약을 남깁니다. 챕터가 두 개 이상이면 목차에서 원하는 위치로 바로 이동할 수 있습니다. 이전 대화 기록은 그대로 남습니다.
- **자동 모드의 안전 규칙:** 자동 모드에서도 파일 삭제, 되돌리기 어려운 명령과 외부 발송 같은 작업은 승인을 기다립니다. 사용자가 정확한 명령을 직접 ‘항상 허용’한 경우는 예외입니다. 외부 반영이나 삭제로 분류된 연결 도구에는 이 예외를 적용하지 않습니다.
- **읽지 않음과 보관:** 다른 대화에서 답변이 끝나거나 질문이 생기면 읽지 않음 표시로 알려 줍니다. 오래된 대화는 기본 30일 뒤 보관하며, 보관함에서 다시 꺼낼 수 있습니다. 고정한 대화는 보관하지 않습니다. 보관은 삭제가 아니며 자동 보관을 끌 수도 있습니다.
- **산출물 카드:** 보고서, 이미지와 생성 문서를 대화 안의 파일 카드에서 열 수 있습니다. 이름과 설명을 보고 필요한 결과를 바로 찾습니다.
- **곁가지 칩:** 지금 작업과 별개로 할 만한 일을 답변 아래에 제안합니다. 칩을 선택하면 같은 프로젝트의 새 대화에서 시작하고, 필요 없으면 닫을 수 있습니다. 시작한 대화에는 ‘제안’ 표시를 붙입니다.
- **편집 뒤 자동 검사:** 프로젝트에 검사 명령을 설정하면 파일 반영 뒤 검사를 이어갑니다. 승인 설정에 따라 실행하거나 승인 카드에서 기다립니다. AI가 검사 명령의 정의나 관련 파일까지 바꾼 경우에는 자동 모드만으로 실행하지 않고 승인을 요청합니다. 정확한 명령을 직접 ‘항상 허용’한 경우는 예외입니다. 검사 실패와 확인되지 않은 결과를 완료로 처리하지 않습니다.
- **조사 하위 에이전트:** 필요한 자료 조사를 나누어 읽고 결과를 모읍니다. 조사 담당은 자료만 읽으며 파일 수정이나 명령 실행을 하지 않습니다. 메인 에이전트가 출처를 다시 확인하고, 확인하지 못한 범위도 남깁니다.
- **실패 뒤 이어서 진행:** 일시적인 모델 연결 오류는 정해진 횟수 안에서 다시 시도합니다. 이어서 진행할 때는 현재 상태와 이미 실행한 결과를 확인하며, 승인 대기나 결과가 불확실한 작업을 무조건 반복하지 않습니다.
- **Markdown 내보내기:** 대화 메뉴에서 요청, 답변, 챕터와 작업 기록을 파일로 저장할 수 있습니다. 인증값과 비밀로 탐지된 내용은 가리고 메일 원문은 제외합니다. AI가 제안한 요청은 사용자 요청과 구분해 표시합니다.
- **이 대화의 사용량:** 모델 호출, 입력과 출력 토큰, 캐시, 압축, 도구 호출과 처리 시간을 확인합니다. 제공되지 않은 토큰은 ‘—’, 일부만 집계한 값은 ‘*’로 표시합니다. 처리 시간은 동시 작업을 포함한 합계이며, 보관된 기록 범위만 집계합니다. 비용은 표시하지 않습니다.
- **루틴:** 프로젝트와 요청을 정해 매일 또는 매주 실행할 수 있습니다. 질문이나 승인이 필요하면 기다립니다. 앱이 꺼져 있는 동안은 실행하지 않고, 다음 시작 때 실행 조건이 맞으면 놓친 일정을 한 번 보충합니다.

## 작은 개선

- 아이콘 내용이 같으면 빌드할 때 아이콘 파일을 다시 쓰지 않습니다. 불필요한 수정 시각 변경을 줄였습니다.

## 배포 전 확인할 범위

Windows 11 회사 PC, Office 2016/NASCA, 실제 Obsidian 앱, 회사 로그인과 메일 수신, 창 도킹과 애니메이션 품질은 해당 환경에서 확인해야 합니다. 로컬 검사 통과가 이 환경의 업무 성공을 뜻하지는 않습니다.

작업 품질과 속도 비교는 회사 PC에서 sol과 luna 실측(Task 0/13)을 진행한 뒤 정리합니다. 진행 상태 한 줄(Task 6)은 보류 중이며, 3차 항목은 이 안내에 포함하지 않았습니다. 명령 기록의 기본 접힘은 현재 상태를 유지합니다.
