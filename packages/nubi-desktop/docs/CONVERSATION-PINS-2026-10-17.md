# 대화 고정과 메뉴 배경

대화 목록 `…`은 기본 상태에서도 옅은 배경을 표시하고 hover/초점/열림 상태에는 선택색을 사용한다. 둥근 배경, 아이콘, 접근성 이름과 툴팁은 공통 토큰을 사용한다.

고정 대화는 날짜 그룹보다 앞의 `고정` 그룹에 한 번씩만 나타난다. 새로 고정하면 맨 위에 추가하고, 고정 해제 후 다시 고정해도 맨 위로 온다. 대화의 최근 활동 시각으로 고정 순서를 바꾸지 않는다. 최근 목록을 접어도 모든 고정 대화와 일반 대화 5개는 유지한다.

`sessionSidebarGroups`는 고정 목록의 중복/삭제된 ID를 걸러내며 기존 프로젝트별 localStorage 키를 유지한다. 고정 때문에 행이 다른 그룹으로 이동한 뒤에는 같은 행의 메뉴로 초점을 돌려 키보드 탐색이 끊기지 않도록 했다.

검증은 `tests/session-navigation.test.mjs`와 `scripts/check-electron-session-pins.mjs`다. 빌드한 macOS Electron에서 오늘/어제/이전 대화를 순서대로 고정하고 해제/재고정, 접힘, 새로고침, 앱 재시작, 다른 프로젝트 전환을 확인했다. 1280/440px와 작은 창의 루트 글자 20px에서 Enter/화살표/Escape와 메뉴 경계를 확인했다.

근거는 `verification/session-pins-2026-10-17/`다. 최초 투명 배경 실패와 행 이동 후 초점 상실 재현을 보존한다. 순서 검사의 첫 실패 로그에는 시험 스크롤 타이밍 문제가 있어 그것을 제품 정렬 오류의 직접 재현으로 사용하지 않는다. 최종 `checks.json`과 `verification/design-token-audit-2026-10-17/final-pins.log`는 수정 후 통과다. 실제 Windows 설치판 확인은 별도다.
