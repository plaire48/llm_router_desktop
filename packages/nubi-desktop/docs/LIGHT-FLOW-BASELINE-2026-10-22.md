## 판정

조건 A 판정은 아직 실패다. 목표는 그대로 둔다.
- 스타일 계산 최대 초과(wiki 39.5, 70.9ms, navigation 37.5, 32.3ms, mail 16.9, 16.6ms): 화면을 처음 열 때 한 번 생기는 계산이다. 요소마다 1.4MB, 1만 개 넘는 규칙과 맞춰 보는 비용이라 계획 2의 CSS 줄이기(덮어쓰기 층 합치기, CX 미사용 규칙 빼기)에서 다시 잰다.
- 긴 작업 초과(mail 6, navigation 13, 12): 스타일이 아니라 JS다. 메일 목록이 행을 지우고 다시 붙이는 작업(removeChild, setAttribute)과 화면 전환 때 큰 화면을 붙이는 작업이다. 상태 관찰기는 비용을 더하지 않았다(mail 장면 DOM 작업이 모두 기준선 이하, querySelector 합계 약 20ms). 계획 2의 새 작업으로 넘긴다.
- chat 놓친 프레임은 실행마다 흔들린다. 계획 2 판정 때 세 번 실행의 중앙값으로 본다.
