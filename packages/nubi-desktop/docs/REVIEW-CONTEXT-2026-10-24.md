# 답변 검토 문맥과 표시

주 답변과 독립 검토는 같은 선택 제공자/모델을 사용한다. 검토는 도구 권한 없이 요구사항, 답변 후보와 호스트 근거를 받는 별도 요청이다. 사용자 Windows에서 나온 특정 답변의 원문/검토 기록은 이번 작업에 제공되지 않았다. 그 답변의 내용 정확성이나 실행 중인 설치판 버전까지 확인했다는 뜻은 아니다.

## 확인한 원인과 변경

- 검토 입력에 이전 사용자 발화는 있었으나 이전 답변이 빠져 있었다. 후속 질문이 앞선 답변의 선택지나 표현을 가리킬 때 주 실행기와 검토기의 문맥이 달랐다. 같은 대화의 역할을 표시한 참고 기록을 추가했다. 최신 요청, 정정과 실제 호스트 근거가 우선이며 참고 기록은 현재 파일/테스트/외부 사실이나 승인을 증명하지 않는다. 네이티브 메시지 역할 호환이라고 표시하지 않는다.
- 현재 모델 예산 안에서 최대 10%, 6,000 토큰과 24개 메시지를 사용하고 메시지별 잘림/생략을 기록한다. 현재 요청과 답변이 먼저 자리를 차지하면 추가 대화 문맥을 생략하고 수를 남긴다. 새 참고 기록 때문에 원래 들어가던 현재 답변이 문맥 초과로 중단되는 경계도 확인했다. 검토 원본 영수증에는 실제 전달한 대화 참고와 생략 수를 보존한다.
- 모델이 추가한 `intent:*` 점검은 사용자가 요청한 결과의 누락과 구분한다. 사용자 요구가 근거로 확인되면 짧은 근거 펼침을 보이고 보조 점검은 그 안의 추가 점검에 보존한다. 기존 호스트의 `interpretation_only` 판정과 다음 단계도 이력/재열기에서 유지한다. 원래 unknown/pending/오류와 사용자 요구의 미해결 상태, 검토 반복 상한은 바꾸지 않는다.
- 제품 프롬프트에 도구 호출마다 설명 문장을 생성하라는 지시가 있었다. 단순 검색/읽기/화면 조회는 도구의 실제 상태로 알리고, 발견/방법 변경/지연/사용자 결정만 공개 진행 문장으로 안내한다. 모델 응답 내용을 문자열로 삭제하거나 필터링하지 않는다. 따라서 실제 모델의 문장 생성 품질을 보장하는 변경은 아니다.

## 검증

입력 문맥, 보조 항목 표시, 다음 단계와 이력 보존, 좁은 예산 경계를 각각 수정 전 실패로 재현했다. 최종 관련 Node 검사 62개가 통과했다. 실제 macOS Electron의 개인 대화 2차례에서 같은 선택 모델 호출, 이전 답변의 검토 전달, 도구 없는 문장 재작성과 불필요한 결과 경고 부재를 확인했다. 격리 저장소와 고정 응답 로컬 제공자이며 실제 모델 성적은 아니다.

- 전체 `npm test`: 2,920개 중 통과 2,718개, 생략 202개, 실패 0개. 전체 검사 중 보완한 이력 메타데이터/예산 경계는 최종 소스의 관련 검사 62개로도 별도 확인했다.
- 제품 Workbench/최종 CSS를 사용한 격리 Electron renderer의 실시간 동작 5개 너비(440~2560px), 보조 점검 펼침과 440px 글자 200%, 실제 누락/다음 단계/오류 상태 통과. 앞선 전체 너비와 입력 초점/폼 즉시 처리/실시간 출력 검사를 유지했다.
- 실제 macOS Electron 앱의 2차례 대화와 1280/440px 캡처 통과. 첫 실행의 캡처 단계는 좁은 창에서 이미 자동으로 닫힌 사이드바 버튼을 기다려 실패했다. 검사 대기를 실제 닫힘 상태에 맞춘 후 통과했고 첫 실패 로그도 보존했다.
- `npm run build:electron`, `npm run design:check` 통과. 기존 Windows Bash CJS import.meta 경고와 PowerShell 부재에 따른 선택 Office 파서 검사 생략은 동일하다.
- 추가 `npm run test:shared-ui`는 첫 시작 화면의 기존 반투명 그라데이션 5개에서 `contrast_unmeasured`로 실패했다. 이 검사를 통과로 표시하지 않는다. 이번 변경은 해당 CSS를 수정하지 않았으며 새 검토 화면은 위의 별도 renderer/실제 앱 검사로 확인했다.

화면/원시 로그는 `verification/review-context-2026-10-24/`, 화면 상태 검사는 `verification/realtime-actions-2026-10-23/`에 보관한다. Windows/설치판/실제 제공자의 답변 정확성은 별도 확인 대상이다.
