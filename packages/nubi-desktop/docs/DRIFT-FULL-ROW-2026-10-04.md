# 이름의 전체 행 호버 영역

짧은 이름의 `DriftLabel`이 flex 행에서 내용 너비만 차지해 남은 여백을 사용하지 않았다. 공통 레이블을 `flex:1 1 0%`와 `width:100%`로 변경했다. 기존 flex 배치가 오른쪽 아이콘, 상태와 동작 영역을 먼저 확보하고 레이블은 남은 영역을 채운다. 내부 창에서 잘라 텍스트가 아이콘 위에 나타나지 않게 한다.

기존 Web Animations와 ResizeObserver를 재사용했다. 원래 자리에서 왼쪽으로 이동하고 사라진 뒤 확보한 영역의 오른쪽 끝에서 다시 진입하는 흐름과 48px/s 속도를 유지한다. 모델 이름은 기존처럼 고정하며 새 의존성은 추가하지 않았다.

Electron 빌드가 완료됐다. 자동 테스트는 실행하지 않았다. 4320 예시 화면에서 짧은 폴더명의 영역이 29.875px에서 151px로 늘었고 오른쪽 아이콘의 시작점 258px보다 앞인 250px에서 잘리는 것을 확인했다. 대화명의 오른쪽 상태 아이콘도 같은 8px 간격을 유지했다. 실제 실행 중인 Electron 재로드는 인증과 미저장 상태 손실에 대한 자동 승인 검토 거절로 대기 중이다.
