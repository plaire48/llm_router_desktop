# 진행 바 남은 시간

사용자 범위 정정: 채팅의 예상 응답 시간이 아니라 프로그래스 바의 예상 잔여 시간을 제공한다. 채팅은 기존 경과 시간 표시를 유지한다.

- 위키 생성/갱신, 메일 파일 가져오기, 메일 저장 위치 이동, Git 가져오기에 공통 추정기를 연결했다.
- 현재 단계에서 관찰한 처리량 증가와 경과 시간으로 남은 양을 계산한다. 복사는 바이트, 문서와 Git은 실제 완료 개수를 사용한다. 5초 단위로 올림하여 `현재 단계 약 1분 20초 남음`으로 표시한다.
- 단계, 작업, 분모 변경 또는 카운터 감소 시 측정 기준을 다시 잡는다. 이어쓰기 전에 완료한 수를 새 실행의 처리 속도로 계산하지 않는다.
- 총량이 없으면 `전체 작업량 확인 중`, 아직 새 처리량이 없으면 `처리 속도 확인 중`을 표시한다. 임의의 예상 시간이나 진행률을 만들지 않는다. 단계 처리가 끝나면 `마무리 확인 중`을 표시하고 최종 완료/오류에서 추정 영역을 제거한다.
- 추정은 전체 작업의 확정 종료 시각이 아니다. 파일별 크기, 네트워크와 모델 속도에 따라 변한다. UI 툴팁에서 근거와 변동 가능성을 설명한다.
- 기존 공통 글꼴, 보조색, 여백과 모달을 유지했다. 별도 창이나 새로운 배경 카드를 만들지 않는다.

검증: `tests/remaining-time.test.mjs`, `tests/response-timing.test.mjs` 5건. `scripts/check-progress-estimate.mjs`는 공유 진행 바와 실제 Wiki/Git 컴포넌트에서 처리량 증가 후 숫자 표시, 단계 변경 초기화, 완료 시 제거, 1280/440px 잘림 없음을 확인한다. 합성 처리량의 로컬 브라우저 검증이며 실제 대용량/사내망 ETA 정확도나 Windows 측정은 아니다.
