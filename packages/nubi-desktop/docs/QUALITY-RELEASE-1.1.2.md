# Nubi Workspace Beta 1.1.2

## Changes

- Windows app-scoped official MinGit, pinned SHA-256 and retained upstream licenses. No system PATH or global Git changes. Missing/denied/timeout/ownership failures have actionable messages. Code Wiki checks Git before reading sources.
- Skills Team/Personal and Wiki Code/Personal share tabs and SSO entry. Mail uses sortable sender/subject/recipient-role/date columns with the reader below. POP3 sent-mail collection remains unsupported.
- Clipped file names animate only while hovered/focused and stop when the name fits or reduced motion is requested.
- Claude actor output streams from the CLI's structured text field. Internal planning and private thought are not displayed. Historical analysis is available on explicit request.
- In-app updates read the fixed GHES channel, validate release asset/size/hash, show real download percentage and automatically install/relaunch after work and dirty editors are checked. Corporate publishing instructions are separate.
- Repeated compaction no longer re-inserts the entire accumulated citation catalog. The last 12 are included in the prompt; complete provenance remains in host state. Recovery questions accept the input hint generated by the shared recovery normalizer.

## Method choices

Reuse official MinGit rather than implementing Git behavior or modifying system installation. Preserve upstream notices, pin artifact integrity and scope execution to app children. Use existing Electron-builder NSIS update flags and the existing native GHES credential owner. No new OAuth/token collection or user credential migration.
