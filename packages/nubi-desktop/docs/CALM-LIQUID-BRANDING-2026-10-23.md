# Calm Liquid 브랜딩 적용

사용자가 지정한 여섯 색의 110deg 그라데이션을 Desktop의 대표 브랜드로 적용했다. 기존 HTML의 출처/해시는 보존하고 최신 사용자 팔레트를 reference.json의 adaptation.theme에 명시한다.

## 화면과 캐릭터

- 브랜드 원색과 새의 기존 승인 색감은 그대로 보존한다. 주요 버튼, 새 대화와 전송에는 원색에 흰색 60%를 섞은 연한 그라데이션과 네이비 글자/아이콘을 사용한다. 프로젝트 연결 카드에는 흰색 92%의 거의 흰 배경 그라데이션을 사용한다. 읽기 면은 흰색, 캔버스는 #FAFCFF이며 링크/포커스/보조 강조는 읽을 수 있는 진한 색을 사용한다.
- AI Pro/ChatGPT/Claude 모델 및 추론 컨트롤의 고유 색, 성공/주의/오류 의미는 유지한다. 프로젝트 연결 창에서도 기존 공통 모델/추론 템플릿을 사용한다.
- 배경은 좌측 상단/우측 하단의 두 유기적인 SVG 실루엣으로 단순화했다. 고정 색/블러/불투명도로 밝기를 유지하고 24/28초 transform 모션의 다섯 자세로 연결한다. 매 프레임 SVG 경로를 변형하는 구현은 아니다.
- 새의 기본/깜빡임/날갯짓/웃음/슬픔 다섯 이미지를 imagegen으로 편집하고, 투명 배경과 전체 정사각 프레임을 유지해 512px WebP로 내보냈다. 기존 AgentMark의 동작을 그대로 재사용한다. 앱 아이콘과 16/32/48/128px 아이콘도 같은 마스터에서 내보냈다. 기존 NSIS 이미지 생성기도 같은 마스터를 읽도록 연결하고 사이드바/헤더 비트맵의 로컬 생성을 확인했다. Windows 설치 실행은 포함하지 않는다.
- Desktop 전용 assets를 빌드 시 공유 아이콘 위에 덮어 복사한다. 공유 확장의 캐릭터나 제공자 로고 파일은 수정하지 않았다. 신규 디자인 의존성은 없다.

## 검증과 경계

`npm run build:electron`, `node scripts/check-identity.mjs`와 관련 단위 검사 24개를 통과했다. 단위 범위는 모션 정책, 프로젝트 준비, 네이티브 타이틀바 색상과 아이콘의 중복 복사 방지다.

`scripts/check-calm-liquid-ui.mjs`는 격리한 실제 macOS Electron에서 합성 제공자 상태로 검사한다. 정확한 색 토큰과 두 SVG, 다섯 캐릭터 이미지의 실제 번들 바이트/디코딩과 앱 아이콘, 그라데이션/네이비 버튼, 프로젝트 연결 창과 초안 보존, 위키/메일, 모션 감소/창 숨김/강제 색상/620px 창을 확인한다. 성공 캡처에 공통 디자인 규칙을 사용하고 시작 화면/연결 모달의 대비와 연결 모달의 양방향 Tab 순환은 공통 접근성 규칙으로 확인한다.

모델·추론 컨트롤 회귀 7개와 실제 프로젝트 전환 커버 검사를 통과했다. 전환 동안 가려진 배경 모션 정지, 한 방향 진행 효과, 정상/실패/모션 감소 흐름을 포함한다. 기존 `workspace-density.css`의 추론 선택자 확장은 보존했다.

새 캐릭터 자산을 실제 Desktop과 같은 순서로 복사하도록 공통 화면 검사 fixture도 맞췄다. `NUBI_SURFACE_OUTPUT=verification/calm-liquid-all-surfaces-2026-10-23 npm run test:all-surfaces`에서 117개를 통과했다. 넓은/좁은/200% 글자, 모달과 위키/메일의 합성 상태를 실제 Electron에서 렌더링한 검사이며 실계정/실제 자료 결과는 아니다.

성능 수치는 `verification/calm-liquid-2026-10-23/result.json`에 기록한다. requestAnimationFrame으로 프레임을 관찰하는 계측 자체가 스타일 표본을 매 프레임 읽게 하므로, 그 결과의 재계산 수를 배경 원인으로 단정하지 않는다. 계측을 끈 4초 유휴와 물방울 정지/전체 모션 정지 조건을 별도로 비교한다. 최종 로컬 표본은 프레임 관찰 8초 동안 50ms 초과 작업 0, 레이아웃 0회였고, 프레임 관찰을 끈 4초 유휴의 스타일 재계산은 후속 연한 배경에서 물방울 실행 8회/정지 7회였다. 배경의 전체 밝기 범위는 0.13/255 이내였다. SVG 내부의 매 프레임 코드 없이 외부 HTML transform을 사용하며 별도 CDP 레이어 진단에서 가속된 transform과 초기 paint 1회를 확인했다.

위키/메일은 빈 로컬 화면이고 실제 계정/자료/모델 호출은 사용하지 않았다. 로컬 UI와 계측 결과는 Windows 설치/업데이트/재실행, Windows에서 보고된 전반적 끊김 해소나 실모델 품질 증명이 아니다. 전체 게이트와 후보 업로드는 Claude 소유이며 이번 작업에서 푸시/머지하지 않았다.


## 후속 피드백: 연한 활용과 대화창의 새

사용자는 새의 기존 그라데이션이 더 좋다고 정정했다. 후속으로 생성했던 연한 캐릭터는 제품에 적용하지 않았으며 기존 다섯 이미지/마스터/아이콘의 바이트가 변경 전과 동일함을 확인했다. 브랜드 여섯 원색도 유지하고 흰색을 섞은 표현용 토큰만 별도로 추가했다. 본문/원본 메일/입력창은 흰 바탕과 짙은 글자를 유지하며 제공자 고유 색도 덮어쓰지 않는다. 배경 물방울의 강도는 0.24/0.18로 낮췄다.

빈 대화창의 새가 작았던 이유는 후행 iOS 토큰의 88~128px 크기 제한이었다. 빈 대화 진입을 `data-entry=conversation`으로 구분해 그 화면만 176~280px 가변 크기로 확장하고 위쪽으로 배치했다. 프로젝트 선택과 답변 행의 작은 마스코트에는 이 배치를 적용하지 않는다. 새 CSS :has 선택자는 추가하지 않았다.

실제 격리 Electron의 전후 비교에서 1280×900 창의 새는 126→279px, 위쪽으로 약 231px 이동했다. 620×820, 1280×620, 200% 글자에서도 새/안내/입력창 겹침과 가로 넘침 없이 공통 대비/키보드 검사를 통과했다. 비교 캡처와 측정은 로컬 작업의 `soft-welcome-before/`, `soft-welcome-after/`에 보관한다. 같은 소스로 브랜딩 네이티브 검사 10개도 다시 통과했다.

후속 소스로 공통 화면 117개도 `verification/calm-liquid-soft-surfaces-2026-10-23/`에서 다시 통과했다. 본문 대비, 모달/선택 상태와 큰 글자/좁은 창을 포함한다. 기존 Windows 검증 경계는 동일하다.
