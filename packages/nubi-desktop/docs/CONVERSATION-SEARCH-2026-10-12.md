# Conversation search

기존 검색은 overview의 최근 50개 task.request만 조회했다. 현재 공간의 모든 저장 task를 검색하는 conversationHistory를 추가했다. 사용자 질문과 AI 답변 원문 전체를 검사하고 결과만 50개씩 반환한다. 모델 문맥 압축이나 화면 목록의 개수 제한과 검색 범위는 별개다.

검색 결과는 제목, 시각, 일치 구절 한 줄로 구성한다. 구절 앞에 나/AI를 표시하고 문자 그대로의 검색어를 React mark로 강조한다. 복사 버튼은 제거했다. 빈 검색은 최근 순 목록과 전체 범위를 표시하고 비동기 검색은 지연/실패/빈 결과를 구분한다. 이전 응답이 새 검색어의 결과를 덮어쓰지 않는다. 오래된 항목을 열 때 호스트에서 full task를 읽으며 state/overview는 현재 선택한 오래된 대화도 유지한다.

현재 공간의 대화만 검색하며 다른 프로젝트 DB, 인증값, 도구의 내부 기록을 검색하지 않는다. 전체 프로젝트 검색으로 표시하지 않는다. 기존 SQLite 저장소를 재사용하고 별도 색인 복사나 검색 패키지는 추가하지 않았다. literal substring은 한 글자 한국어와 문장 중간 일치에 적합하며 정규식 문자는 이스케이프한다. 대화가 매우 많아 검색 지연이 관찰되면 저장소 색인 도입을 별도 측정한다.

검증: SQLite의 대화 61개에서 최근 목록 밖의 대화와 긴 답변 끝부분을 조회하고 원문을 열었다. 한 글자 한국어, 대소문자, 정규식 기호, 메시지 text 배열, 미일치와 페이지 전환을 검사했다. 실제 React 화면 1280/440px에서 본문만 일치하는 빵 검색, mark, 복사 없음과 대화 열기를 확인했다. verification/ui-conversation-search-*.png는 합성 화면이다.

왼쪽 도구는 48px 클릭 영역과 24px 아이콘을 유지하면서 상하 여백 16px, 버튼 간격 20px로 넓혔다.

실제 앱을 새 실행기로 재시작한 뒤 저장된 대화에서 제목에 없는 `28`을 검색했다. AI 답변의 `28건`이 포함된 구절과 강조 표시, 결과 1개, 복사 버튼 없음, 결과 클릭 후 해당 대화 열기를 네이티브 화면에서 확인했다. 저장된 데이터로 검증했으며 새 모델 호출이나 메일 재수신 검증은 아니다.

후속 사용자 피드백에 따라 `질문과 AI 답변 포함` 보조 문구를 제거했다. 전체 질문/답변 검색 범위는 유지하며 렌더러 빌드와 실제 앱 새로고침 후 문구가 사라진 것을 확인했다.
