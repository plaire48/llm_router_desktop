# Wave 2 Task 5 곁가지 작업 칩

현재 1.2.10 작업 폴더의 Task 4 완료 상태에 설계 A2를 덧붙였다. 전체 게이트가 종료 코드 0으로 통과했다.

## 적용

- `spawn_task`는 확인된 범위 밖 일을 제목, 짧은 이유, 독립적인 요청으로 제안한다. 요청은 파일 경로를 포함한 200~4,000자, 실행당 3개다. 모호한 개선 제안과 한 줄 수정은 공통 도구 규칙에서 제외한다.
- 같은 실행에서 해결한 제안은 `dismiss_task`로 거둔다. 호스트의 실행 ID를 사용하며 다른 실행의 제안을 모델이 닫지 못한다.
- 답변 아래 칩을 누르면 기존 `createTask`로 같은 프로젝트의 대화를 준비하고 선택한다. 기존 시작 버튼으로 실행한다. 이 단계에서 파일 변경이나 명령을 실행하지 않는다.
- 중복 클릭은 같은 생성 요청을 공유한다. 시작한 칩에는 새 대화 ID를 보존해 다시 요청해도 추가 대화를 만들지 않는다. 생성 실패 시 제안 상태를 유지한다.
- 사용자가 닫거나 새 대화로 옮긴 상태는 늦은 모델 응답의 이전 스냅샷으로 되돌아가지 않는다. 칩 기록은 삭제하지 않는다.
- 생성 중 원 대화 삭제, 같은 서비스의 프로젝트 교체와 앱 업데이트를 차단한다. 다른 프로젝트/대화로 전환한 뒤 늦게 온 응답이 현재 화면을 바꾸지 않도록 UI 범위를 확인한다.
- 칩과 닫기 버튼은 공통 디자인 토큰과 기존 액션을 사용한다. 디자인 시스템에 sparkles가 없어 기존 Mark 규격으로 공용 SparklesMark를 추가했다.

## 검증

- 최초 모듈 누락과 칩 미표시를 재현했다. 첫 연결 중 도구가 아직 등록되지 않은 실패도 확인했다.
- 새 도구를 넣자 스키마 6,158 토큰으로 기존 한도를 넘었다. Desktop 전체 목록의 반복 설명을 이름별 `TOOL_RULES`로 옮겼다. 공용 도구 정의, 입력 제약과 lean 설명은 유지했다. 전체 설명 축약 후 lean/full 크기 비율 검사도 한 차례 실패했고, 첨부 범위의 다음 페이지와 하위 분석 동시 실행 한도라는 유용한 정보를 설명에 유지해 두 예산 검사를 함께 통과했다.
- 집중 시험 최종 41개 통과. 칩 한도/상태 전이, 같은 프로젝트의 단일 대화 생성, 사용자 닫기 보존, 생성 실패와 재시도, 진행 중 보호, 실제 에이전트 spawn/dismiss, 기존 lean/스키마/위키 안내와 압축 회귀 9개를 포함한다.
- 첫 전체 게이트에서 기존 압축 검사 2개가 실패했다. 긴 사용자 원문이 있는 이력에서 실행이 멈추고, 긴 답변 뒤 압축에서 검토 피드백이 누락됐다. 별도 실행에서도 재현한 뒤 해당 게이트 프로세스만 중단했다. 이후 취소 표시는 중단 결과다. 새 안내의 고정 입력 증가가 원인이어서 중복 문장을 줄이고 도구 계약은 유지했다. 공용 압축 코드와 기존 시험은 바꾸지 않았다. 압축 9개를 포함한 집중 시험 41개가 통과했고 전체 게이트를 새로 실행했다.
- 1280px/440px Chrome 합성 화면 통과. 두 칩 표시, 긴 제목 배치, 닫기, 키보드로 새 대화 선택, 요청 전달과 기존 시작 버튼을 확인했다. 두 화면을 직접 확인했다.
- 최종 `npm run test:gates` 종료 코드 0. 단위 총 1,976개 중 1,776개 통과, 실패 0개, 플랫폼/기능 조건으로 200개 건너뜀. 디자인 검사, 브라우저 UI, 빌드, macOS Electron, 117개 화면 조합, 비가역 승인 화면과 추가 QA 4종 모두 통과했다. 산출물 카드의 이미지/캡처/텍스트/PDF/Word 열기와 새로고침 후 보존도 통과했다.
- 게이트 종료 후 소스/검사 12개 파일의 해시가 시작 시점과 같음을 확인했다. 로컬 완료이며 Claude QA/업로드는 남아 있다.

## 증거 범위

현재 기능 검사는 합성 모델 응답과 로컬 자료다. 실제 모델이 제안하는 업무의 타당성, 회사 PC, Windows 설치판 성적은 별도로 확인해야 한다. 평가 과제와 채점기는 변경하지 않았고 push와 릴리스도 하지 않았다.
