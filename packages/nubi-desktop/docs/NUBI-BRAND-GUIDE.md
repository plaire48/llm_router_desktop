# 누비 브랜드 관리 기준

누비는 민트에서 블루, 라벤더로 이어지는 여섯 색과 기존 새 캐릭터를 브랜드 원형으로 사용한다. 글자와 정보를 읽는 면은 밝고 안정적으로 유지하고, 같은 색을 연하게 섞은 면과 선명한 기능 아이콘으로 화면의 소속감을 만든다.

2026-10-23 추가 아이덴티티 원본은 루트 `design-reference/nuvi_calm_liquid_theme.html`과 `design-reference/motion_interaction_atlas.html`이다. 강조 파랑은 `#2873EE`, 작은 글자/링크/초점의 진한 파랑은 `#1765DB`를 사용한다. Calm Sky `#A9D9FF`, Aqua `#A8EDEA`, Lavender `#C5BBFA`를 보조 테마 토큰으로 제공하며 기존 여섯 색 마스코트 그라데이션은 유지한다. 흰 바탕의 일반 크기 문구에는 대비 약 5.36:1인 진한 파랑을 우선한다. 유리 효과를 강조하려고 별도 색/패턴을 유리 뒤에 추가하지 않는다.

## 한곳에서 관리

브랜드 원본은 `design/brand/nubi-brand.css`다. 원색, 읽을 수 있는 잉크색, 흰색과 섞는 강도와 의미별 별칭을 관리한다. 모달, 화면과 아이콘에 원시 HEX를 직접 쓰지 않는다. `design/reference.json`은 사용자가 승인한 색상과 사용 규칙의 검증 계약이며 브랜드를 의도적으로 바꿀 때 함께 갱신한다. `node scripts/check-identity.mjs`가 원색과 파생색, 글자/아이콘 대비를 대조한다.

| 브랜드 원형 | 값 |
| --- | --- |
| Mint | #74CDD4 |
| Aqua | #8EDAD9 |
| Sky | #9BCFE8 |
| Periwinkle | #A2BFEA |
| Iris | #B3B8E5 |
| Lavender | #CEC7EB |

대표 그라데이션은 110deg, 순서대로 0/20/40/60/80/100%다. 새 캐릭터의 기존 승인 색감과 다섯 표정은 유지한다.

시작 컷신도 `WorkspaceBrand`를 공유한다. 비행 뒤 타이틀과 평소 짧은 시작 화면, 모션 감소 화면에 같은 새 원본과 워드마크를 표시한다. 컷신에서는 로고 아래에 패키지의 숫자 버전을 표시하며 현재 값은 `1.3.0`이다. 빌드가 주입하는 `__NUBI_VERSION__`을 사용하므로 별도 문자열로 버전을 복제하지 않는다. 상단 도구 줄, 설정과 창 제목도 같은 숫자 버전을 표시한다. 좁은 도구 줄에서도 버전 배지는 숨기지 않는다. 컷신 버전은 20~24px/600, 도구 줄 버전은 14px이며 준비 막대는 높이 10px로 표시한다. 준비 중에는 상태 문구와 불확정 막대를, 실제 준비 완료 후에는 완료 문구와 100%를 표시한다.

Windows 컷신 동안에는 네이티브 창 버튼의 그림과 클릭을 막고 완료 후 기존 컨트롤과 최신 테마 색을 복원한다. 실제 Windows 표시 확인은 macOS 렌더링이나 모의 네이티브 호출 검사와 구분한다. [컷신 브랜드와 창 버튼 검증](CINEMATIC-BRAND-1.3.0-2026-10-23.md)을 따른다.

## 색을 사용하는 역할

| 용도 | 브랜드 비율 | 흰색 비율 | 적용 |
| --- | --- | --- | --- |
| 주요 동작 / 아이콘 타일 | 40% | 60% | 새 대화, 전송, 모달 주 동작, 제목 아이콘 바탕 |
| 선택된 영역 | 20% | 80% | 현재 메뉴, 현재 대화, 선택 필터와 카탈로그 탭 |
| 화면과 모달의 분위기 | 8% | 92% | 모달 제목부, 상단 도구 줄, 메뉴 레일, 프로젝트 카드 |
| 읽기 / 입력 | 흰색 유지 | 100% | 모달 본문, 문서/메일 원문, 대화 본문과 입력창 |

강도는 `--nuvi-action-tint`, `--nuvi-selection-tint`, `--nuvi-content-tint`에서 조절한다. 파생 그라데이션은 CSS color-mix로 원색을 참조하므로 화면마다 연한 색을 복사해 보관하지 않는다.

화면은 `--nubi-brand-modal-header`, `--nubi-brand-page-header`, `--nubi-brand-selection`, `--nubi-brand-icon-tile` 같은 역할을 사용한다. 기능 CSS는 공통 컴포넌트의 형태/색 역할을 재정의하지 않는다. 새 화면도 기존 DetailPanel, CX 컨트롤과 공통 제목 아이콘을 재사용한다.

## 아이콘

- 일반 기능은 Lucide 1.61.0의 원본 SVG를 사용한다. `ui/LucideIcon.jsx`가 기존 CX 기능 이름을 연결하므로 같은 기능은 같은 도형을 쓴다. 24px 격자와 둥근 1.8px 선, 크기/클릭 영역의 공통 역할 토큰을 유지한다. 새 캐릭터, 회사/제공자/GitHub/AI Workspace 로고는 별도 브랜드 원형을 유지한다.
- 일반 기능의 아이콘은 진한 청록, 블루, 라벤더 잉크가 이어지는 선을 사용한다. 연한 브랜드색은 바탕 타일에 둔다. 작은 선을 옅은 파스텔로 칠하지 않는다.
- 하나의 정적 SVG 그라데이션 정의를 메뉴/제목/프로젝트 카드/위키 아이콘과 body 포털이 함께 참조한다. 아이콘마다 SVG 정의나 애니메이션을 추가하지 않는다.
- 닫기, 삭제, 확인과 경고/오류/완료 같은 의미를 가진 아이콘은 기존 동작/상태의 색을 유지한다. 제공자 로고/모델·추론 컨트롤, AI Workspace 로고와 원본 콘텐츠를 일반 아이콘처럼 다시 칠하지 않는다.
- 아이콘의 색만으로 현재 메뉴나 상태를 구분하지 않는다. 선택 면과 기존 aria-pressed/aria-selected, 접근성 이름/툴팁/키보드 초점을 함께 유지한다.
- 호버/키보드 초점은 안쪽 도형만 최대 4% 반응한다. 기존 메뉴 Dock 효과도 이 도형을 사용해 바깥 SVG/버튼/텍스트 위치를 고정한다. 누를 때는 살짝 줄어들며 반복 애니메이션이나 새 프레임 루프를 추가하지 않는다. 모션 감소에서는 정적으로 표시한다.
- 로딩은 같은 Lucide 모래시계를 사용한다. 읽을 수 있는 브랜드 잉크를 `--nubi-brand-icon-fill`로 적용하고 4초마다 잠시 멈췄다가 뒤집는다. 숨김/모달/모션 감소의 기존 정지 정책과 강제 색상 모드를 따른다. 진행률이나 완료 상태는 아이콘 움직임으로 만들어내지 않는다.

## 버튼과 배치

| 역할 | 공통 토큰 | 기본 16px 글자 기준 |
| --- | --- | --- |
| 일반 컨트롤 높이 | `--nubi-work-control-height` | 40px |
| 터치 컨트롤 최소 영역 | `--nubi-work-control-touch` | 44px |
| 일반 / 상단 / 메뉴 아이콘 | `--nubi-icon-control` / `--nubi-icon-toolbar` / `--nubi-icon-navigation` | 16 / 17 / 20px |
| 목록 / 펼침 아이콘 | `--nubi-icon-inline` / `--nubi-icon-disclosure` | 14 / 12px |
| 동작 그룹 간격 | `--nubi-control-gap` / `--nubi-work-control-gap` | 8px |

아이콘은 버튼의 클릭/초점 영역 안에 두고 수직 중심을 맞춘다. 펼침 화살표는 메뉴/접기 컨트롤에만 작은 토큰을 적용한다. 메일 이전/다음 같은 독립 동작은 일반 아이콘 크기를 유지한다. 텍스트 크기가 커지면 rem 기반 아이콘도 함께 커진다.

좁은 입력창의 마우스 버튼 그룹은 `--cx-space-1`(4px)까지 줄일 수 있다. 터치 환경에서는 클릭 영역 44px와 간격 8px를 유지한다. 작은 설정 스위치는 트랙 모양을 유지한 채 버튼 영역만 넓힌다. 여러 줄 프로젝트/모델/대화 카드는 별도의 콘텐츠 배치를 유지한다.

관련 동작은 같은 그룹으로 묶고 위험하거나 세션을 끝내는 동작은 분리한다. 모델 창은 새로고침/연결 편집을 왼쪽에, 연결 해제를 오른쪽에 둔다. 한쪽에 놓였다는 이유만으로 모든 버튼을 화면 전체에 균등 분산하지 않는다. 원래의 접근성 이름, 툴팁과 키보드 초점을 보존한다.

`scripts/button-layout-audit.mjs`는 실제 렌더링된 버튼과 아이콘의 영역, 토큰 크기, 겹침과 그룹 간격을 기록한다. 공통 화면 검사와 실제 호스트 검사에서 함께 사용한다. [버튼 배치 검증 기록](BUTTON-LAYOUT-AUDIT-2026-10-23.md)에 확인 범위를 적는다.

## 가독성과 움직임

20개 모션도 색/아이콘/새와 함께 브랜드 자산으로 관리한다. 기존 Atlas의 18개 상호작용과 물방울/모래시계 2개를 같은 목록에서 관리하며, [상황별 20개 모션 기준](BRAND-MOTION-GUIDE.md)을 따른다. 기능/데이터가 준비되는 시점은 그대로 두고 사용자가 공간, 선택과 실제 작업 상태를 이해하도록 연결한다.

전환/선택 표면은 `--nubi-brand-motion-surface`(브랜드 20%), 유리/로딩 배경은 `--nubi-brand-motion-glass`(8%), 윤곽은 `--nubi-brand-motion-edge`를 사용한다. 본문/입력의 색이나 좌표는 장식에 따라 바꾸지 않는다. 모달/프로젝트 전환/창 숨김이 시작되면 이전 장식 효과를 정리하며, 돌아왔을 때 다음 상호작용부터 반응한다.

본문과 일반 레이블은 최소 4.5:1, 기능 아이콘은 최소 3:1을 유지한다. `check-identity`는 브랜드 표면과 잉크의 보수적인 색 경계도 확인한다. 실제 화면의 문자/컨트롤과 모달 Tab 순환은 공통 접근성 검사로 확인한다. 대비를 맞추기 위해 본문을 작게 하거나 지나치게 굵게 만들지 않는다.

브랜드 배경은 정적이며 새 반복 모션을 추가하지 않는다. 기존 두 물방울의 낮은 강도와 모달/숨김/모션 감소 정책을 유지한다. 강제 색상 모드에서는 그라데이션과 SVG 색 참조를 시스템 색으로 바꾼다. 원본 메일 HTML, 문서, 코드/터미널과 제공자 UI를 브랜드 스타일로 덮지 않는다.

## 유지 위치

- 색과 강도: `design/brand/nubi-brand.css`
- 일반 UI 별칭과 서체/형태: `design/workspace-identity.css`
- 모달 제목/본문 계약: `design/workspace-dialogs.css`
- 일반 화면과 선택 면: `design/workspace-pastel.css`
- 아이콘 사용 범위와 시스템 색 복귀: `design/workspace-icons.css`
- 최종 버튼 그룹 간격과 목록 축 정렬: `design/workspace-alignment.css`
- 공통 SVG 색 정의: `ui/BrandIconDefinitions.jsx`
- 아이콘 원형/기능 이름 연결: `ui/LucideIcon.jsx`, `ui/icons/lucide-glyphs.json`
- 고정한 원본 버전/해시/라이선스: `ui/icons/lucide-provenance.json`, `vendor/licenses/lucide.txt`
- CX 내부 아이콘의 Desktop 연결: `scripts/desktop-icons-plugin.mjs`
- 승인 계약: `design/reference.json`

브랜드 변경은 주변 화면과 열린 모달을 함께 확인한다. 넓은/좁은 창, 200% 글자, 키보드와 강제 색상 설정을 포함한다. 로컬 합성 화면 검증은 Windows 설치나 실계정/실자료 검증과 구분한다.
