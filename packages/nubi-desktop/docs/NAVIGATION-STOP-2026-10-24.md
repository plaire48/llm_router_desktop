# 작업을 종료하고 프로젝트 이동

실행 중인 터미널이 있으면 renderer의 `changeProject`가 바로 `project_busy`를 던져 “진행 중인 작업을 마친 뒤 프로젝트를 바꿔 주세요.”를 표시했다. 사용자 프로젝트 이동은 이 거절 대신 현재 AI 실행과 명령/PTY의 취소를 요청하고 종료를 확인한 뒤 이어서 이동한다. 같은 이동의 중복 클릭은 새 요청을 만들지 않는다.

대상은 기존 worker의 폴더/Git 정규화로 먼저 확인한다. 선택 창 취소, 없는 대상과 현재 프로젝트의 하위 폴더 선택은 기존 실행을 취소하지 않는다. 기존 파일/Wiki 초안 보호도 유지한다. 폴더/ZIP/Git 열기, 저장된 프로젝트 선택과 개인 대화 공간 전환이 같은 host 경로를 쓴다.

현재 프로젝트의 모든 실행 중인 대화와 확인 대기, 원래 명령의 시작 준비/실행을 기존 `stopAgent`/`Processes.stop`으로 취소한다. PTY도 같은 프로젝트에 속한 세션만 닫고 shell의 실제 exit까지 기다린다. 실행기가 명령을 종료하는 동안 AI가 계속 실행되지 않도록 두 취소를 함께 요청한다. 다른 프로젝트의 PTY/서비스, 메일과 Wiki의 독립 백그라운드 큐, 인증 저장/로그인 변경 보호는 그대로 유지한다.

취소 중 새 모델/명령/터미널 시작을 차단한다. 시작 전 자료 검증이 늦게 끝나도 이전 이동 세대의 요청은 실행되지 않는다. 취소 뒤 늦은 답변을 발행하거나 기존 승인/쓰기/명령을 재실행하지 않는다. 원래 서비스와 저장소를 닫거나 경로를 바꾸지 않고 기록/완료한 변경/미확정 영수증을 유지한다. 취소가 이미 완료한 변경을 되돌리는 것은 아니다.

진행 화면은 실제 중지 요청과 종료 후의 불러오기/저장/화면 준비를 표시한다. 15초 안에 종료 확인이 오지 않으면 확인 중임을 알리고 현재 프로젝트와 원래 기록을 유지한다. 실제 종료까지 신규 실행 차단을 유지하며 시간 초과만으로 성공 처리하거나 강제로 저장소를 닫지 않는다.

## 검증

- 수정 전 Node 검사에서 자동 이동 뒤 기존 대화/명령이 계속 실행되는 것과 프로젝트별 terminal 종료 경로 부재를 재현했다. 이후 늦은 자료 검증이 새 실행을 시작하는 경우도 별도로 실패를 확인하고 이동 세대 검사로 막았다.
- 최종 관련 Node 검사 49개 통과. 복수 대화와 질문 취소, 실제 명령의 종료 영수증, 종료 미확정 때 실행 차단 유지, 늦은 모델 답변 폐기, 대상 확인과 같은 프로젝트의 무중지, 프로젝트별 PTY/준비 중 세션 정리, 기존 입력/편집 후 검사를 포함한다.
- `npm test` 전체 2,929개 중 2,727개 통과, 기존 비활성 워크플로우 등 202개 생략, 실패 0. 이 실행 중간에 host 중지 단계 경로가 추가됐고 해당 검사도 포함되어 통과했다. 이후 폴더/Git 정규화 사전 확인을 더한 최종 소스는 위 49개 관련 검사와 빌드/Electron으로 확인했으며 마지막 추가 검사를 전체 2,929개에 소급하지 않는다.
- `check-navigation-stop.mjs` 실제 macOS Electron/PTY 검사 3개 흐름 통과. 열린 모델 HTTP 요청과 Node child를 확인한 뒤 선택창 취소 시 유지, 저장된 프로젝트 클릭 시 HTTP 취소와 실제 PTY/child 종료 후 이동, 재진입 시 취소된 대화/이전 답변/미전송 초안/원본 파일 보존을 확인했다. 마지막 격리 실행은 이동과 전환 화면 종료까지 353ms였으며 Windows 체감 성능 수치가 아니다.
- `check-project-direct-navigation.mjs`의 3회 왕복, Wiki 없는 폴더 열기, 대상 폴더가 사라졌을 때 기존 대화와 초안 유지 검사도 통과했다.
- `npm run build` 통과. 기존 Windows Bash CJS import.meta 경고와 PowerShell 부재에 따른 선택 Office 파서 생략은 동일하다.

Electron의 실행 시작은 기존 host RPC를 사용하고 이동/취소/재진입과 PTY 입력은 실제 UI로 검증했다. 합성 compatible 제공자의 인증 보관 경고가 캡처에 남아 있으며 로그인 유지/실서비스/모델 품질을 검증한 것은 아니다. 초기 폼 전송 시 모델 요청이 관찰되지 않은 검사와 선택 창 취소 후 원래 모달로 돌아오는 경로 보정 기록도 보존했다. 최종 이동 검사는 실제 진행 중 HTTP 요청을 선행 조건으로 확인한다.

실행/수정 전 실패와 실제 화면 자료는 `verification/navigation-stop-2026-10-24/`에 보관한다. 소스 main 반영, CI, Windows/Office/삼성/설치판 검증은 별도다.
