# Wave 2 Task 4 산출물 카드

기준은 현재 1.2.10 작업 폴더와 Wave 2 설계 A3다. Task 3 이후 변경을 덧붙였으며 공용 런타임과 평가 과제는 고치지 않았다. 로컬 구현과 전체 게이트를 완료한 기록이다.

## 적용

- `send_file`로 실행이 만든 프로젝트 파일이나 같은 작업/실행에 바인딩된 호스트 캡처를 카드로 전달한다. 실행당 5개이며 다른 실행의 카드는 유지한다.
- 실제 파일 크기와 종류, 짧은 캡션만 저장한다. 캡처 바이트는 기존 호스트 저장소에 남고 대화에는 참조만 저장한다. 외부 경로, 보호 경로, 경로를 벗어나는 심볼릭 링크, 다른 작업/실행의 캡처는 거부한다.
- 해당 실행의 마지막 답 아래에 아이콘, 파일명, 크기, 캡션을 표시한다. 질문과 후속 사용자 메시지 밑에 중복하지 않는다. 입력 첨부와 기존 변경 목록은 유지한다.
- 이미지/캡처는 기존 오른쪽 미리보기, 텍스트는 편집기, PDF/Office는 기존 문서 읽기로 연결한다. 호스트 캡처는 저장된 카드 ID로 다시 조회하고 바인딩을 확인한다.
- 긴 파일명 줄바꿈과 공통 디자인 토큰을 사용한다. 읽기 전용 미리보기의 경로 표시도 실제 파일명을 사용하도록 바로잡았다.
- 새 도구를 더한 뒤 6,000 토큰 예산을 넘겨, Desktop 전체 도구 목록의 중복 설명을 공통 규칙으로 옮겼다. 공유 정의와 매개변수 계약은 유지하고 lean 설명은 바꾸지 않았다.

## 검증과 최초 실패

1. 모듈 누락과 산출물 카드 미표시를 각각 먼저 재현했다.
2. 첫 집중 검사에서 도구의 기본 required가 path/captureId를 모두 요구했다. 둘은 선택 매개변수로 노출하고 런타임에서 정확히 하나만 받도록 수정했다. 같은 검사에서 도구 스키마 6,100 토큰 초과를 확인하고 공통 규칙으로 옮겼다.
3. 집중 시험 16개 통과. 파일 범위, 크기와 종류, 링크 이탈, 동시 호출의 실행별 한도, 캡처 바인딩, 실제 에이전트 도구 저장, lean 도구와 스키마 예산을 포함한다.
4. 1280/440 Chrome 합성 화면 검사 통과. 처음 발견한 긴 제목 넘침을 보정했고 두 화면을 직접 확인했다. 카드 위치, 키보드 열기와 기존 챕터/보관 흐름도 검사했다.
5. 빌드한 macOS Electron에서 저장된 카드 5개를 눌러 프로젝트 이미지, 호스트 캡처, 텍스트, PDF, Word를 열고 새로고침 후 보존을 확인했다. 첫 검사는 이전 이미지가 남은 비동기 전환, Monaco의 NBSP, Word iframe 외부 조회 때문에 실패했다. 실제 새 대상이 표시될 때까지 기다리고 올바른 iframe 안에서 확인하도록 검사만 보정했다. 최종 산출물 Electron 검사는 전체 게이트에도 추가했다.
6. 첫 전체 게이트: 전체 1,967개 중 통과 1,766, 실패 1, 제외 200. 기존 `wiki-steering` 검사가 축약한 `wiki_query` 규칙에서 종합 분석의 `ask_openwiki` 연결 안내 누락을 잡았다. 검사 조건은 유지하고 규칙을 복원했다. 위키 회귀를 더한 집중 시험 29/29 통과. 재실행 단위 시험은 전체 1,967개, 통과 1,767, 실패 0, 플랫폼/기능 조건 제외 200이다. 최종 `npm run test:gates`는 종료 코드 0이다. 디자인, Chrome 화면, 빌드, macOS Electron, 117개 전체 화면, 추가 QA 4개와 산출물 카드 Electron 검사까지 통과했다. 게이트 전후 소스/검사 15개 해시도 일치했다.
