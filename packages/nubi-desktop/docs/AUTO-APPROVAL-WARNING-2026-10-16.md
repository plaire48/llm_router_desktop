# 자동 허용 전 안내

승인 방식에서 `파일 자동 반영` 또는 `파일과 명령 자동`을 선택하면 공통 확인 모달을 먼저 연다. `자동 허용`을 누른 경우에만 기존 `setApprovalMode`를 호출한다. 취소, 닫기와 Escape는 기존 설정을 유지하고 입력창의 승인 방식 버튼으로 초점을 돌린다. `매번 확인`으로 돌아가는 동작에는 추가 확인이 없다.

## 안내 내용

- 파일 모드는 확인 없이 파일을 반영한다는 점과 작업 손실 가능성, 사전 보관을 안내한다.
- 명령 모드는 프로젝트 검사 명령이 PC에서 실행되며 파일 변경과 외부 통신이 발생할 수 있음을 안내한다. 임의의 모든 명령이 자동 허용된다고 표현하지 않는다.
- 설정은 현재 프로젝트의 다른 대화에도 적용되며 대기 중인 작업이 처리될 수 있음을 안내한다.
- 관리자 명령과 앱 조작의 기존 승인 경계는 유지한다.
- 항상 허용한 명령이 있을 때는 별도 목록에서 허용을 해제해야 한다는 점을 표시한다. `매번 확인`으로 전환하면 기존 허용 목록도 삭제된다고 안내하지 않는다.

## 화면과 상태

주변 화면과 같은 `DeckConfirmation`과 `workspace-dialogs.css`의 공통 색상, 제목, 본문, 여백과 버튼을 사용한다. 핵심 효과를 먼저 강조하고 영향과 복구 방법을 문단으로 나눈다. 초기 초점은 취소에 두며 확인의 중복 호출을 방지한다. 프로젝트가 바뀌면 미확정 선택은 폐기한다.

후속 가독성 요청으로 기본 화면에는 자동 반영/실행의 효과, 위험, 현재 프로젝트의 모든 대화와 대기 작업 적용 범위, 관리자 명령/앱 조작의 확인 유지까지만 표시한다. 설정 복귀 방법, 검사 명령의 범위와 기존 항상 허용 목록의 해제 방법은 공통 `DeckDisclosure`의 `설정 변경과 허용 범위`에 둔다. 기본은 접힘이며 글자 확대에서 펼친 마지막 문장까지 스크롤로 접근할 수 있다. 확인 전 저장 금지와 기존 허용 범위는 유지한다.

좁은 440px 창과 기본 글자 200%에서 제목과 버튼을 유지하고 본문만 스크롤한다. 공통 키트의 직접 자식 문단에 적용된 고정 줄 간격을 이 모달에서 상대 줄 간격으로 바꾸어 확대 시 줄 겹침을 막는다.

## 검증 범위

`test:shared-ui`는 실제 React 구성 요소와 모의 RPC 경계로 확인 전 저장 차단, 취소, 닫기, Escape, 초점 복원, 두 자동 모드의 확인과 수동 모드 복귀를 검사한다. 기본, 좁은 창과 200% 글자에서 공통 모달 크기, 가로 넘침, 문단 줄 간격과 마지막 안내의 스크롤 접근을 확인한다.

화면 근거는 `verification/ui-auto-approval-warning-*.png`다. 최초 검사에서 자동 모드 선택이 곧바로 RPC를 호출하는 기존 동작이 실패했고, 확대 화면의 문단 줄 겹침도 검출한 뒤 보완했다. 제품 소스와 개발 빌드의 변경이며 Windows 설치판 갱신이나 실제 Windows 실행을 검증한 결과는 아니다.

최종 검사는 UI 38항목 통과, 전체 회귀 1,696개 중 1,500개 통과와 196개 건너뜀, 실패 0개다. `build:electron`과 `design:check`도 통과했다. 전체 회귀에는 개발용 PowerShell 파서 실행이 포함되지만 Windows Office 실행 근거는 아니다. 로그는 `verification/auto-approval-warning-2026-10-16/`에 보관했다.
