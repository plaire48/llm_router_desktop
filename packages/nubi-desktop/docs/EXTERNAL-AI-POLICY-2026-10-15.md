# 외부 AI 연결 보안 안내

ChatGPT와 Claude를 연결할 때 사용자 제공 보안 문구와 정책 링크를 공통 DetailPanel에 표시한다. AI Pro/FabriX에는 표시하지 않는다. 개인정보/민감정보/계정정보 금지, 가명 처리, 기밀 정보의 보안 위규 가능성을 유지한다. 사용자가 제공한 Q1/Q2 문구를 그대로 표시하며 오탈자/띄어쓰기만 정리했다. 테넌트 조건을 임의로 추가하지 않는다. 내부 정책 URL 내용은 이 환경에서 접근 검증하지 못했다.

확인하고 연결을 누른 경우만 기존 제공자 로그인으로 이어진다. 다시 보지 않기는 그때 앱 설정(localStorage)에 저장한다. 취소/닫기/정책 링크 열기는 로그인 또는 설정 저장을 하지 않는다. 정책 링크는 기존 인앱 페이지 열기 경로를 사용한다.

공통 글꼴, 15px 본문, 제목 강조, 20px 모달 곡률, 버튼/여백 토큰을 재사용한다. 1280/440px 실제 렌더링에서 공통 identity 계약, 가로 넘침, 취소, 연결 전 차단과 재진입 시 설정 유지를 검사했다. 제공자는 합성이며 실제 사내 정책/로그인 성공을 검증한 것은 아니다.

사용자 후속 요청: 개인정보 입력 금지와 대화 저장/보안 책임 두 항목을 각각 공통 아이콘과 굵은 제목, 옅은 배경으로 구분했다. 사용자의 재확인 요청에 따라 원래 Q1/Q2 제목과 문장을 복원했다. 배치/아이콘/강조만 적용하며 개인정보 예시/가명 처리/로그 저장/보안 위규 안내의 뜻과 조건을 바꾸지 않는다.
