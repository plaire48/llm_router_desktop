# 누비 Workspace Beta 1.2.0

## 개선

- 위키 화면을 메일 화면과 같은 구조로 바꿨습니다. 문서 목록(검색, 열 정렬과 필터, 페이지), 관계 지도(링크와 앞머리 기반, 분류 색, 연결 수, 관계 강도), 아래 문서(수정, 다시 작성 요청, 원본 열기, 연결된 문서). 앞머리는 본문과 분리해 보여 줍니다.
- 메일 설정은 사내 포털 로그인(추천)과 파일 가져오기 카드 두 장으로 정리했습니다. 최근 수집 시각은 아이콘과 두 줄로 읽기 쉽게 했습니다.
- Claude 잔여 한도를 창 상단 알약으로 보여 주고, 사용량 패널에 창별 남은 비율을 보여 줍니다. 한도는 로그인 직후와 패널을 열 때 자동으로 읽으며, 사용량 패널의 Claude 칸은 ChatGPT 칸과 같은 구조(제목, 새로고침, 창별 막대, 읽은 시각)입니다. 응답마다 실리는 달러 비용은 장부에 기록만 합니다.
- 대화 기억: 사람이 말한 선호와 사실을 이 PC에만 저장하고 다음 대화에 참고합니다. 답변 아래 "기억했어요"와 되돌리기, 설정의 기억 목록과 사용 스위치. 비밀번호와 토큰은 저장하지 않습니다.
- 메일 시간 사실: 메일에서 담당자, 기한, 금액, 상태처럼 바뀌는 사실을 유효 기간과 함께 기록합니다. 메일 위키 문서 아래 "사실 이력", 에이전트 도구 `mail_facts`.
- "프로젝트 자료" 패널을 "위키 설정"으로 바꾸고 사내 메일 행과 파일, 위키 검색 상자를 뺐습니다. 시작 메일 안내와 메일 화면 포털 안내 문장을 줄였습니다.
- 디자인: iOS 느낌으로 테두리를 줄이고 아이콘과 색으로 뜻을 전하며, 화면 전환과 모달 등장을 부드럽게 했습니다. 글꼴과 간격은 CX 토큰으로 통일했습니다.
- 설정에 앱 버전을 마스코트와 함께 굵은 강조색으로 보여 줍니다. 위키의 고립 문서는 글자 대신 빨간 아이콘으로 표시하고, 지도 안 아이콘이 잘리던 문제를 고쳤습니다.
- 메일 검색 조건은 CX 셀렉트와 강조색 아이콘, 적용한 조건 수 배지로 정리했고, 열 필터는 E2E Report 방식(값 검색, 전체 선택과 개수, 적용 중 점)을 따릅니다. 고정한 메일은 책갈피 표시로 보여 줍니다.
- 기억 목록, 사실 이력, 연결된 문서처럼 길어질 수 있는 목록은 한 번에 8~10개만 보여 주고 더 보기로 늘립니다.
- 사내 포털 메일 로그인은 별도 창 대신 앱 안 브라우저 탭에서 진행합니다. SSO 팝업은 같은 탭 묶음 안에서 열리고, 로그인이 확인되면 탭이 자동으로 닫힙니다. 세션은 이전처럼 유지되어 다음 실행 때 조용히 복구합니다.
- 질문 선택지, 스킬 설명, 명령 요약, 메일 미리보기처럼 한 줄로 잘리던 문장은 두 줄까지 보여 줍니다.
- AI Workspace: 탭 아래 반복되던 제목을 없앴습니다. 앱 카드는 ai_workspace에 등록한 아이콘과 설명 원문(줄바꿈 포함)을 그대로 보여 주고, 앱 등록은 ai_workspace 등록 양식과 같은 항목(제목, URL, 내용, 아이콘)을 팝업 없이 화면 안에서 받아 같은 카탈로그에 커밋합니다. Talk 글쓰기도 화면 안 페이지로 바뀌었고, 글과 댓글의 작성자는 사내 GitHub에서 세션으로 읽은 프로필 사진, 이름과 메일 주소, "3일 전" 같은 상대 시간으로 보이며, 이름에 마우스를 올리면 소속과 위치가 담긴 작은 프로필 카드가 뜹니다.
- 대화: 새 질문을 보내도 위로 튀지 않고 아래로 따라가며, 진행 중 기록은 아이콘이 돌고 제목이 숨 쉬어 작업 중임이 보입니다.
- 메일: 폴더 가져오기 상한을 폴더당 20,000개 또는 4 GB, 파일당 50 MB로 올렸습니다. 포털 로그인과 폴더 가져오기 중에도 메일 설정 창이 잠기지 않습니다. 포털 메일함 종류가 "기타"일 때 화면이 깨지던 문제(Unknown icon: folder)를 고쳤습니다.
- 시작 화면과 위키 작성 화면은 홈처럼 워크벤치 그라데이션 위에 놓이고 레일과 사이드바 끝부터 창 끝까지 채웁니다.
- 관계 지도: 프레임이 더 커지고 넓게 보기로 창 높이만큼 펼칠 수 있습니다. 확대, 축소, 전체 보기 버튼은 지도 안에 있고, 휠로 확대하고 왼쪽이나 오른쪽 버튼으로 끌어 이동합니다. 연결 많은 문서 목록은 제목을 두 줄까지 보여 줍니다. 문서가 300개를 넘으면 약한 선과 작은 문서 라벨을 줄여 그립니다.
- AI Workspace 앱과 Talk 탭은 ai_workspace 사이트의 화면 그대로입니다(앱 등록의 링크/파일 탭, 아이콘, 편집자, Talk 편집기와 첨부, 멘션). 사내 GitHub 호출은 앱의 SSO 세션을 쓰는 호스트 프록시를 거칩니다. 웹 검사 화면은 가벼운 자체 화면을 유지합니다.
- 사용량 패널에 claude.ai 사용량 블록이 생겼습니다. 앱 안 브라우저에서 claude.ai에 로그인하면 그 세션으로 사용량 페이지의 값을 읽습니다(세션 밖으로 토큰이나 쿠키를 꺼내지 않음).
- 에이전트가 앱 브라우저에 열린 페이지를 스크린샷으로 찍어 이미지 모델(AI Pro는 Qwen)에게 물어보는 inspect_workspace_page 도구가 생겼습니다. 답은 글로 대화 모델에 돌아갑니다.
- 호스트 요청이 0.4초를 넘으면 툴바 아래 가는 선이 움직이고, 프로젝트 전환 중에는 이전 화면이 흐려집니다. "불러오는 중" 문구는 마스코트와 스피너가 함께 보입니다.
- 터미널 출력에 localhost 주소가 나오면 앱 브라우저에서 열고 안내를 띄웁니다. 대화에서 시작한 서버는 주소와 "앱 브라우저로 열기"를 보여 주고, 실행 중인 셸 출력은 접어 둡니다.
- 메일과 위키 목록 아래에 E2E Report식 페이지 번호(처음, 10쪽 앞뒤, 이전/다음, 1~10)가 붙고, 열 필터의 초기화/적용은 아이콘 버튼입니다. 위키 목록 상한은 3,000개, 120MB입니다.
- 준비안(명령 제안)의 형식 오류는 같은 뜻의 값(목록, 빈 값)을 정리한 뒤 검사해 실행이 멈추는 일을 줄였습니다. AI Pro 목록에서 관리자용 Qwen3-Coder_rag, aipro-fast-model은 숨깁니다. AI Pro와 FabriX도 연결 뒤 같은 음영을 씁니다.
- 작업 계획, 확인한 자료, 명령 상세 사이 여백을 줄이고, 관계 지도의 보조 목록은 접을 수 있습니다.
- 위키 생성의 오류 코드 안내, 중단된 갱신 정리, 커밋하지 않은 변경 반영, 조사 예산, 터미널 한글 입력 복구 등 10-12 이후 품질 개선을 포함합니다.

## 설치와 업데이트

Windows x64 설치파일을 실행하세요. 앱 이름과 저장 경로를 유지해 기존 설치판을 업데이트합니다. 사내 자동 업데이트 배포 방법은 INSTALL-AND-UPDATE-1.2.0.md와 Publish-NubiUpdate.ps1을 참고하세요.

## 범위

Desktop A2A는 지원하지 않습니다. 첨부파일 내용 분석은 1.2.1부터 켭니다(사용자 결정 2026-10-14, 회사 PC의 Office 2016 COM 경로는 실기기 확인 필요). 대화 기억과 메일 시간 사실은 제품 실행기에서만 동작하며 평가와 자동 검사는 이를 끄고 잽니다. GHES/포털 실계정, Claude 실계정의 한도 확인, 실제 Windows 11 사용자 PC의 확인은 자동 검사와 구분합니다. 이 설치파일은 공인 코드서명이 없는 Beta입니다.

## 2026-10-14 (4차) 초기화 전 접근 오류, 메일 위키 품질

- **화면이 비는 오류** `Cannot access … before initialization`: `ui/Workbench.jsx`의 메일 진행 상태 폴링 `useEffect`가 `project` 상태 선언보다 앞에 있어서 난 일시적 사각지대(TDZ) 오류였다. 선언 뒤로 옮겼다. 명령 상세 접기 블록에 남은 `}`도 제거.
- **AI Workspace 포팅 빌드**: `es-module-lexer/js`(asm 빌드)는 `init`을 내보내지 않아 `const init=Promise.resolve()`로 대체.
- **메일 위키 품질**: `docs/MAIL-WIKI-QUALITY-2026-10-14.md` 참조. 인용 답장 제거, thread 열쇠와 헤더 front matter, 같은 thread의 사슬 간선, 근거 있는 사실 추출.
- **위키 라이브러리 상한**: 목록 걷기의 두 바이트 검사를 모두 120MB로.
- **로딩 오버레이**: `nubi-preparing`, `project-wiki-progress`가 `--nubi-chat-surround` 그라데이션으로 뒤 내용을 가린다.
- **아이콘 이름 검사** `scripts/check-icons.mjs`: 화면이 쓰는 모든 `<Icon name>`을 실제로 렌더해 없는 이름을 빌드 전에 잡는다(`folder`, `terminal` 사례). `build:electron` 앞에 `check:tdz`, `check:icons`가 돈다.
- **알림 센터** (`ui/notice-store.js`, `ui/NotificationCenter.jsx`): 레일의 종 아이콘에 미확인 점. 목록에는 토스트, Windows 결정 알림, 호스트 이벤트가 쌓이고 각 알림의 동작(열기)이 남는다. 결정 요청은 앱 안 토스트에도 '열기' 버튼으로 나온다. 토스트 유지 시간은 3초(사용자 결정, 30초에서 되돌림). 토스트 안에서 객관식·입력까지 하는 HITL은 다음 단계(설계 필요: ask_user 질문 봉투를 토스트에 싣고 답을 대화로 돌려보내는 통로).
- **너비**: `--nubi-chat-width: clamp(700px, 94cqi, 1480px)`, 스킬 화면 1200px. 컨테이너 단위라 사이드바·보조 영역이 생기면 자동으로 줄어든다.
- **내장 브라우저 너비 조절**: 네이티브 뷰가 손잡이 폭만큼 왼쪽을 비워 두고, 끄는 동안(`data-pane-resizing`) 뷰를 숨긴다. 3분할 복귀 아이콘은 `chevronsRight`.
- **내장 브라우저 클립보드**: 세션이 `clipboard-sanitized-write`만 허용(회사 AI Workspace 로그인 화면의 코드 복사).
- **검사 갱신**: 메일 가져오기 단위 검사는 2 GiB 상한 기준, 메일 UI 검사는 로그인 중 대화상자 닫기가 로그인을 유지하는 동작 기준.
- **마스코트**: 자는 상태(`data-mood="sleep"`)에서 호버하면 `nubi-bird-startle`(점프, 눈 뜸)을 한 번 하고 인사 춤으로 이어진다(사용자 요청 2026-10-14).
- **첨부 읽기 켬** (`runtime/beta-features.mjs` `mailAttachmentReading:true`, 사용자 결정 2026-10-14): PDF, DOCX, PPTX, XLSX, 텍스트 첨부를 메일 본문과 함께 읽어 요약·사실·검색에 쓴다. 정책 검사 `tests/mail-beta-scope.test.mjs`는 게이트가 열렸는지와 다운로드 바이트 일치를 본다. HWP와 이미지 첨부는 아직 읽지 않는다(§8 검토).
- **첨부 읽기 순서** (사용자 결정 2026-10-14): 파서 먼저, Office 2016 COM은 파서가 못 읽는 바이트(NASCA 등)에만. `docs/OFFICE-ATTACHMENT-READING-2026-10-05.md` 머리말 참조.
- **이미지 첨부 읽기** (`runtime/mail-attachment-image.mjs`, 사용자 요청 2026-10-14): PNG, JPEG, GIF, WebP, BMP 첨부는 연결된 이미지 입력 모델(화면 캡처 분석과 같은 경로, AI Pro는 Qwen)이 글과 내용을 한국어로 적어 첨부 본문이 된다. 6MB 초과는 `document_limit`, 이미지 모델이 없으면 `document_vision_unavailable`로 표시. 이미지 글은 자료이지 지시가 아니라는 안내를 프롬프트에 둔다.
- **메일 위키 암호화 저장** (사용자 결정 2026-10-14, 메일 자료만): `runtime/mail-wiki-vault.mjs`. 키는 연결 보관소(`safeStorage`)의 `mail-wiki-key`, 페이지는 `.md.enc`(AES-256-GCM). 실행 중 세션 사본(`session-wiki/`, 사용자 전용)을 읽고 종료·다음 시작 때 지운다. 기존 평문은 첫 실행 때 암호화 후 삭제. `safeStorage`를 못 쓰는 PC는 `encryption.state='unavailable'`(평문 유지). 메일 설정에 자물쇠 표시. 다음: 메일 원본과 검색 색인. 설계 `docs/WIKI-ENCRYPTION-2026-10-14.md`.
- **설치판 보호와 설치 속도** (사용자 결정 2026-10-14): 실행기·메인 번들 최소화(`NUBI_MINIFY=0`으로 해제), Electron 퓨즈(NODE_OPTIONS 차단, asar 무결성, asar만 로드, runAsNode 유지, --inspect는 CI 검사가 붙어야 해서 허용), 설치 파일 `compression: store`(복사 설치). `docs/PACKAGING-SECURITY-2026-10-14.md` 적용 절.
- **문의 화면 포팅** (사용자 요청 2026-10-14): ai_workspace의 서비스 데스크(목록, 작성, 담당자·수신자 지정, 완료 처리, 관리자 설정) 22개 파일을 `ui/ai-workspace/`에 추가. AI Workspace 페이지의 '문의' 구역과 레일 맨 아래 문의 아이콘. 데이터는 같은 ai_workspace 저장소 Issues(GHES 프록시 허용 경로 그대로). 첨부 저장소(`VITE_SERVICE_DESK_ATTACHMENT_*`)는 비어 있어 첨부 업로드는 꺼짐. 실제 문의 왕복은 회사 PC에서 확인.
