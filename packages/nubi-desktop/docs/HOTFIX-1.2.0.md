# 누비 Workspace Beta 1.2.0

## 개선

- 위키 화면을 메일 화면과 같은 구조로 바꿨습니다. 문서 목록(검색, 열 정렬과 필터, 페이지), 관계 지도(링크와 앞머리 기반, 분류 색, 연결 수, 관계 강도), 아래 문서(수정, 다시 작성 요청, 원본 열기, 연결된 문서). 앞머리는 본문과 분리해 보여 줍니다.
- 메일 설정은 사내 포털 로그인(추천)과 파일 가져오기 카드 두 장으로 정리했습니다. 최근 수집 시각은 아이콘과 두 줄로 읽기 쉽게 했습니다.
- Claude 잔여 한도를 창 상단 알약으로 보여 주고, 사용량 패널에 창별 남은 비율을 보여 줍니다. 한도는 로그인 직후와 패널을 열 때 자동으로 읽으며, 사용량 패널의 Claude 칸은 ChatGPT 칸과 같은 구조(제목, 새로고침, 창별 막대, 읽은 시각)입니다. 응답마다 실리는 달러 비용은 장부에 기록만 합니다.
- 대화 기억: 사람이 말한 선호와 사실을 이 PC에만 저장하고 다음 대화에 참고합니다. 답변 아래 "기억했어요"와 되돌리기, 설정의 기억 목록과 사용 스위치. 비밀번호와 토큰은 저장하지 않습니다.
- 메일 시간 사실: 메일에서 담당자, 기한, 금액, 상태처럼 바뀌는 사실을 유효 기간과 함께 기록합니다. 메일 위키 문서 아래 "사실 이력", 에이전트 도구 `mail_facts`.
- "프로젝트 자료" 패널을 "위키 설정"으로 바꾸고 사내 메일 행과 파일, 위키 검색 상자를 뺐습니다. 시작 메일 안내와 메일 화면 포털 안내 문장을 줄였습니다.
- 디자인: iOS 느낌으로 테두리를 줄이고 아이콘과 색으로 뜻을 전하며, 화면 전환과 모달 등장을 부드럽게 했습니다. 글꼴과 간격은 CX 토큰으로 통일했습니다.
- 설정에 앱 버전을 마스코트와 함께 굵은 강조색으로 보여 줍니다. 위키의 고립 문서는 글자 대신 빨간 아이콘으로 표시하고, 지도 안 아이콘이 잘리던 문제를 고쳤습니다.
- 메일 검색 조건은 CX 셀렉트와 강조색 아이콘, 적용한 조건 수 배지로 정리했고, 열 필터는 E2E Report 방식(값 검색, 전체 선택과 개수, 적용 중 점)을 따릅니다. 고정한 메일은 책갈피 표시로 보여 줍니다.
- 기억 목록, 사실 이력, 연결된 문서처럼 길어질 수 있는 목록은 한 번에 8~10개만 보여 주고 더 보기로 늘립니다.
- 사내 포털 메일 로그인은 별도 창 대신 앱 안 브라우저 탭에서 진행합니다. SSO 팝업은 같은 탭 묶음 안에서 열리고, 로그인이 확인되면 탭이 자동으로 닫힙니다. 세션은 이전처럼 유지되어 다음 실행 때 조용히 복구합니다.
- 질문 선택지, 스킬 설명, 명령 요약, 메일 미리보기처럼 한 줄로 잘리던 문장은 두 줄까지 보여 줍니다.
- AI Workspace: 탭 아래 반복되던 제목을 없앴습니다. 앱 카드는 ai_workspace에 등록한 아이콘과 설명 원문(줄바꿈 포함)을 그대로 보여 주고, 앱 등록은 ai_workspace 등록 양식과 같은 항목(제목, URL, 내용, 아이콘)을 팝업 없이 화면 안에서 받아 같은 카탈로그에 커밋합니다. Talk 글쓰기도 화면 안 페이지로 바뀌었고, 글과 댓글의 작성자는 사내 GitHub에서 세션으로 읽은 프로필 사진, 이름과 메일 주소, "3일 전" 같은 상대 시간으로 보이며, 이름에 마우스를 올리면 소속과 위치가 담긴 작은 프로필 카드가 뜹니다.
- 대화: 새 질문을 보내도 위로 튀지 않고 아래로 따라가며, 진행 중 기록은 아이콘이 돌고 제목이 숨 쉬어 작업 중임이 보입니다.
- 메일: 폴더 가져오기 상한을 폴더당 20,000개 또는 4 GB, 파일당 50 MB로 올렸습니다. 포털 로그인과 폴더 가져오기 중에도 메일 설정 창이 잠기지 않습니다. 포털 메일함 종류가 "기타"일 때 화면이 깨지던 문제(Unknown icon: folder)를 고쳤습니다.
- 시작 화면과 위키 작성 화면은 홈처럼 워크벤치 그라데이션 위에 놓이고 레일과 사이드바 끝부터 창 끝까지 채웁니다.
- 관계 지도: 프레임이 더 커지고 넓게 보기로 창 높이만큼 펼칠 수 있습니다. 확대, 축소, 전체 보기 버튼은 지도 안에 있고, 휠로 확대하고 왼쪽이나 오른쪽 버튼으로 끌어 이동합니다. 연결 많은 문서 목록은 제목을 두 줄까지 보여 줍니다. 문서가 300개를 넘으면 약한 선과 작은 문서 라벨을 줄여 그립니다.
- 위키 생성의 오류 코드 안내, 중단된 갱신 정리, 커밋하지 않은 변경 반영, 조사 예산, 터미널 한글 입력 복구 등 10-12 이후 품질 개선을 포함합니다.

## 설치와 업데이트

Windows x64 설치파일을 실행하세요. 앱 이름과 저장 경로를 유지해 기존 설치판을 업데이트합니다. 사내 자동 업데이트 배포 방법은 INSTALL-AND-UPDATE-1.2.0.md와 Publish-NubiUpdate.ps1을 참고하세요.

## 범위

Beta의 첨부파일 내용 분석과 Desktop A2A는 지원하지 않습니다. 대화 기억과 메일 시간 사실은 제품 실행기에서만 동작하며 평가와 자동 검사는 이를 끄고 잽니다. GHES/포털 실계정, Claude 실계정의 한도 확인, 실제 Windows 11 사용자 PC의 확인은 자동 검사와 구분합니다. 이 설치파일은 공인 코드서명이 없는 Beta입니다.
