# 공통 화면/모달/아이콘의 누비 브랜딩

사용자의 목적은 누비의 브랜딩을 한 기준으로 관리하는 것이다. 기존 승인한 여섯 원색과 새 캐릭터는 유지하고, 화면/모달/아이콘에 사용하는 역할과 흰색 혼합 비율을 중앙화했다. 기준과 유지 위치는 [누비 브랜드 관리 기준](NUBI-BRAND-GUIDE.md)에 있다.

## 변경

- `design/brand/nubi-brand.css`: 원색, 잉크, 표면과 역할별 강도. 주요 동작/아이콘 타일 40%, 선택 20%, 제목/외곽 8%의 브랜드 색을 흰색과 섞는다. 파생 그라데이션은 CSS 변수와 color-mix를 참조하므로 원색을 화면마다 복사하지 않는다.
- 모달은 제목부만 거의 흰 브랜드 면을 사용하고, 본문/입력/하단은 흰색으로 유지한다. 공통 모달의 간격과 서체/동작은 그대로다.
- 상단/메뉴 레일, 선택 대화/메뉴/필터/카탈로그와 프로젝트 카드에서 같은 색 역할을 재사용한다.
- 일반 기능 아이콘은 한 개의 정적 SVG 그라데이션 정의를 참조한다. 선은 읽을 수 있는 진한 청록/블루/라벤더이고 바탕 타일만 파스텔이다. 아이콘의 기존 모양/크기/선 굵기/접근성 이름과 툴팁을 유지한다. 닫기/삭제/확인/경고와 제공자 로고/모델·추론에는 일반 아이콘 색을 강제하지 않는다.
- 프로젝트 화살표의 기존 hover는 짙은 블루 면에 흰 선을 쓰던 규칙이었다. 새 잉크와 함께 어둡게 보일 수 있어 hover도 밝은 타일로 고정했다. 선택 메뉴의 hover/focus도 같은 밝은 면을 유지한다.
- 새 반복 모션, 그래픽 엔진과 의존성은 추가하지 않았다. body 포털은 같은 SVG 정의를 참조하고 강제 색상에서는 시스템 색을 사용한다.

`workspace-density.css`의 사용자/Claude 수정과 캐릭터/제공자/상태 색은 유지한다. 새 CSS :has 선택자는 추가하지 않았다.

## 검증 범위

전체 Electron 빌드와 identity 검사 통과. identity 검사는 승인 원색/파생색을 대조하며 일반 글자 4.5:1, 기능 아이콘 3:1의 보수적인 색 경계도 확인한다. 브랜드 파일은 compile의 source-inputs에 포함된다.

모션/타이틀바 관련 단위 검사 20개 통과. 공통 화면 117개는 넓은/좁은 창과 200% 글자, 모달/위키/메일의 합성 상태를 실제 Electron에서 렌더링했다. `verification/common-brand-surfaces-2026-10-23/`에 기록한다. 이 실행 뒤 화살표/선택 메뉴의 hover 면을 보완하고 해당 상태를 실제 호스트에서 별도 확인했다.

실제 호스트의 브랜딩 검사는 합성 제공자 상태와 격리 저장소를 사용한다. 한 개의 SVG 정의와 body 포털의 참조, 밝은 모달 제목/흰 본문, hover 상태, 강제 색상/모션 감소/창 숨김/좁은 창, 초안 보존을 포함한다. 성공 화면의 공통 디자인 규칙, 모달 대비와 양방향 Tab 순환을 검사한다.

실계정/실자료/실모델 호출, Windows 설치/업데이트/재실행과 Windows에서 보고된 전반적 끊김 해소는 검증하지 않았다. 전체 릴리스 게이트와 후보 업로드는 Claude 소유이며 푸시/머지를 하지 않았다.

호버 보완 후 실제 호스트 11개 검사와 제공자/모델·추론 회귀 7개를 통과했다. 프로젝트 화살표와 선택 위키 메뉴에 실제로 마우스를 올리고 밝은 그라데이션 면과 아이콘을 확인했다. 캡처는 `verification/calm-liquid-2026-10-23/connection.png`, `wiki.png`에 있다.
