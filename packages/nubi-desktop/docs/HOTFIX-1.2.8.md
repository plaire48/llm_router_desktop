# 누비 Workspace Beta 1.2.8

2026-10-16 수정 빌드는 기존 1.2.8 이후의 메일, 사내 브라우저, 계정 표시, 위키 내용 검토와 작업 복구 변경을 포함합니다. 기존 1.2.8과는 Release의 빌드 번호와 SHA-256으로 구분합니다. 1.2.7의 변경은 `docs/HOTFIX-1.2.7.md`에 있습니다.

## 이번 수정 빌드

- **코드 위키의 내용 정확도**: 코드 구조와 호출 관계를 작성 문맥에 제공하고, 페이지 전체와 Claims를 원문에 대조하는 별도 검토를 추가했습니다. 극단값, 실패 이전의 상태 변경, 과거 설명과 현재 구현, 재시도의 롤백/중복 실행 한계를 구분합니다. 원문과 모순되는 내용이나 불확실한 판정은 수정 대상으로 돌려보냅니다. 모델 검토이므로 모든 사실 오류의 제거를 보장하지는 않습니다.
- **위키 대기 줄이기**: 정상 판정은 공통 근거로 묶고, 반복 설명과 불필요한 전체 문서 재출력을 줄였습니다. 정확도와 시간은 같은 고정 예제로 재평가하며, 실제 측정 결과는 이번 릴리즈의 검증 보고서에 구분합니다.
- **메일과 결재**: 본문 HTML의 첨부 오인식, 문서 형식과 읽기 실패 안내, 원문/첨부 수집 설정, 데이터 초기화와 결재 단계별 진단을 보완했습니다. 사내 세션 만료 팝업은 사용자가 확인한 뒤 로그인으로 이어가도록 안내합니다.
- **사내 웹과 계정**: 새 탭 SAML 이동의 POST/opener/session 유지와 실패 단계 안내, GHES 프로필 상태 이모지의 이름 옆 표시를 보완했습니다. 사내 실서비스 성공은 별도 확인 대상입니다.
- **작업 검증과 시작 복원**: 과거 테스트 성공으로 최근 실패를 덮지 않으며, 승인한 수정 명령의 결과를 원래 검증에 연결합니다. 같은 프로젝트의 동시 시작 복원은 한 번만 실행하고 결과를 공유합니다.
- **공통 화면 정리**: 메일 설정, 결재 목록, 원문 충돌 안내와 위키 진행의 폰트, 아이콘, 간격을 기존 공통 토큰에 맞췄습니다.

이번 배포는 Windows x64의 서명되지 않은 Beta입니다. GitHub Windows 설치 검사, Mac 화면 검사, 합성 코드의 실모델 평가와 사내 SSO/Office 2016/NASCA 실사용은 서로 다른 검증 범위입니다. 사용자 요청으로 취소한 추가 메일 보안 변경은 포함하지 않습니다.

## 이전 1.2.8에 포함된 수정

- **메일 암호화가 조용히 꺼지던 문제**: 메인 프로세스의 작업자 비밀 게이트가 AI 공급자 키만 허용해 메일 위키 키, 원문 키, MCP 서버 비밀이 모두 막혔습니다. 위키 암호화는 "꺼짐"으로 남고 원문 수집은 "암호화 키를 열지 못했어요"로 멈췄습니다. 공급자 키, 메일 키 2개, MCP 비밀을 허용하고 회사 GitHub 자격은 계속 메인 전용입니다.
- **명령 기록이 접혀 출력이 숨던 문제**: 실행한 명령은 대화 제자리에 열린 채로 남고 실행 상태, 종료 코드, 중지 단추를 결과 줄에 보입니다. 셸 이름은 설정의 프로필 이름으로 표시합니다.
- **스킬 "수정"이 편집기를 열지 않던 문제**: Markdown 미리보기 대신 원문 편집기로 엽니다. 미리보기와 원문 편집 전환 단추는 그대로입니다.
- **승인한 MCP 호출이 중단되면 반복 보고되던 문제**: 예외나 중단으로 끝난 승인 호출을 "미확인"으로 한 번만 기록하고 다시 실행하지 않습니다.
- **메일 오류 안내 세분화**: 암호화 원문(96MiB + 32바이트) 읽기 상한, 키 분실과 키 열기 실패 구분, 저장 위치 권한 오류 구분, 가져오기 중 대상 폴더 쓰기 실패는 파일별 "읽기 권한" 대신 한 번의 저장 오류로 안내, 저장 위치 확인 전에 암호화 키를 먼저 열어 문제를 바로 보임, 저장 위치 이동 뒤 이전 폴더에 남은 항목 수 안내, 첨부 읽기 실패에 금고 오류 코드 유지, 다운로드 검증 실패 시 잘못 저장된 파일 삭제, 이동 중 설정 잠금 상태 표시.
- **캡처 저장 실패 기록**: 첨부 캡처를 저장하지 못하면 작업 기록에 사유를 남깁니다.

## 검사 갱신

- 위키 진행 추정은 처리량 표본이 쌓이기 전 "처리 속도 확인 중"으로 보입니다.
- 변경한 파일 목록은 모달 대신 제자리 접기입니다.
- 메일 잠금 배지 이름은 "메일 원문과 첨부 암호화 저장"입니다.
- 작업자 비밀 범위 단위 시험을 추가했습니다.
