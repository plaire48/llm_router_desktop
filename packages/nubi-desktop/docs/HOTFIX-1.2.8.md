# 누비 Workspace Beta 1.2.8

1.2.7 뒤 Codex가 이어 간 작업(메일 원문 암호화, 저장 위치 이동, 문서 미리보기, 위키 진행 추정)을 품질 검증하고 결함을 고친 빌드입니다. 1.2.7의 변경은 `docs/HOTFIX-1.2.7.md`에 있습니다.

## 고친 것

- **메일 암호화가 조용히 꺼지던 문제**: 메인 프로세스의 작업자 비밀 게이트가 AI 공급자 키만 허용해 메일 위키 키, 원문 키, MCP 서버 비밀이 모두 막혔습니다. 위키 암호화는 "꺼짐"으로 남고 원문 수집은 "암호화 키를 열지 못했어요"로 멈췄습니다. 공급자 키, 메일 키 2개, MCP 비밀을 허용하고 회사 GitHub 자격은 계속 메인 전용입니다.
- **명령 기록이 접혀 출력이 숨던 문제**: 실행한 명령은 대화 제자리에 열린 채로 남고 실행 상태, 종료 코드, 중지 단추를 결과 줄에 보입니다. 셸 이름은 설정의 프로필 이름으로 표시합니다.
- **스킬 "수정"이 편집기를 열지 않던 문제**: Markdown 미리보기 대신 원문 편집기로 엽니다. 미리보기와 원문 편집 전환 단추는 그대로입니다.
- **승인한 MCP 호출이 중단되면 반복 보고되던 문제**: 예외나 중단으로 끝난 승인 호출을 "미확인"으로 한 번만 기록하고 다시 실행하지 않습니다.
- **메일 오류 안내 세분화**: 암호화 원문(96MiB + 32바이트) 읽기 상한, 키 분실과 키 열기 실패 구분, 저장 위치 권한 오류 구분, 가져오기 중 대상 폴더 쓰기 실패는 파일별 "읽기 권한" 대신 한 번의 저장 오류로 안내, 저장 위치 확인 전에 암호화 키를 먼저 열어 문제를 바로 보임, 저장 위치 이동 뒤 이전 폴더에 남은 항목 수 안내, 첨부 읽기 실패에 금고 오류 코드 유지, 다운로드 검증 실패 시 잘못 저장된 파일 삭제, 이동 중 설정 잠금 상태 표시.
- **캡처 저장 실패 기록**: 첨부 캡처를 저장하지 못하면 작업 기록에 사유를 남깁니다.

## 검사 갱신

- 위키 진행 추정은 처리량 표본이 쌓이기 전 "처리 속도 확인 중"으로 보입니다.
- 변경한 파일 목록은 모달 대신 제자리 접기입니다.
- 메일 잠금 배지 이름은 "메일 원문과 첨부 암호화 저장"입니다.
- 작업자 비밀 범위 단위 시험을 추가했습니다.
