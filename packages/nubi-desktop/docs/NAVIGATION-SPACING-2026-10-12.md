# 메뉴 폭과 상단 경계 정렬

사용자가 느끼는 좌우 빈 공간을 줄이기 위해 아이콘 rail을 88px에서 72px로, 기본 대화 목록을 300px에서 280px로, 기본 오른쪽 패널을 420px에서 380px로 줄였다. 대화 목록 최소값은 264px, 오른쪽 최소값은 320px다. 사용자가 조절해 보관한 유효 너비는 유지한다. 아이콘 24px, 버튼 48px와 세로 간격 20px는 보존하고 rail의 가로 패딩만 줄인다. 좌측 목록과 우측 패널 헤더의 가로 패딩은 12px로 맞춘다.

기존 ResizeObserver와 CSS 토큰을 재사용하며 새 의존성을 추가하지 않았다. 상단 로고 영역은 펼쳐진 사이드바의 실제 오른쪽 좌표를 읽어 구분선을 맞춘다. 드래그/키보드 크기 조절, 창 크기 변경을 따라가며 사이드바가 닫히거나 좁은 창에서 겹쳐 열릴 때는 자연 너비로 돌아간다. AI Workspace는 rail의 마지막 아이콘이며 margin-top:auto로 맨 아래를 유지한다.

격리된 Electron production 컴포넌트에서 넓은 창, 크기 조절, 사이드바 접기, 960/760/440px와 글자 200%의 7개 검사를 통과했다. 구분선과 실제 경계의 오차 1px 미만, rail 72px, AI Workspace 하단 배치, 버튼 잘림과 줄바꿈을 확인했다. 디자인 검사와 Electron 빌드 및 격리된 native shell의 파일/저장/Git/터미널/브라우저 등 14개 동작도 통과했다. 실제 로그인된 사용자 앱은 Mac 잠금으로 표시 확인하지 못했다.
