# 누비 Workspace Beta 1.2.2

1.2.1 공개 뒤 같은 날 받은 피드백을 반영한 빌드입니다. 작업 기록 전체는 `docs/HOTFIX-1.2.0.md`에 이어서 적혀 있습니다.

## 1.2.2에서 바뀐 것

- **고친 것**: `WorkspaceAction is not defined`(관리 메뉴 import 누락), 메일 화면의 `Unknown icon: folder`(메일 종류 표), 사내 포털 주소 http와 페이지 주입 주소, 상단 아이콘 한 줄·간격·호버 통일, 설정 머리글 정렬, 진행 중 표시를 원형 스피너로, 위키 설정 여백, source_search 인자 정규화(Sonnet 5.5).
- **새로 들어간 것**: 문의 전용 페이지, 프로필 사진의 GHES 상태 이모지, Talk 카테고리 이모지, 알림 종을 우측 상단으로(앱 안 결정 토스트 없음, Windows 알림에 선택지·답변 입력), 회사 세션 통합(포털·GHES 로그인 한 번), Claude 잔여 한도를 Claude Code 로그인으로, 상단 메일 아이콘(메일 설정), MCP를 작성기 도구 목록으로 옮기고 등록 폼 재구성, 시작 화면 정리(프로젝트 더미 제거, 작성기 너비), 관계 지도(보이는 것만 렌더, 휠 확대, 한 줄 목록·색 점·배지), 회사 계정·보관 오류에 코드 표시.

- **복사 설치가 실제로 적용됨**: 1.2.1은 `compression: store`를 두고도 electron-builder의 차등 패키징이 압축을 '보통'으로 강제해 173MB 압축 설치 파일로 나왔습니다. 차등 패키징(`nsis.differentialPackage`)을 끄자 설정이 적용되어 설치가 압축 해제 없는 복사로 끝납니다. 설치 파일은 앱 크기 그대로(약 650~700MB)입니다. 사내 업데이트는 전체 설치 파일로 배포하므로 차등 업데이트를 잃는 것은 없습니다.

1.2.0 이후 반영 내역(1.2.1과 같음)입니다. 작업 기록 전체는 `docs/HOTFIX-1.2.0.md`에 이어서 적혀 있습니다.

## 고친 것

- 화면이 비면서 `Cannot access … before initialization`이 나던 오류(메일 상태 폴링이 프로젝트 상태보다 먼저 선언됨). 같은 유형과 없는 아이콘 이름을 빌드 전에 잡는 검사 추가.
- 명령 상세의 없는 아이콘으로 명령 화면이 비던 문제.
- 내장 브라우저 안 페이지의 복사 버튼(클립보드 쓰기 허용), 보조 영역 너비 조절이 위쪽에서만 되던 문제, 3분할 복귀 아이콘 방향.
- 로딩 오버레이가 뒤 내용을 가리지 않던 문제, 작업 계획·확인한 자료·변경 파일 행의 과한 여백.

## 새로 들어간 것

- **알림**: 레일의 종 아이콘과 미확인 점, 알림 목록. Windows 알림에 질문의 선택지 버튼과 답변 입력. 앱 안 토스트는 3초, 닫기 버튼.
- **메일**: 첨부 읽기 켬(문서는 파서가 먼저, Office는 파서가 못 읽는 파일만, 이미지는 연결된 이미지 모델이 읽음). 메일 위키 암호화 저장(키는 Windows 보관소, 실행 중에만 복호화 사본). 인용 답장 제거, 스레드 묶기, 근거 있는 사실 추출.
- **에이전트**: 화면 캡처 분석 도구, 로컬 서버 실행 시 자동 열기와 안내, MCP 서버 연결(stdio 명령과 Streamable HTTP, 쓰기 도구는 실행 전 질문).
- **AI Workspace**: 앱 등록과 Talk 작성 화면을 그대로 사용, 작성자 프로필 카드, 문의(목록·작성·담당자) 화면과 레일 아이콘.
- **화면**: 모든 화면이 창 너비를 더 넓게 사용, 시작 화면 프로젝트 목록 더 보기, 자는 마스코트 깜짝 깨기.
- **설치판**: 실행기·메인 번들 최소화, Electron 퓨즈(NODE_OPTIONS 차단, asar 무결성, asar만 로드), 복사 설치(압축 없음, 설치 파일은 커짐).

## 회사 PC에서 확인할 것

문의 실제 왕복, AI Workspace 앱 등록, 포털 로그인, Office 첨부(NASCA) 경로, 퓨즈를 켠 설치판 실행, 사내 MCP 서버 연결.
