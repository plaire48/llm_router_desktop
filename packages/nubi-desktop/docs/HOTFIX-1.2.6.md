# 누비 Workspace Beta 1.2.6

1.2.5를 회사 PC에서 써 본 뒤 받은 보고를 고치고 대화 화면을 정리한 빌드입니다. 1.2.5의 변경은 `docs/HOTFIX-1.2.5.md`에 있습니다.

## 고친 것

- **포털 로그인 '확인 중'이 끝나지 않음**: 페이지 안에서 실행하는 스크립트의 포털 주소 자리표시가, 빌드 과정에서 따옴표 모양이 바뀌어 실제 주소로 바뀌지 않았습니다. 그래서 로그인해도 메일 확인 요청이 엉뚱한 주소로 가 늘 실패했습니다. 따옴표 모양과 상관없이 바꾸고, 못 바꾸면 바로 오류를 내며, 빌드된 결과로 검사합니다. 로그인 창이 samsung.net 첫 화면이나 kor3 포털 홈에 머물러도 이어서 확인합니다.
- **연결 취소가 듣지 않음**: 취소 요청의 번호가 진행 중인 연결과 맞지 않으면 무시했습니다. 연결 중이면 번호와 상관없이 멈춥니다.
- **Talk '게시판 응답을 확인하지 못했습니다'**: 게시판 읽기가 앱 호스트를 거치지 않고 빈 토큰으로 바로 요청했습니다. 다른 화면처럼 앱 호스트로 읽습니다.
- **CMD로 설정했는데 PowerShell로 실행**: 모델이 셸을 직접 적어 보내면 설정을 무시하고 그 셸로 실행했습니다. 설정한 셸이 항상 이기고, 다른 셸로 보낸 명령은 실행하지 않고 그 셸 문법으로 다시 쓰게 돌려보냅니다(관리자 권한 실행만 PowerShell).
- **폴더 열기 때 위키가 만들어지지 않음**: OpenWiki가 이미 있는 폴더는 조용히 건너뛰었습니다. 이제 "OpenWiki가 이미 있어요(문서 n개). 그대로 가져올까요?"를 묻고, '지우고 다시 만들기'를 고르면 기존 openwiki 폴더를 지우고 처음부터 만듭니다.
- **문의 '문의를 불러오지 못했습니다'**: 같은 경로를 쓰도록 정리하고, 실패하면 원인 코드를 문구 뒤에 붙입니다. 회사 계정 확인은 2분 동안 다시 쓰고 401이면 새로 읽습니다.

## 바뀐 것

- **대화 화면 정리**: 작업 계획은 그 턴의 맨 위, 생각한 내용은 기록 안에 차례로 쌓이고 답이 나오면 함께 접힙니다. 승인해서 실행한 명령은 승인한 자리에 CMD처럼 출력까지 그대로 남고, '실행 결과 보기'와 '명령 상세' 단추는 없앴습니다. 한 번 그린 것은 지우거나 아래로 옮기지 않습니다.
- **"오픈위키 갱신"**: 대화에서 말하거나 `/wiki_update`를 치면 위키 갱신 단추를 누른 것과 같이 갱신합니다. git에서 받은 폴더는 먼저 `git pull --ff-only`로 받은 뒤 갱신합니다(원격이 없으면 건너뜀).
- **Workspace 화면 캡처**: 입력창의 화면 캡처 단추로 창의 일부를 끌어 고르면 메시지에 첨부됩니다(3장까지). 누비가 이미지 모델로 읽어 답합니다. 보낸 메시지에도 썸네일이 남습니다.
- **자는 새 깨우기**: 가만히 두어 잠든 새는 앱에서 무언가 일어나면 깜짝 놀라며 깹니다.
- **시작 장면**: 설치한 버전마다 한 번. 버전을 올려 설치하면 첫 실행 때 다시 나옵니다.
- **AI Pro 기본 모델**: 목록에 GLM이 있으면 GLM으로 시작합니다(없으면 이전처럼 Qwen 3.8 27B).
- **진행 중 답변 말풍선 없앰**: 작업 중에는 위쪽 답변 말풍선을 만들지 않고 생각하는 내용만 보여 줍니다. 답변은 끝나면 한 번에 나옵니다.
- **'보완할 결과가 있어요'**: 접힌 한 줄로 대화 맨 아래에 놓고, 다음 단계는 그 아래에 보입니다. 누르면 남은 확인과 확인 항목이 펼쳐집니다.
- **문의 머리글**: 위아래 두 줄을 한 줄로. 도움말(?)은 위 줄로 올렸습니다.
- **AI Workspace와 문의**: 좌우 여백 없이 창 너비를 다 씁니다. 뒤로(←) 버튼을 없애고 그 자리에 왼쪽 메뉴의 아이콘을 둡니다. 뒤로 가기는 Esc.
- **위키 페이지 이동**: 스킬처럼 아래 번호 페이지 하나로.
- **상태 이모지**: 프로필 사진 모서리 대신 이름 오른쪽에(모든 프로필).

- **기본 화면**: 폴더 프로젝트 없이 개인 대화만 있으면 '프로젝트를 열어 주세요' 화면이 먼저 나옵니다. 새 대화나 기존 대화를 고르면 바로 대화로 갑니다.

## 회사 PC에서 확인할 것

Talk·문의·앱 목록이 로그인 뒤 열리는지(실패하면 문구 뒤 괄호 속 코드), CMD 설정 때 명령이 CMD로 실행되는지, 폴더 열기 때 OpenWiki 확인 창, 화면 캡처 첨부 뒤 답변, 포털 로그인 뒤 확인이 시작되는지, 처음 실행 안내 위치, 창 조절 버튼(- □ ×) 호버 음영.
