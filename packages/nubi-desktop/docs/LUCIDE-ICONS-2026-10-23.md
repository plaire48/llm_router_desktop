# Lucide 아이콘과 모래시계

사용자가 기존 기능 아이콘을 익숙한 라이브러리로 바꾸고 브랜드 색/인터랙션과 모래시계 로딩을 요청했다. 일반 기능을 [Lucide](https://lucide.dev/)로 통일했다. 캐릭터/회사/모델 제공자/GitHub/AI Workspace 로고와 성공/주의/오류 의미는 유지한다.

## 구현

- `lucide-static@1.61.0`의 원본 SVG 115개를 119개 기존 기능 이름에 연결한다. 선택한 노드 데이터는 약 23KB다. 전체 아이콘 라이브러리, 아이콘 폰트, 모션 런타임과 CDN 요청을 추가하지 않는다. 원본 패키지/개별 SVG 해시와 ISC/Feather MIT 고지를 보존하며 배포 라이선스 폴더에도 복사한다.
- `ui/LucideIcon.jsx`를 CX 일반 버튼, 검색, Desktop mark와 AI Workspace에 함께 연결한다. Desktop 빌드 플러그인은 고정한 CX 0.5.4의 source entry/Icon 경계만 연결하며 설치된 패키지나 브라우저/Office 소스는 수정하지 않는다. CX 패키지를 갱신하면 이 source 경계도 검토한다.
- 기능 이름, 클릭 영역, 접근성 이름과 툴팁, 기존 24px 격자/둥근 1.8px 선, 역할별 크기를 유지한다. 일반 메뉴/설정/상단은 읽을 수 있는 청록·블루·라벤더 잉크를 사용하고 연한 색은 바탕에 둔다.
- 호버/초점/누름은 내부 도형만 움직인다. 기존 Dock 반응이 SVG를 약 20% 키우던 것을 Lucide에서는 내부 도형 최대 4%로 줄이고 바깥 크기를 고정했다. 기존 이벤트 처리를 재사용하며 새 반복 루프는 없다. 모션 감소에서는 내부 움직임도 멈춘다.
- 기존 공통 모래시계 정책을 유지하고 원본 Lucide SVG 파일/브랜드 잉크 토큰에 연결했다. 4초 주기에 두 번 180도 뒤집고 중간에 머문다. 모션 감소/숨김/가림 상태에서는 기존 정책대로 정지하며 강제 색상에서는 시스템 잉크를 사용한다.

공통 화면 fixture도 실제 renderer의 플러그인/로더를 사용한다. 일반 버튼과 CX 내부 버튼이 서로 다른 아이콘을 보여주는 검증 차이를 방지한다.

## 검증

- 실제 macOS Electron: `check-calm-liquid-ui` 13개 통과. 초기 실제 화면에서 보이는 20개 아이콘 중 19개가 Lucide이며 나머지는 보존한 브랜드 아이콘이다. 호버 전후 SVG 영역이 정확히 일치하고, 모션 감소에서 내부 이동이 멈췄다. 실제 Desktop CSS의 모래시계는 4초, 0도 유지와 180도 유지, 원형 테두리 제거와 브랜드 잉크를 확인했다. 로딩 스타일 확인용 표본은 검사 중에만 추가하고 제거한다.
- 1280px / 440px 125% 글자 / 440px 터치: 아이콘 18개 그룹과 대화/설정 6개 버튼 범위 통과. 버튼 표본 96개, 위반/정렬 관찰 사항 0건. 네 제공자의 색을 보존하며 터치 스위치의 확장 영역으로 켜기/끄기도 확인했다.
- 정적 아이콘 이름 검사 86개와 모션/창 숨김/타이틀바 단위 검사 27개 통과. 최종 `npm run build:electron`, 승인 팔레트/대비/공통 별칭 identity 검사 통과. 배포 라이선스 폴더의 Lucide 고지도 원본과 바이트가 일치했다.

모션 품질 검사도 145개 모두 통과했다(미판정 0건). 이전의 원형 스피너/은퇴한 배경 도형을 찾던 검사를 현재 4초 모래시계와 24/28초 두 물방울로 갱신했다. 대화 화면 진입의 물방울 정지와 같은 애니메이션 인스턴스/위상에서의 복귀를 확인한다. 결과: `verification/motion-1.3.0/lucide-icons/result.json`.

증거는 `verification/calm-liquid-2026-10-23/icon-proof.json`, `lucide-hourglass.png`, `model-actions.png`, `verification/icon-scale-2026-10-17/after.json`에 있다. 최종 전체 화면 117개 검사(116개 화면/모달과 새 모션 기록 1개)도 통과했다. 버튼 표본 1,371개와 동작 그룹 157개에서 배치 위반/정렬 관찰 사항 0건이다. 결과는 `verification/lucide-surfaces-2026-10-23/`에 있다.

격리 데이터와 합성 제공자 상태를 사용했다. 실계정/실모델/실제 메일·위키 자료와 Windows 설치/업데이트/재실행, Windows 전체 끊김 해소는 이 로컬 검증으로 확인하지 않았다. 후보의 전체 릴리스 게이트와 업로드는 Claude 소유로 유지한다.
