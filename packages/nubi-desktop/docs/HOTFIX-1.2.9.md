# 누비 Workspace Beta 1.2.9

## 2026-10-16 수정 빌드

- **시작 후 클릭 복구**: 컷신 중 복원된 모달을 닫으면 전체 화면이 입력 불가 상태로 남던 잠금 충돌을 수정했습니다. 컷신과 모달의 잠금 대상을 분리하고 실제 메뉴 클릭을 배포 검사에 추가했습니다.
- **알림 중복 방지**: 이미 발송한 질문, 승인, 답변, 위키 완료 알림은 창 재열기와 앱 재실행 때 다시 발송하지 않습니다. 메일 재로그인 알림은 연결이 복구된 뒤 새 장애가 생길 때 다시 알립니다.
- **메일 세션 만료**: 신뢰하는 포털과 로그인 탭의 알려진 세션 만료 팝업을 자동 확인합니다. alert와 confirm 모두 처리하고 로그인 입력이나 SSO 창 전환 때문에 연결이 먼저 종료되지 않도록 했습니다. 다른 확인과 입력 팝업은 유지합니다.
- **결재 ID 조회 보완**: 제공된 JS의 포털 사용자 조회 GET을 추가했습니다. 로그인 창을 닫은 뒤 GET에 빈 본문이 붙어 실패하던 부분도 고쳤습니다. 숫자 ID와 보낸 메일함 조회를 보완하고 사용자 ID 누락 시 메일 연결을 유지합니다.
- **메일 질문과 작업 계획**: 프로젝트 없는 대화에서도 검색 결과의 원문 ID로 메일을 읽도록 인자 호환을 보완했습니다. 마지막 단계까지 완료하는 계획 갱신을 허용하고, 독립 검토에서 확인한 단계만 완료로 확정합니다. 미확인 단계는 완료 숫자를 채우지 않고 구분합니다.
- **위키 진행 화면**: 해당 프로젝트의 대화만 잠그고 설정과 다른 프로젝트 이동은 유지합니다. 겹친 배경을 없애고 단색 진행 바와 은은한 밝기 변화로 정리했습니다.
- **커밋 그래프**: 기존 25개 목록에서 분기와 병합 흐름을 함께 확인합니다. 페이지를 넘겨도 부모 연결을 유지하며 파일 선택과 변경 비교는 기존 흐름을 따릅니다.

기존 1.2.9를 설치한 사용자는 이번 EXE로 수동 재설치해야 합니다. 같은 숫자 버전은 앱의 새 버전 알림 대상이 아닙니다. 기존 릴리즈 파일은 덮어쓰지 않고 새 빌드 태그로 구분합니다.

## 기존 1.2.9 포함 내용

- **터미널 출력 안정성**: 대량 출력의 처리 완료량을 정확히 계산하고 마지막 출력 뒤에 종료 상태를 표시합니다. 탭 재진입을 포함한 크기 변경을 실제 셸에 전달하고 Windows PTY의 줄 배치 호환 정보를 적용합니다. Mac Electron 검증과 Windows PowerShell 실사용 확인은 구분합니다.

- **개인 메일 폴더**: 기본 메일함 옆에서 포털 개인 폴더를 선택할 수 있습니다. 선택한 폴더를 유지하고 긴 이름은 한 줄로 표시하며 전체 이름은 툴팁으로 확인합니다.

- **문서로 질문**: 채팅의 + 메뉴에서 PDF, Word, Excel, PowerPoint, 텍스트 문서를 선택해 질문할 수 있습니다. 읽은 내용과 범위를 미리 보고 답변의 출처에서 다시 열 수 있습니다. 문서 이미지, OCR, 수식 재계산은 텍스트 추출과 구분합니다.
- **결재 사용자 확인**: 기존 포털 세션에서 사용자 ID를 다시 조회합니다. 중첩 응답, 필드명 대소문자와 숫자 ID를 처리하고, 사용자 정보 누락과 로그인 만료를 구분합니다.
- **메일 로그인 대기**: 확인 팝업과 로그인 입력을 기다리는 동안 연결 제한 시간이 소진되지 않도록 했습니다. 일반 확인 버튼은 사용자가 직접 누르며 위의 세션 만료 안내만 자동 확인합니다.
- **Talk 필터**: 정렬, 카테고리, 답변 상태와 페이지당 표시 수에서 중복되던 화살표를 하나로 통일했습니다.
- **문의 화면**: 목록과 본문을 왼쪽에 정렬하고 화면 하단까지 넓혔습니다. 목록 접기 화살표를 제거하고 좁은 창의 목록 복귀는 유지했습니다.
- **시작 화면**: 컷신 건너뛰기 버튼과 Escape 건너뛰기를 제거했습니다. 재설치 후 컷신과 시스템 모션 감소 설정을 유지합니다.
- **대형 프로젝트 위키**: 원문 전체를 한 번에 넣던 검토를 주장별 묶음과 원문 구간으로 나눴습니다. 아직 읽지 않은 내용은 근거로 인정하지 않고, 모든 검토가 끝나야 문서를 완료합니다.
- **위키 재작성**: 시작 직후부터 해당 프로젝트의 채팅을 잠그고 같은 화면에서 진행률과 경과 시간을 보여줍니다. 초안은 보존하며 다른 프로젝트로 이동할 수 있습니다.
- **화면 가독성**: AI Workspace 등록과 담당자 선택에 공통 글자 크기와 입력창을 적용했습니다. 위키의 단계, 처리 수와 시간을 나눠 표시하고 터미널 기록과 서브에이전트는 기본으로 접고 작업 계획의 진행 숫자는 오른쪽에 정렬합니다.

- **메일 위키 종류**: `SR처리/이력내용`은 `SR처리`처럼 기존 상위 분류로 표시합니다. 목록과 지도에 같은 기준을 적용하며 상세 분류는 검색할 수 있습니다. 연결 없는 문서는 경고 대신 중립 문서 아이콘으로 표시합니다.
- **위키 필터 오류**: 필터 버튼의 컴포넌트 이름 불일치로 화면 전체가 오류로 바뀌던 문제를 수정했습니다. 실제 React 화면의 코드/메일 위키에서 네 가지 필터의 적용, 다시 열기, 초기화와 빈 결과 복구를 1100/440/360px로 확인했습니다. 합성 자료를 사용한 로컬 검증이며 Windows 설치판 검증은 별도입니다.
- **위키 반응 속도**: 검색할 때 반복 정렬을 줄이고 지도 이동 중 문서와 연결 계산을 재사용합니다. 초안 입력과 필터 위치 갱신도 필요한 경우에만 처리하며 기존 모션은 유지합니다.
- **중단 후 대화 순서**: 실행 기록을 작업을 시작한 질문 위치에 연결합니다. 중단이나 후속 요청으로 터미널 기록이 새 질문 아래로 이동하지 않도록 했습니다.

- **인사말 타이핑**: 새 아래 인사말을 한 글자씩 표시하며 새 대화의 문구에도 다시 적용합니다. 문구의 공간을 미리 확보해 배치를 유지하고 모션 감소 설정에서는 전체 문구를 바로 보여줍니다.

1.2.8의 위키 정확도, 이어쓰기, 사내 웹과 메일 개선도 포함됩니다. 설치 방법과 사내 nuri 배포 방법은 `INSTALL-AND-UPDATE-1.2.9.md`를 참고하세요.

Windows x64용 서명되지 않은 Beta입니다. CI의 Windows 설치 검증과 실제 사내 SSO, 결재 계정, Windows 11 사용자 PC 및 Office/NASCA 검증은 서로 다른 범위입니다.
