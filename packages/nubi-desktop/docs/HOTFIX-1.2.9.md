# 누비 Workspace Beta 1.2.9

- **문서로 질문**: 채팅의 + 메뉴에서 PDF, Word, Excel, PowerPoint, 텍스트 문서를 선택해 질문할 수 있습니다. 읽은 내용과 범위를 미리 보고 답변의 출처에서 다시 열 수 있습니다. 문서 이미지, OCR, 수식 재계산은 텍스트 추출과 구분합니다.
- **결재 사용자 확인**: 기존 포털 세션에서 사용자 ID를 다시 조회합니다. 중첩 응답, 필드명 대소문자와 숫자 ID를 처리하고, 사용자 정보 누락과 로그인 만료를 구분합니다.
- **메일 로그인 대기**: 확인 팝업과 로그인 입력을 기다리는 동안 연결 제한 시간이 소진되지 않도록 했습니다. 확인 버튼은 사용자가 직접 누릅니다.
- **Talk 필터**: 정렬, 카테고리, 답변 상태와 페이지당 표시 수에서 중복되던 화살표를 하나로 통일했습니다.
- **문의 화면**: 목록과 본문을 왼쪽에 정렬하고 화면 하단까지 넓혔습니다. 목록 접기 화살표를 제거하고 좁은 창의 목록 복귀는 유지했습니다.
- **시작 화면**: 컷신 건너뛰기 버튼과 Escape 건너뛰기를 제거했습니다. 재설치 후 컷신과 시스템 모션 감소 설정을 유지합니다.
- **대형 프로젝트 위키**: 원문 전체를 한 번에 넣던 검토를 주장별 묶음과 원문 구간으로 나눴습니다. 아직 읽지 않은 내용은 근거로 인정하지 않고, 모든 검토가 끝나야 문서를 완료합니다.
- **위키 재작성**: 시작 직후부터 해당 프로젝트의 채팅을 잠그고 같은 화면에서 진행률과 경과 시간을 보여줍니다. 초안은 보존하며 다른 프로젝트로 이동할 수 있습니다.
- **화면 가독성**: AI Workspace 등록과 담당자 선택에 공통 글자 크기와 입력창을 적용했습니다. 위키의 단계, 처리 수와 시간을 나눠 표시하고 터미널 기록은 기본으로 접고 작업 계획의 진행 숫자는 오른쪽에 정렬합니다.

1.2.8의 위키 정확도, 이어쓰기, 사내 웹과 메일 개선도 포함됩니다. 설치 방법과 사내 nuri 배포 방법은 `INSTALL-AND-UPDATE-1.2.9.md`를 참고하세요.

Windows x64용 서명되지 않은 Beta입니다. CI의 Windows 설치 검증과 실제 사내 SSO, 결재 계정, Windows 11 사용자 PC 및 Office/NASCA 검증은 서로 다른 범위입니다.
