# Project Wiki notifications

프로젝트 위키 생성 결과가 저장되면 Windows 시스템 알림으로 프로젝트 이름과 문서 수를 알려준다. 갱신안 준비와 실제 반영 완료는 서로 다른 문구를 사용한다. 문서 본문과 전체 경로는 알림에 포함하지 않는다.

- 초기 생성: 게시와 완료 상태 저장 이후 `위키 생성 완료`.
- 갱신 사본: 준비 상태 저장 이후 `위키 갱신안 준비 완료`. 반영이 필요함을 명시한다.
- 승인한 갱신: 반영 상태 저장 이후 `위키 반영 완료`.
- 실패, 취소, 기존 위키 발견과 상태 조회는 알림을 만들지 않는다. 프로젝트/작업/완료 단계별로 중복을 막는다.
- 클릭하면 기존 프로젝트 전환 보호를 거쳐 위키로 이동한다. 갱신안은 기존 검토 화면으로 연다. 클릭 자체로 실행하거나 승인하지 않는다.
- 기존 Electron Notification과 누비 앱 아이콘을 사용한다. 시스템 알림 차단이나 IPC 오류가 저장된 작업을 실패로 바꾸지 않는다.

검증: 위키 생성/갱신 파일 작업, 알림 상태/중복/클릭, 기존 답변 알림과 프로젝트 서비스 포함 52개 자동 검사 통과. Electron 빌드 통과. 실제 Windows 알림 표시와 OS 알림 설정에 따른 전달은 별도 Windows 검증 대상이다.
