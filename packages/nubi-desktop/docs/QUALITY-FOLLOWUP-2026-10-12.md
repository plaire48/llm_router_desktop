# Desktop 품질 후속 확인

## 변경

- 로그인 유지: OS 암호화 저장을 Electron 42.11.10의 비동기 safeStorage로 전환했다. OS 대기 시간 초과, 지연 완료 후 쓰기 차단, 로그아웃 순서와 키 교체를 검증했다. ChatGPT/AI Pro의 앱 내부 브라우저 로그인 방식은 유지한다. 상세는 `CONNECTION-PERSISTENCE-2026-10-12.md`를 따른다.
- 독립 결과 검토: 중복 지침을 4032자에서 3568자로 줄였다. 사용자 범위, 근거 누락, 승인, 하위 분석 실행 영수증과 보고서 정확도 구분은 유지했다. 이전 문장을 그대로 찾던 검사도 같은 의미의 새 문장에 맞췄다.
- UI 회귀: 시간대별 따뜻한 인사말과 승인 문구를 현재 제품 계약으로 검증하도록 정리했다.
- 메일 첨부: 실제 `image001.jpg`를 열어 호텔 홍보 배너의 미리보기 성공을 확인했다. 목록은 실제 queued/reading일 때만 읽기 대기/읽는 중으로 표시한다. 지원 불가/실패 등 미확인 첨부는 확인 필요로 구분한다. 이미지 글자 읽기와 검색/AI 미포함 범위는 유지하며 이미지 열기만으로 완료 처리하지 않는다.

## 검증

- 전체 Node 검사 815개: 620 통과, 195 건너뜀, 실패 0. 건너뜀은 비활성 A2A/Computer Use와 실행 환경별 검증을 포함하며 성공에 합산하지 않았다.
- 디자인 검사 및 forms 8, mail 7, modals 29, shared 34 검사를 통과했다.
- Electron build와 native shell 14, skills 9, agent 8, live-web 9, lifecycle 및 all-surfaces 105 검사를 통과했다. 화면 검사는 격리된 자료/제공자 fixture이며 실모델 품질이나 실서비스 성공을 의미하지 않는다.
- 실제 macOS 앱을 재시작한 뒤 추가 로그인 없이 ChatGPT GPT-6.1-Sol/Light 복원과 새 요청의 응답을 확인했다. 저장 메일 36개와 원문/이미지 미리보기도 실제 앱에서 확인했다.
- 마지막 첨부 표시 문구 변경 뒤 Electron을 다시 빌드하고 재시작했다. 실제 저장 메일에 `Room`을 검색해 한 결과의 제목/본문 강조와 `첨부 확인 필요` 표시를 확인했다. 두 번째 재시작에서도 ChatGPT 모델과 Light 선택이 복원됐다.

## 남은 범위

이미지 OCR은 미지원이다. Windows Office 2016/NASCA, Windows DPAPI, 다른 제공자 실계정 복원과 현재 모델의 반복 품질 평가는 이 결과에 포함하지 않는다. 메일 비밀번호는 저장하지 않으므로 재시작 이후 신규 수집은 사용자 메일 재연결이 필요하다. 저장한 메일 조회와 AI 로그인 복원은 별도로 동작한다.
