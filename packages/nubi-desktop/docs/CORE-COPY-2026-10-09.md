# Existing CX identity and concise copy

기존 CX, Nubi 컴포넌트, 누비 캐릭터와 제공자/폴더/Git 아이콘, 기준 HTML의 폰트와 파랑 팔레트를 재사용했다. 새 글꼴/아이콘 라이브러리나 장식 이미지는 추가하지 않았다. 발표 자료의 시각 위계는 참고하지만 큰 제목과 기능 나열을 업무 화면에 옮기지 않는다.

폰트는 Pretendard Variable/Pretendard 우선, 번들 Noto Sans KR와 Windows Malgun Gothic 폴백이다. 현재 토큰은 본문/입력 16px, UI 15px, 보조 14px, 일반 제목 18px의 rem 값이다. 팔레트와 원본 HTML SHA-256은 그대로 유지하고 현재 적용 수치만 reference.json과 VISUAL-IDENTITY.md에 동기화했다. 과거 Theia/VS Code 검증 기록과 현재 Electron 기준을 구분한다.

변경:

- Electron 로그인은 “모델을 연결해 시작하세요.” 한 문장과 기존 이미지/제공자 버튼을 사용한다.
- 프로젝트 시작은 “프로젝트를 열어 주세요.”와 80px 아이콘 카드로 표시한다. 폴더/Git 안내는 각각 “최상위 폴더 선택”, “새 폴더로 복제”다.
- Git의 정확한 복제 위치는 기존 입력을 펼쳤을 때 보여준다. 선택 모델과 프로젝트 내용 전달 안내는 유지한다.
- 메일 빈 화면은 다음 행동 한 문장만 표시한다. 자동 정리 연결 모달의 반복 설명은 줄이고 비밀번호 비저장 안내는 유지한다.
- 대화 본문이나 모델 응답은 잘라내지 않는다. 승인/미확정 상태/복구와 원문 읽기 범위 안내도 유지한다.

검증은 Electron 빌드, 원본 HTML 해시를 포함한 디자인 검사, 실제 로컬 macOS Electron 로그인/설정/메일 화면, 별도 Electron 합성 프로젝트/Git 상세/메일 화면과 좁은 창에서 수행했다. 프로젝트 카드 높이 80px와 공통 폰트 스택을 확인했다. 현재 검증 Mac에서 실제 로드된 번들 폰트는 Noto Sans KR다. 캡처/측정은 `verification/typography/core-*`에 있다. 기존 Nubi/CX와 details를 활용하므로 새 패키지 도입은 필요하지 않다. 문구 검토는 UX Writing 스킬과 기존 VISUAL-IDENTITY의 핵심/필수 정보 보존 원칙을 적용했다.

합성 모델/프로젝트 상태는 실제 제공자 성능이나 Windows 설치판 성공을 뜻하지 않는다. 사용자 PPT 원본 파일은 이번 턴에 별도로 제공되지 않았으며 기존 저장소의 HTML/이미지 자산을 확인했다.
