# 누비 Workspace Beta 1.1.6

## 변경

- 메일을 열면 HTML 표, 글자 강조, 본문 이미지가 바로 표시됩니다. CID 삽입 이미지, HTTP/HTTPS 이미지와 래스터 data 이미지가 대상입니다. 별도의 이미지 표시 버튼은 없습니다.
- 메일 연결 중 새와 회전 표시, 실제 경과 시간을 제공합니다. X, Esc, 바깥 클릭으로 연결 창을 닫을 수 없고 연결 취소는 유지합니다. 완료/실패/취소 뒤 다시 닫을 수 있습니다.
- 시작 화면의 준비 문장을 새와 회전 표시로 바꿉니다. 시스템 모션 감소 설정에서는 회전을 멈춥니다.
- 질문의 선택지와 직접 입력란을 대화 안에 바로 표시합니다. 답변하기 버튼/질문 모달을 거치지 않습니다. OS 시스템 알림 클릭은 해당 대화의 질문으로 이동합니다.
- GHES 프로필 사진의 API 요청이 실패하면 누비 내부 SSO 브라우저 세션으로 같은 서버에 다시 요청합니다. 다른 서버로 인증값을 보내거나 쿠키를 추출하지 않습니다. 서버가 MIME을 생략한 PNG/JPEG/GIF/WebP도 파일 서명을 확인합니다.
- 공유 위키 조회의 409/422를 저장 충돌로 오해하지 않도록 구분합니다. Git 참조 조회가 실패하면 Commit API로 한 번 조회하며, 계속 실패하면 읽기 실패를 표시합니다. 파일 해시 불일치는 무결성 오류로 표시합니다. 쓰기 시 HEAD 확인과 강제 갱신 금지는 유지합니다.
- 1.1.5의 메일 본문 복구, 삽입 이미지/첨부 구분, ASAR 밖 OpenWiki 준비 자산 수정도 포함합니다. 예전 실패 기록은 위키 준비의 다시 시도로 재실행합니다.

## 표시와 근거

HTML은 기존 DOMPurify 3.4.15 허용 목록으로 정리한 후 스크립트/폼/외부 프레임/임의 CSS 요청이 막힌 프레임에서 표시합니다. 표와 본문 스타일은 Workspace 바깥으로 적용되지 않습니다. 링크는 누비 브라우저로 엽니다. 이미지는 원본 참조대로 자동 요청하며 Referer를 보내지 않습니다. CID 이미지 전송은 본문 삽입 PNG/JPEG/GIF/WebP 합계 8MB까지입니다. HTML 표시 범위는 500,000자입니다.

검색, Agent 질문, Personal Wiki 정리에는 기존 원문 텍스트만 사용합니다. HTML/이미지는 화면 표시 요청에만 전달하며 원본과 manifest 영수증을 수정하지 않습니다. 첨부 파일 내용 분석은 Beta에서 지원하지 않습니다.

## 검증 범위

- 로컬 실제 컴포넌트 렌더링: 표/CID/외부 이미지 자동 표시, 검색어 강조, 실행 요소 제거, X/Esc/바깥 클릭 차단과 완료 후 해제.
- 검증된 합성 MIME: HTML/이미지 표시, AI 근거의 텍스트 유지, 영수증 보존, 바뀐 원본 거절.
- GHES 합성 응답: 내부 SSO 세션 요청 보완, 인증값 없는 브라우저 사진 요청, 동일 서버/리다이렉트와 파일 서명 보호.
- 위키 관련 5개 회귀: 참조 조회 복구, 지속 읽기 실패의 구분, 해시 불일치 거절, 쓰기 전/최종 참조 충돌 보호.
- Windows 빌드와 패키지 내 준비 자산 무결성을 확인합니다. 사용자 요청에 따라 추가 전체 기능/모델/설치 회귀는 생략합니다.

사내 GHES 실계정의 사진/공유 위키 성공과 실제 Windows 11 메일 서버의 HTML 표시, 사용자 PC 업데이트는 별도 확인이 필요합니다. 외부망 빌드 성공을 사내 서비스 성공으로 표시하지 않습니다.

## 방법론

기존 DOMPurify/격리 프레임 패턴을 재사용하고 새 의존성은 추가하지 않았습니다. [DOMPurify](https://github.com/cure53/DOMPurify), [iframe sandbox](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe), [GitHub Git references](https://docs.github.com/en/rest/git/refs?apiVersion=2022-11-28)를 확인했습니다. 화면과 검색/AI 근거를 분리하며 조회 실패 복구가 쓰기 권한/CAS 확인을 완화하지 않도록 했습니다.
