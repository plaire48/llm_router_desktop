# 1.2.10 적용 범위와 설치판 확인

기준 배포: 1.2.9, `c702f835618c6c948986c1601832baed003ab0df`.

이번 배포는 현재 Desktop 빌드의 입력 886개를 소스 복사본과 대조했다. 생성 중간물을 제외한 입력 파일의 누락과 내용 차이는 0개다. 직전 배포에 없던 빌드 입력은 84개다. 이 숫자는 기능 개수나 실제 업무 통과 수가 아니다.

| 영역 | 설치판에 포함하는 기능 | 별도 확인 대상 |
| --- | --- | --- |
| Office 검토 | Word 문단과 표, PPT 개체와 메모, Excel 셀과 수식 미리보기. 변경 강조, 원본 비교, 직접 초안 수정 | 실제 Office 페이지와의 표시 일치 |
| Excel 계산 | 기존 Univer 계산 작업자와 라이선스. 수정 수식과 관련 셀 재계산 | 실제 Office 2016의 계산 결과와 모든 함수 |
| Office 연결 | 열린 문서 선택, task/session 바인딩, 승인, 재읽기, 별도 저장 | Windows 11 + Office 2016/NASCA의 전체 실행 |
| PDF | 페이지 렌더링, 선택 범위 질문, 일반 텍스트 양식의 승인 편집, 사본 저장과 Undo | 임의 본문, OCR, 서명, 주석 편집은 미지원 |
| 문서 편집기 | 누비 편집기와 Obsidian 연결. PDF는 내부 편집 | 실제 외부 앱의 설치 및 권한. 메모장은 제외 |
| 결과 확인 | 적용과 저장 상태 구분, 승인 전후 비교, 출처 버전에 묶인 숫자 범위 대조 | 의미, 단위, 모든 문서 전체의 자동 정확성 판정 |
| 브라우저 | 외부 연결, 창 도킹, DWM 도착 전환, 현재 화면 학습과 재사용 계약 | 브라우저별 Windows 창 제어, 회사 로그인, 실제 속도 |
| 메일과 위키 | MIME 첨부 미리보기, 범위 읽기, 세션 복구, 위키 갱신과 검토 | 사내 SSO와 실제 메일 수신, 실제 모델 과제 |
| 대화와 실행 | 기존 공통 UI, 문맥 정리, 모달과 전환, 터미널 복구와 중지 계약 | 회사 PC에서 장시간 사용과 체감 품질 |

`check-distribution-capabilities.mjs --packaged`는 미리보기 및 연결의 필수 빌드 입력과 실제 생성 파일을 검사하고, Electron 패키지 안의 모든 lib 파일을 빌드 결과와 바이트 단위로 대조한다. 빠진 경우 릴리즈 생성 전에 CI가 실패한다. 파일 포함 확인이 사용자 환경에서의 동작 성공을 뜻하지 않는다.

Office UI는 세 앱과 두 화면 너비에서 실제 브라우저로 검증한다. 문서 내용과 native 포트는 fixture다. PDF 대화 편집은 실제 Electron과 파일 재열기를 확인하며 모델 응답은 fixture다. 실제 모델 품질 기록과 Windows 설치/업데이트 검사는 별도 근거로 유지한다.

새 파일 생성 모듈의 연구 평가와 native 열린 문서 미리보기는 서로 다른 경로다. 모든 Office 파일 형식이나 모든 앱의 native 기능을 지원한다고 표시하지 않는다.

사용자 후속 결정: 외부 PDF 앱 연결을 제거하고 누비 PDF 미리보기/양식 편집만 사용한다. UI와 IPC, 프로세스 실행 및 브리지 패키징을 제거했으며 배포 검사에서 잔여 실행 파일과 빌드 입력의 부재를 확인한다. 일반 본문, OCR, 서명 및 주석 수정은 지원 범위에 추가하지 않았다.
