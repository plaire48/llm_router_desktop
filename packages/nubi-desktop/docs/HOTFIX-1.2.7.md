# 누비 Workspace Beta 1.2.7

1.2.6을 회사 PC에서 써 본 뒤 받은 보고와, 에이전트 하네스 1차 개선을 담은 빌드입니다. 1.2.6의 변경은 `docs/HOTFIX-1.2.6.md`에 있습니다.

## 고친 것

- **AI Workspace 화면 오류와 Talk "게시판 주소를 확인하세요"**: 앱 안에서는 페이지 주소가 웹 주소가 아니라 Talk 링크 만들기가 실패하며 화면 전체가 깨졌습니다. 공개 사이트 주소(`https://code.sdsdev.co.kr/pages/Manufacturing-IT/ai_workspace/`)를 기준으로 쓰고, 포팅 화면이 실패해도 그 화면만 오류를 보입니다.
- **결재 목록 "로그인하세요"**: 메일은 연결됐는데 결재 서비스 응답이 로그인 페이지인 경우를 따로 안내합니다.
- **스킬 탭, 파일 열기 오류**: 문구 뒤에 오류 코드를 붙입니다.
- **상태 이모지**: 사내 GitHub의 사용자 지정 이모지(그림)도 상단 프로필, 계정 모달, AI Workspace의 이름 오른쪽에 보입니다. 그림을 못 읽으면 `:이름:`으로 보입니다.
- **문의 목록 접기**: 접기 단추가 새로고침 아이콘 오른쪽에 있고, 접힌 뒤에는 머리글에 펼치기만 남습니다.
- **시작 때 메일 안내 없음**: 메일 연결 안내나 로그인 양식이 시작 때 자동으로 열리지 않습니다(AI 로그인과 겹치던 충돌). 메일 로그인은 메일 설정과 포털 로그인 단추로만 엽니다.
- **메일 세션**: 일시적인 포털 오류에 로그아웃하지 않고 자동으로 다시 확인합니다. 알 수 없는 경로 이동은 로그인 만료로 보지 않습니다. 사내 메일 로그인 양식(아이디, 비밀번호)을 앱 안 회사 로그인 페이지에 대신 채웁니다.
- **메일 첨부 그림**: 본문 아래 썸네일로 보이고 눌러 크게 볼 수 있습니다.

## 바뀐 것

- **에이전트 하네스 1차**: 도구 설명을 한 문장으로 줄이고 규칙은 한 곳에 모았습니다(도구 스키마 7,967 → 5,800 토큰). 독립 읽기는 한 응답에서 함께 실행합니다. 시스템 프롬프트가 실행 중 바뀌지 않아 캐시가 유지됩니다. 모델이 첫 턴에 계획을 직접 쓰고, 단계 완료를 표시하면 검토가 확인하거나 되돌립니다. 실행 예산(60회 또는 20분)에 닿으면 정리한 답과 '이어서 진행' 단추가 나옵니다. 읽기만 한 실행은 검토 1회입니다.
- **인앱 캡처**: 끌어 고른 영역을 기기 해상도에서 잘라 글자가 선명합니다. 첨부 캡처는 그 메시지의 질문으로 읽고 3장은 동시에 읽습니다. 캡처 단추는 + 오른쪽입니다.
- **인앱 Playwright**: 클릭 뒤 대기 550 → 208ms, 동작 응답에 새 화면을 바로 포함, 찾기/폼 채우기/스크롤 도구 추가, 같은 탭 동시 호출은 줄 세우기, SPA 해시 이동에도 문서 id 유지.
- **대화 화면**: 작업 계획은 접힌 기록 위에 그대로, 도구 기록은 순서대로 묶음, 답변은 읽기 순으로 나타남, 답변 완료 시스템 알림.
- **개발 검증**: 변경을 적용한 뒤 테스트와 앱 안 미리보기까지 이어서 확인합니다.
- **시작 장면**: 설치 id 기준으로 설치나 업데이트 뒤 첫 실행에 재생합니다.
- **메일 관계**: 답장과 참여자 관계를 위키 관계 지도에 반영합니다.

## 회사 PC에서 확인할 것

AI Workspace Talk와 문의가 열리는지, 결재 목록, 상태 이모지가 이름 오른쪽에 보이는지(그림이면 `:이름:` 대신 그림이 나오는지), 시작 때 로그인 창이 뜨지 않는지, 메일 로그인 양식으로 연결되는지.
