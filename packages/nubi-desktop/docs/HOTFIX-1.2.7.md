# 누비 Workspace Beta 1.2.7

1.2.6을 회사 PC에서 써 본 뒤 받은 보고와, 에이전트 하네스 1차 개선을 담은 빌드입니다. 1.2.6의 변경은 `docs/HOTFIX-1.2.6.md`에 있습니다.

## 고친 것

- **AI Workspace 화면 오류와 Talk "게시판 주소를 확인하세요"**: 앱 안에서는 페이지 주소가 웹 주소가 아니라 Talk 링크 만들기가 실패하며 화면 전체가 깨졌습니다. 공개 사이트 주소(`https://code.sdsdev.co.kr/pages/Manufacturing-IT/ai_workspace/`)를 기준으로 쓰고, 포팅 화면이 실패해도 그 화면만 오류를 보입니다.
- **결재 목록 "로그인하세요"**: 메일은 연결됐는데 결재 서비스 응답이 로그인 페이지인 경우를 따로 안내합니다.
- **스킬 탭, 파일 열기 오류**: 문구 뒤에 오류 코드를 붙입니다.
- **상태 이모지**: 사내 GitHub의 사용자 지정 이모지(그림)도 상단 프로필, 계정 모달, AI Workspace의 이름 오른쪽에 보입니다. 그림을 못 읽으면 `:이름:`으로 보입니다.
- **문의 목록 접기**: 접기 단추가 새로고침 아이콘 오른쪽에 있고, 접힌 뒤에는 머리글에 펼치기만 남습니다.
- **시작 때 메일 안내 없음**: 메일 연결 안내나 로그인 양식이 시작 때 자동으로 열리지 않습니다(AI 로그인과 겹치던 충돌). 메일 로그인은 메일 설정과 포털 로그인 단추로만 엽니다.
- **메일 로그인**: 유효한 세션을 먼저 확인하고 필요하면 기존 인앱 포털 로그인 탭을 엽니다. 채팅에서 아이디나 비밀번호를 받거나 숨은 페이지에 자동 제출하지 않습니다. 원문 저장 위치 안내와 기존 메일은 유지합니다.
- **메일 첨부 그림**: 본문 아래 썸네일로 보이고 눌러 크게 볼 수 있습니다.

## 바뀐 것

- **에이전트 하네스 1차**: 도구 설명을 한 문장으로 줄이고 규칙은 한 곳에 모았습니다(도구 스키마 7,967 → 5,800 토큰). 독립 읽기는 한 응답에서 함께 실행합니다. 시스템 프롬프트가 실행 중 바뀌지 않아 캐시가 유지됩니다. 모델이 첫 턴에 계획을 직접 쓰고, 단계 완료를 표시하면 검토가 확인하거나 되돌립니다. 실행 예산(60회 또는 20분)에 닿으면 정리한 답과 '이어서 진행' 단추가 나옵니다. 읽기만 한 실행은 검토 1회입니다.
- **인앱 캡처**: 끌어 고른 영역을 기기 해상도에서 잘라 글자가 선명합니다. 첨부 캡처는 그 메시지의 질문으로 읽고 3장은 동시에 읽습니다. 캡처 단추는 + 오른쪽입니다.
- **인앱 Playwright**: 클릭 뒤 대기 550 → 208ms, 동작 응답에 새 화면을 바로 포함, 찾기/폼 채우기/스크롤 도구 추가, 같은 탭 동시 호출은 줄 세우기, SPA 해시 이동에도 문서 id 유지.
- **대화 화면**: 작업 계획은 접힌 기록 위에 그대로, 도구 기록은 순서대로 묶음, 답변은 읽기 순으로 나타남, 답변 완료 시스템 알림.
- **개발 검증**: 변경을 적용한 뒤 테스트와 앱 안 미리보기까지 이어서 확인합니다.
- **시작 장면**: 설치 id 기준으로 설치나 업데이트 뒤 첫 실행에 재생합니다.
- **메일 관계**: 답장과 참여자 관계를 위키 관계 지도에 반영합니다.

## 최신 보완

- **메일 재로그인**: `/loginapp/abnormal-logout`과 `/loginapp/logout`을 기존 회사 로그인 화면으로 인식합니다. 로그인 입력 중 조회 오류로 창이 닫히지 않으며, 인증 후 같은 세션으로 메일함을 확인해 복구합니다.
- **재로그인 안내**: 주변 모달과 같은 아이콘, 글꼴, 강조와 여백을 사용합니다. 안내를 줄이고 연결 대기 화면의 큰 빈 공간을 없앴습니다.
- **Office 첨부 읽기**: Word, Excel, PowerPoint 본문 읽기와 AI 질문 연결을 유지합니다. Windows에서 일반 파서가 읽지 못한 보호 문서는 설치된 Office 읽기 전용 경로로 확인합니다. 실제 NASCA 문서는 사내 PC 검증이 필요합니다.

- **위키 구성 분석 실패**: 설명만 답하고 구성을 제출하지 않은 모델 응답은 같은 분석 내용에서 보완합니다. 계속 실패하면 구성 제출 누락과 모델 연결 오류를 구분합니다. 최초 생성 중 모델 오류가 나도 구성과 완료 문서의 이어쓰기 기록을 보존합니다. 기존 위키 갱신도 완료 문서와 구성, 이어쓰기 기록을 보관합니다. 다시 시도하면 원본과 보관본이 일치하는지 확인하고 남은 문서부터 이어갑니다. 원본이 바뀌면 기존 작업을 덮어쓰지 않고 새 갱신이 필요함을 안내합니다.
- **도구 실행 승인**: 승인한 정확한 MCP 호출을 한 번 실행하고 결과를 AI에 전달합니다. 항상 허용은 프로젝트별 도구에 저장합니다. 인자는 인증값을 가린 구조화된 내용으로 표시합니다.
- **기본 터미널**: 명령 기록과 `/terminal`에서 설정한 CMD, PowerShell, Git Bash를 엽니다. 승인 대기 중 설정이 바뀌면 새 셸 문법으로 명령을 다시 준비합니다. 이미 열린 세션은 유지합니다.
- **오래 걸리는 명령**: 일반 명령에서 5분간 새 출력이 없으면 계속 기다리거나 중지 후 원인을 확인할 수 있습니다. 개발 서버와 직접 입력하는 터미널은 제외합니다. 명령을 자동 재실행하지 않습니다.
- **시작과 프로젝트 이동**: 준비 화면 전에 작업 화면이 잠깐 노출되거나 이전 프로젝트가 보이는 현상을 보완했습니다.
- **AI Workspace 문의**: 인앱 요청 경로와 계정 확인을 보완했습니다. 실제 사내망 동작은 아래 확인 항목입니다.

## 회사 PC에서 확인할 것

AI Workspace Talk와 문의, 결재 목록, 상태 이모지, 인앱 포털 로그인, Windows 시스템 알림을 확인하세요. 로컬 자동 검사와 GitHub Windows 설치 검사는 회사망 SSO 성공을 보장하지 않습니다. 설치 파일은 공인 코드 서명이 없는 Beta입니다.
