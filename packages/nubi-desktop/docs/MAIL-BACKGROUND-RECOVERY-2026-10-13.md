# 메일 백그라운드 확인과 복구

하단 백그라운드 상태 버튼을 누르면 확인 필요한 메일과 원인, 조치를 한 모달에서 확인합니다. 실패 메일은 10개씩 표시하고 페이지 이동은 공통 모달의 고정 하단 영역을 사용합니다. 개별 다시 정리, 모델/메일 설정, 해시를 유지한 원문 보기를 제공합니다. 서버에서 받지 못한 메일은 다음 서버 확인 때 다시 받도록 요청하며 기존 서버 대기 시간을 우회하지 않습니다. 11 MB 초과처럼 재시도로 해결되지 않는 제한은 원인을 설명하고 반복 다운로드 버튼을 숨깁니다.

계정 ID와 원본 변경을 확인한 뒤 지정한 메일만 재시도합니다. 다른 실패 메일과 원문/영수증은 보존합니다. 모달을 열거나 목록을 읽는 것만으로 재시도를 실행하지 않습니다. 서버 UIDL, 저장 경로와 서버 응답 본문은 진단 목록으로 보내지 않습니다.

정상 취소나 로그아웃으로 중단된 정리는 실패 대신 대기 상태로 보존합니다. 이전 `mail_cancelled` 실패 기록도 원문을 유지한 채 대기로 복원합니다. 호스트가 취소하지 않았는데 모델 응답이 중단되면 `mail_summary_interrupted`로 남겨 원인과 수동 재시도를 표시합니다. 연결 요청의 정상 취소는 오류 알림을 띄우지 않으며 예상하지 못한 중단은 한국어 안내를 사용합니다.

초기 준비와 메일 연결 확인은 기존 콘텐츠 위에 겹쳐 표시합니다. 연결 전후에 새 진행 행을 넣지 않으며 콘텐츠 위치와 모달 크기를 유지합니다. 연결 중 원래 입력/설정은 inert로 보호하고 취소 버튼에 초점을 둡니다. X/Esc/배경 닫기 차단과 해당 요청 ID만 취소하는 계약은 유지합니다.

공통 `workspace-dialogs.css`와 CX 토큰을 재사용합니다. 제목 18/600, 본문 15/600, 보조 14, 파랑 조치 색과 공통 여백을 실제 렌더링에서 확인합니다. 짧은 상태/버튼은 한 줄이고 긴 제목은 툴팁과 원문 보기로 확인합니다. 재시도 확인은 모달 안에 표시하며 제목을 가리는 별도 성공 알림을 만들지 않습니다. [Loading States 스킬](/Users/ganadi/.codex/plugins/cache/designer-skills/interaction-design/1.0.0/skills/loading-states/SKILL.md)의 레이아웃 이동 방지, 실제 진행 표시, 취소와 모션 감소 지침을 적용했습니다.

검증: 메일 확인/개별 재시도/취소 검사와 기존 로컬 TLS POP3 회귀, 공통 디자인 검사 및 로컬 Electron 빌드. 실제 공유 컴포넌트 Chrome에서 360px/1000px 페이지 이동, 제목/폰트/버튼 정렬, 원문 해시 전달, 로딩 전후 콘텐츠 좌표 유지, 취소 후 입력 복구를 확인합니다. 계정과 응답은 합성이며 사내 메일 서버나 설치된 Windows 검증을 뜻하지 않습니다.

이 변경은 게시된 1.1.6 설치 파일 이후의 소스 개선입니다. 기존 1.1.6 EXE를 덮어쓰지 않습니다.
