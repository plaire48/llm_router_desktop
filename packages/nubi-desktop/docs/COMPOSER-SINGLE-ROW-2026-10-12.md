# 채팅 입력 도구 한 줄 배치

입력창의 실제 너비를 기준으로 승인, 추론, 모델의 보조 문구를 차례로 숨긴다. 버튼은 줄바꿈하지 않고 아이콘, 접근성 이름과 툴팁을 유지한다. 모델 제공자 색상, 컨텍스트 숫자, 입력 펼치기와 실행 중 대기열 추가/중지는 유지한다. 대기열 버튼의 중복된 ‘추가’ 글자는 제거했다.

기존 CSS container query와 공통 CX 버튼을 재사용했다. 새 라이브러리는 추가하지 않았다. 마우스 화면은 기본 36px, 좁은 중앙 영역은 32px 버튼과 4px 간격을 사용한다. 컨텍스트 버튼은 44px를 보존하고 터치 입력은 모든 버튼의 최소 크기를 44px로 유지한다. 승인 버튼의 바깥 영역도 중앙 정렬해 작은 버튼만 위로 어긋나던 문제를 수정했다.

중앙 영역의 최소 너비 계산은 묶음 요소 대신 실제 표시된 각 버튼을 센다. 긴 초안에서 추가되는 펼치기, 실행 중 대기열/중지, 모델 복구 버튼까지 예약한다. 수축 가능한 읽기 여백의 하한과 기존 레이아웃 최소값도 보존한다. 상단 도구 줄 역시 rem 기준 container query로 보조 문구를 줄여 글자 확대 시 계정 버튼이 화면 밖으로 밀리지 않게 했다.

검증은 production 컴포넌트와 전체 Electron 스타일을 사용한 격리 화면이다. 긴 모델명과 20줄 초안으로 대기/실행 상태 각각 1280, 1000, 900, 760, 620, 520, 440px 및 760px의 글자 200%를 검사해 16개 조건 모두 통과했다. 한 줄 중심 정렬, 입력창 내부 배치, 버튼 겹침과 문구 줄바꿈, 도넛 크기/글자, 접근성 이름/툴팁을 확인했다. design:check와 build:electron도 통과했다. 실제 사용자 앱은 macOS 키체인 확인 대기이므로 재시작 후 표시 확인과 구분한다.
