# 실행 기록과 인앱 터미널

기존 실행기의 승인과 결과 확인을 유지하면서 표시를 분리했다. 저장소는 최신순 목록을 반환하므로 대화에서는 오래된 실행부터 표시한다. 승인 대기는 현재 대화 맨 아래에 둔다.

- 승인 후 실행 ID로 같은 앱의 터미널 탭을 연다. 새 실행도 관찰하며 과거 대화 진입으로 탭을 자동 열지 않는다.
- 명령과 실제 출력, 종료 상태는 xterm 표면에 표시한다. 실행 중에는 500ms, 보이지 않는 탭은 1500ms 간격으로 읽으며 종료 후 조회를 멈춘다. 조회 실패는 자동 반복하지 않는다.
- 대화 기록은 기본 접힘이며 실행 상태가 같은 자리에서 바뀐다. 후속 사용자 요청으로 펼치면 기존 검정 TerminalBlock에 명령과 실제 출력, 종료 코드를 바로 표시한다. 접힌 동안 출력 렌더링을 생략하고 긴 출력은 영역 안에서 스크롤한다. 터미널 열기는 같은 실행 ID의 기존 탭으로 돌아가며 명령을 재전송하지 않는다.
- 에이전트 실행 기록은 읽기 전용이다. 직접 입력 버튼은 현재 설정된 기본 셸의 별도 PTY를 연다. 실행 중지는 기존 stop 경로를 사용한다. 기록 탭을 닫아도 실행 중인 프로세스를 임의로 중지하지 않는다.
- 대화의 질문, 실행 승인, 파일 반영/취소, 복구는 기존 호스트 계약을 유지한다. 새 의존성이나 외부 터미널 실행기를 추가하지 않았다.

검증: `check-command-terminal.mjs`의 실제 Electron/macOS Bash 실행과 모의 모델로 자동 탭 열기, 실행 결과, 접기 유지, 재열기 중복 실행 없음, 직접 입력, 한글, 작업 경로와 Ctrl+C를 검사했다. `check-external-ai-policy.mjs`에 합성 2개 완료 기록과 하단 승인 순서/440px 검사를 포함했다. Windows PowerShell/CMD/Git Bash 실행과 설치판 검증은 별도다.
