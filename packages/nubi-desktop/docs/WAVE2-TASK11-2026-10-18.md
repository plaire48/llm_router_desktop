# Wave 2 Task 11 — 이 대화의 사용량

로컬 구현과 전체 게이트를 완료했다. commit/push/릴리스는 하지 않는다.

대화 `…`의 사용량 아이콘에서 공통 모달을 연다. 계획, 본문, 검토, 요약, 분석, 하위 조사 6개 행에 실제 호출과 입력/출력/캐시 토큰을 합산한다. 기존 document/wiki_update 목적은 분석 행에 묶고 research는 하위 조사로 구분한다. 재시도도 실제 호출 수에 포함한다.

미제공 토큰은 `—`, 일부 호출만 집계된 값은 `*`다. 실제 0은 0으로 보존한다. 도구/압축/재시도 횟수와 모델 처리 시간 합계를 표시한다. 병렬 작업 시간을 실제 사용자 대기 시간으로 표시하지 않는다. 기존 지표는 새 작업 때 30일 이전 기록을 정리하므로 보관된 기록 기준이라는 한계를 표시한다. 비용과 추정 과금은 없다.
