# 메뉴 위치와 선택 창 CX

사용자 요청에 따라 AI Workspace 아이콘을 왼쪽 rail의 마지막 항목으로 옮기고 남는 높이를 위쪽 여백으로 사용한다. 화면에 이름을 반복하지 않고 접근성 이름과 툴팁은 유지한다. 열린 보조 화면 제목도 동일한 AI Workspace 자산 아이콘으로 표시한다. 이전 상단 배치 결정을 대체한다.

추론, 스킬, 승인, 변경 파일, 슬래시 명령 선택 창은 공통 `--nubi-picker-width:24rem`을 읽는다. 기본 384px이며 좁은 창에서는 화면 안으로 줄고 글자 확대에는 rem 기준으로 대응한다. 공통 본문 글자, 44px 이상 행, 12px 내부 여백, 선택 배경과 키보드 초점을 유지한다. 추론 메뉴의 별도 256px 제한을 제거하고 body portal로 옮겨 좁은 중앙 영역과 왼쪽 rail에 가리지 않도록 했다. 화면 좌표와 스크롤/resize를 따라 위치를 조정한다. 초기화는 아이콘과 툴팁으로 표시해 불필요한 글자가 세로로 쌓이지 않게 했다. 승인 설명과 항상 확인하는 작업 범위는 보존한다.

새 UI 라이브러리 없이 기존 CX 컴포넌트와 anchored modal의 초점/키보드/화면 경계 처리를 재사용했다. 격리된 Electron production 컴포넌트의 전체 화면 105개 검사를 통과했고 마지막 초기화 버튼과 승인 문구 수정 후 선택 창 6개와 새 모션 회귀 1개도 통과했다. 실제 사용자 앱은 macOS 키체인 접근 확인 대기이므로 새 renderer의 실제 앱 표시 확인과 구분한다.

추가 추론 설정 수정: 초기화 버튼의 24px 고정 grid 칸을 실제 버튼 크기에 맞는 auto 열로 바꿨다. 선택값은 한 줄로 유지하고 초기화/닫기는 같은 2.25rem 아이콘 버튼으로 정렬한다. 기본값 설명은 접근성 이름과 툴팁에만 남긴다. 440px와 1280px 선택 창 및 모션 회귀 총 7개, 디자인 검사와 Electron 빌드가 통과했다. 이 수정 시 실제 앱은 Mac 잠금으로 확인하지 못했다.
