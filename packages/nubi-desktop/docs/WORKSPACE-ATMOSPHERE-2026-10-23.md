# 흐르는 Workspace 배경

이 문서는 `0dc2a81`의 최초 색 필드 적용 기록이다. 이후 사용자 정정으로 시작/프로젝트 이동은 별도의 3D 유리 링 뒷배경으로 분리했다. 최신 범위와 브랜드 구성은 [후속 기록](SCENE-GLASS-BRAND-2026-10-23.md)을 따른다.

2026-10-23. 최종 사용자 요청은 여러 색의 올가닉 형태가 겹쳐 섞이며 화면 여러 위치를 실제로 가로지르는 느낌이다. 위아래 고정 방울과 리본 초안은 폐기했다. 처음에는 시작 진행/프로젝트 이동 두 장면으로 제한했고, 이후 사용자가 메인/채팅 배경도 명시적으로 추가했다.

## 적용 범위

- `CinematicIntro`의 로고/진행 바 단계와 `ProjectSwitchCover`의 프로젝트 이동 화면.
- `Workbench`의 메인/대화 콘텐츠 배경. 기존 두 SVG 모서리 장식을 이 영역에서 교체한다. 채팅은 같은 색을 낮은 불투명도로 표현한다.
- `ProjectStart`와 `NubiPreparing` 자체에는 새 배경을 넣지 않는다. 생성/연결 모달, 메일/위키/스킬의 기존 배경과 제공자 고유 색을 유지한다.
- 기존 시작 비행, 로고 원본, 글자/입력/초점, 실제 진행률, ready/실패/취소와 화면 전환 시점은 유지한다. 배경 완료를 기다리지 않는다.

## 구현과 선택

기존 누비의 mint/aqua/sky/periwinkle/iris/lavender 토큰을 사용한다. 여섯 색 중심은 서로 다른 연속 경로로 가로/세로를 이동한다. 경계가 휘는 색 필드를 한 프래그먼트 셰이더에서 합성해, 형태가 겹치고 분리되며 자연스럽게 섞이게 한다. 포인터 반응은 작은 감쇠 spring으로 제한한다. 48초는 기준 시간 척도이며 각 경로의 주기가 달라 동시에 처음 위치로 리셋하지 않는다.

제공된 3D 갤러리의 모핑/탄성/액체 합체 예제도 실제 재생하고 SVG/CSS 원본을 대조했다. 참고 HTML SHA-256은 `b06a234146a291bfc3ee5d359ec4f6457bf9a2a23c7fa9740bd3ac722a66c35c`다. 최종 제품은 사용자가 요청한 겹치는 그라데이션을 작은 2D 색 필드로 구현하며, 입체 구 메시나 범용 soft-body/유체 해석 엔진이라고 표시하지 않는다. 기존 낮은 픽셀 한도와 명시적 수명 관리 패턴을 재사용하며 새 라이브러리/네트워크/권한은 추가하지 않는다.

4정점과 1 draw/frame, 기본 그래픽 64,000 이하, 식별 가능한 소프트웨어 렌더러에서는 24,000 이하 backing pixel을 사용한다. 드라이버 문자열은 상태/로그/저장소로 보내지 않고 예산 선택에만 사용한다. 프레임마다 React 상태/DOM 치수/메시를 갱신하거나 화면 전체 blur/메타볼 SVG 필터를 실행하지 않는다. 중심/팔레트의 typed array를 재사용한다. 장시간 실행의 셰이더 시간 정밀도를 위해 지원 환경에서는 fragment highp를 사용한다.

숨긴 창, 화면 밖, 모달, 화면 전환과 프로젝트 이동 뒤 본문은 정지한다. 일반 준비 화면에 가려진 메인도 정지하며, 복귀 시 숨긴 시간만큼 급히 따라잡지 않는다. 모션 감소는 정적 그라데이션, 강제 색상은 장식 숨김, WebGL 실패/손실은 정적 대체다. 실패 시 프레임마다 context 생성을 재시도하지 않는다. 해제/복구 때 RAF/이벤트/observer와 GL 자원을 정리한다.

## 검증

- 관련 단위 45개, 디자인 토큰 검사와 기존 게이트 분할 보존 검사 통과. 중심별 가로/세로 이동 범위, 합체/분리와 60/120Hz 반응을 확인했다.
- 제품 컴포넌트 UI 50개 통과, 오류 0개. 1280/440px, DPR 1.5, 기본 Chrome 그래픽과 강제 SwiftShader를 구분했다. 시작/프로젝트 진행/ready, 메인/대화의 입력/초점/치수, 생성 모달 배경 제외, 가림/숨김/모션 감소/강제 색상과 GL 부재/손실/복구/해제를 확인했다.
- 4배 CPU 지연의 채팅 RAF 간격 P95는 기본 그래픽 약 16.7ms, SwiftShader 약 16.8ms이며 각 1.5초 표본의 50ms 이상 long task는 0개다. SwiftShader 최대 간격 33.4ms도 보존했다. 기본 64k 예산을 모든 환경에 쓰던 직전 측정은 SwiftShader P95 33.4ms였으며, 소프트웨어 24k 경로를 보완한 뒤 별도로 재측정했다. 짧은 로컬 표본이며 Windows의 실제 표시 FPS나 GPU 사용률 개선 증명은 아니다.
- GL 손실/복구와 해제 뒤 버퍼 생성/삭제는 각 조건 2/2였다. GPU 없는 화면은 생성 시도 1회/그리기 0회, 초기 모션 감소는 GPU 시도 0회였다.
- 실제 빌드 Electron에서 메인 배경, 새 배경이 없는 생성 모달, 두 임시 프로젝트의 실제 열기 단계/성공/실패 복원과 모션 감소를 확인했다. 로딩 canvas는 WebGL/실행 중, 63,756픽셀이었다. 이 검사는 합성 응답만 렌더링한 fixture와 구분하며 사용자 프로젝트/모델/사내 서비스 성공을 뜻하지 않는다.
- 기존 진행 바 UI 28개 통과. 실제 값/미확정 채움/모달/시작/프로젝트/ready 계약을 보존했다.
- `build:electron` 통과. 기존 Windows Bash CJS/import.meta 경고와 macOS에서 PowerShell 파서 검사를 생략한 사실은 유지한다.

검증 결과는 `verification/workspace-atmosphere-2026-10-23/`에 기록한다. 실제 앱 결과는 `verification/project-switch-cover-2026-10-23/`에 기록한다. 이전 방울 초안과 실패 로그는 별도 보존하며 최종 성적에 합치지 않는다. 첫 검사는 테스트가 기존 대화를 선택하지 않아 대화 화면을 기다렸고, 후속 검사는 사이드바가 접히는 중의 너비를 정적인 너비와 비교해 실패했다. 기존 대화를 실제로 열고 레이아웃 안정 후 비교하도록 검사 경로를 정정했으며 배경의 입력 보존 단언을 제거하지 않았다.

이번 범위는 macOS의 소스/로컬 Chrome/Electron이다. 전체 게이트, 실제 모델/사내 계정과 Windows GPU/드라이버/설치/업데이트 검증은 각각 별도다. 새 UI 회귀는 기존 게이트를 제거하지 않고 Electron 게이트에 추가했다. `npm run test:workspace-atmosphere`로 재실행한다. 기존 `NUBI_SHARED_RUNNER=1` 계약에서는 기능 검사를 모두 유지하고 시간 표본은 공용 미판정 원장에 남긴다. 로컬/목표 기기에서는 시간 한도를 실제로 판정한다.
