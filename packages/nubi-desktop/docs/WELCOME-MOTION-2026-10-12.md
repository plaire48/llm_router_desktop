# 중앙 누비 모션 복원

기존 Desktop 밀도 CSS가 AgentMark의 전체 애니메이션을 초기화하고 중앙 새를 2px 호흡으로 제한해 날개 프레임이 보이지 않았다. 사용자 후속 요청에 따라 중앙 새의 날개짓과 비행, 호버 인사를 복원했다.

기존 공유 AgentMark와 원본 날개/눈/웃음/슬픔 자산을 그대로 사용한다. 별도 캐릭터나 모션 라이브러리는 추가하지 않았다. 하나의 8초 비행 경로(좌우 4px, 위로 최대 8px)와 호버 중 작은 회전만 조합해 중복 이동을 피한다. 고정된 welcome-art 영역을 호버 대상으로 사용해 움직이는 새의 경계에서 인사가 반복 시작되지 않도록 했다. 호버를 유지하면 기존 1.8초 인사 타이머 이후에도 미소와 춤이 유지된다.

입력창 초점만으로 중앙 새를 멈추지 않는다. 수면/슬픔 상태에서는 비행을 멈추고 원래 표정을 유지한다. 작은 로고/답변 새의 위치 고정, OS 모션 감소, 모달과 비활성 화면의 정지 계약을 유지한다. 모션은 장식이며 진행률이나 작업 성공을 표시하지 않는다.

검증은 실제 production 컴포넌트와 Electron CSS를 사용하는 격리된 Electron 화면에서 수행했다. 비행 경로, 날개 프레임, 호버 2초 후 미소/춤 유지, 호버 해제, 수면/슬픔 표현, 입력 초점, OS 모션 감소를 확인했다. 수면/슬픔은 CSS 상태를 주입한 렌더링 검사이며 실제 모델 실행 성공의 증거가 아니다. 디자인 검사와 Electron 빌드를 통과했다.
