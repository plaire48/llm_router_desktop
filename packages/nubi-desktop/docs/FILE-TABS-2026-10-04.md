# File selection and editing tabs

The file explorer now selects a file on one click and opens it in an individual tab on double-click or Enter. It does not automatically mount an inline preview on the first click. The empty editor placeholder and file-selection instruction are absent. Returning to the explorer tab shows the list across its available width; opened file tabs remain available.

Opening a file tab closes the explorer so the editor gets the entire auxiliary pane width. The existing explorer toggle can reveal the tree again. Explicit file-change/source navigation still reveals the selected file and its ancestor folders. Late or superseded file reads return no presented file, so they cannot close the explorer for a newer selection.

The existing React Arborist and Monaco implementations are reused with no new dependency. Arborist's installed Enter handler is for rename and does nothing with editing disabled; the host therefore handles Enter as activation inside the tree only. Arrow navigation, path/filter inputs and folder expansion keep their original behavior. Monaco models, dirty state, undo and saved editor view state remain in the existing buffer cache; switching to the explorer does not dispose an opened file model. Existing hash/readback and dirty-close protection are unchanged.
