# Git 가져오기 진행률

Git URL과 사내 저장소 선택은 같은 clone 경로를 사용한다. `git clone --progress`의 CR 구분 진행 출력을 단계별로 해석해 Electron host event로 전달한다. 단계별 퍼센트/처리 개수와 Git이 제공한 전송량/속도만 표시하고, 전체 예상 퍼센트나 남은 시간을 만들지 않는다. 연결 및 프로젝트 열기는 불확정 진행 바와 경과 시간으로 표시한다.

기존 프로젝트 전환 가림 화면, 누비 브랜드와 공통 CX 색상/서체/간격을 사용한다. 요청 ID가 일치하는 이벤트만 반영하고 성공/실패/취소 종료 때 진행 상태를 해제한다. 원문 stderr, URL, 경로, 인증값은 전달하지 않는다. 사내 인증 전달과 실패한 복제 폴더 보존을 유지한다. Git의 종료 이벤트 뒤에도 남은 진행 출력을 읽은 후 close에서 완료를 결정한다.

검증: 실제 로컬 Git 전송과 진행 파서, 성공/실패 완료 경계 및 인증 격리 9개 검사 통과. 1000px/360px 실제 컴포넌트 렌더링에서 퍼센트, 불확정 전환, 모션 감소와 가로 잘림을 확인했다. 기존 Electron 프로젝트 왕복과 초안 보존도 통과했다. 로컬 Git daemon에서 실제 Electron의 주소 입력, 저장 폴더 선택, clone 진행 IPC, 퍼센트 렌더링과 프로젝트 열기까지 통과했다. 회사망 사내 인증 및 Windows MinGit은 이 변경의 실환경 검증 대상이며 새 설치 파일은 배포하지 않았다.
