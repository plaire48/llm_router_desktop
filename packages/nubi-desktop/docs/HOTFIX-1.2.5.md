# 누비 Workspace Beta 1.2.5

1.2.4를 회사 PC에서 써 본 뒤 받은 보고를 고친 빌드입니다. 같은 1.2.5 번호로 다시 올린 빌드에는 아래 '다시 올린 빌드' 항목이 더 들어 있습니다. 1.2.4의 변경은 `docs/HOTFIX-1.2.4.md`에 있습니다.

## 고친 것

- **Talk·문의 오류**: AI Workspace에서 Talk이나 문의를 누르면 "Cannot read properties of null (reading 'has')"가 나던 문제. 앱 안 화면에 원래 웹앱과 같은 화면 상태 저장소를 두었습니다.
- **앱 목록 '연결을 확인하고 다시 불러오세요'**: 로그인 정보가 앱 목록 화면보다 늦게 전달되어, 로그인하지 않은 것으로 읽고 실패하던 문제. 화면을 그리기 전에 로그인 정보를 넘깁니다.
- **포털 로그인 확인**: 포털(http://samsung.net)에서 로그인한 뒤에도 확인이 시작되지 않던 문제. 로그인 창이 포털 첫 화면에 머물러도, 같은 회사 세션으로 메일 주소를 직접 열어 로그인을 확인합니다(최대 6초 간격).
- **처음 실행 안내**: 안내 카드가 창 위쪽 바깥에 놓이던 문제. 시작할 때 뜨는 메일 연결 창이 닫힌 뒤에 나오고, 짚는 곳 옆 빈 자리에 항상 창 안으로 놓이며, 화면을 어둡게 하지 않습니다.
- **시작 장면**: 느린 PC에서 시작 작업과 겹쳐 순식간에 지나가던 문제. 첫 장면에서 기다렸다가(최대 2.5초) 처음부터 끝까지 재생합니다.

## 다시 올린 빌드에서 고친 것

- **포털 로그인 '확인 중'이 끝나지 않음**: 페이지 안에서 실행하는 스크립트의 포털 주소 자리표시가, 빌드 과정에서 따옴표 모양이 바뀌어 실제 주소로 바뀌지 않았습니다. 그래서 로그인해도 메일 확인 요청이 엉뚱한 주소로 가 늘 실패했습니다. 따옴표 모양과 상관없이 바꾸고, 못 바꾸면 바로 오류를 내며, 빌드된 결과로 검사합니다. 로그인 창이 samsung.net 첫 화면이나 kor3 포털 홈에 머물러도 이어서 확인합니다.
- **연결 취소가 듣지 않음**: 취소 요청의 번호가 진행 중인 연결과 맞지 않으면 무시했습니다. 연결 중이면 번호와 상관없이 멈춥니다.
- **Talk '게시판 응답을 확인하지 못했습니다'**: 게시판 읽기가 앱 호스트를 거치지 않고 빈 토큰으로 바로 요청했습니다. 다른 화면처럼 앱 호스트로 읽습니다.
- **문의 '문의를 불러오지 못했습니다'**: 같은 경로를 쓰도록 정리하고, 실패하면 원인 코드를 문구 뒤에 붙입니다. 회사 계정 확인은 2분 동안 다시 쓰고 401이면 새로 읽습니다.

## 바뀐 것

- **진행 중 답변 말풍선 없앰**: 작업 중에는 위쪽 답변 말풍선을 만들지 않고 생각하는 내용만 보여 줍니다. 답변은 끝나면 한 번에 나옵니다.
- **'보완할 결과가 있어요'**: 접힌 한 줄로 대화 맨 아래에 놓고, 다음 단계는 그 아래에 보입니다. 누르면 남은 확인과 확인 항목이 펼쳐집니다.
- **문의 머리글**: 위아래 두 줄을 한 줄로. 도움말(?)은 위 줄로 올렸습니다.
- **AI Workspace와 문의**: 좌우 여백 없이 창 너비를 다 씁니다. 뒤로(←) 버튼을 없애고 그 자리에 왼쪽 메뉴의 아이콘을 둡니다. 뒤로 가기는 Esc.
- **위키 페이지 이동**: 스킬처럼 아래 번호 페이지 하나로.
- **상태 이모지**: 프로필 사진 모서리 대신 이름 오른쪽에(모든 프로필).

- **기본 화면**: 폴더 프로젝트 없이 개인 대화만 있으면 '프로젝트를 열어 주세요' 화면이 먼저 나옵니다. 새 대화나 기존 대화를 고르면 바로 대화로 갑니다.

## 회사 PC에서 확인할 것

Talk·문의·앱 목록이 로그인 뒤 열리는지(실패하면 문구 뒤 괄호 속 코드), 포털 로그인 뒤 확인이 시작되는지, 처음 실행 안내 위치, 창 조절 버튼(- □ ×) 호버 음영.
