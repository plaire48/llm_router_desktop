# MCP 승인과 실행 인자 표시

2026-10-15. 승인 뒤 멈춤, 반복 승인, 인앱 화면 미표시의 공통 경로를 수정했다.

## 확인한 원인과 수정

- `persistTask`가 `pendingMcp`와 승인 정보를 저장하지 않았다. 질문 답변을 처리할 때 실행 대상을 복원하지 못했다. 이제 대기 호출과 승인 상태를 저장한다.
- 승인 후 모델이 같은 호출을 다시 만들어야 하던 경로를 없앴다. 호스트가 승인된 정확한 인자로 한 번 실행한 뒤 결과를 다음 모델 호출에 전달한다.
- ‘항상 허용’은 현재 프로젝트의 해당 서버/도구에 저장한다. 다른 도구, 다른 프로젝트에 승인을 확대하지 않는다. ‘실행’은 이번 호출만, ‘취소’는 실행하지 않는다.
- 실행 여부가 불확실하거나 앱이 실행 중 종료된 경우 같은 호출을 자동 재전송하지 않는다. 재개 시 미확정 영수증을 전달해 상태 확인을 요구한다. JSON 객체의 키 순서만 바뀐 요청도 같은 호출로 판정한다.
- MCP 도구 이름이 화면의 고정 어휘 목록에 없어 실행 기록에서 빠졌다. 검증된 MCP 이름을 동작 중심 이름으로 표시한다.

## 화면과 권한

- 승인 폼에는 동작 이름, 서버/도구, 들여쓴 JSON 인자, 이번 실행/프로젝트 내 항상 허용/취소를 표시한다. 자유 입력으로 승인 문구를 조합하지 않는다.
- 실행 기록의 MCP, 스킬 읽기와 명령 준비 항목에서 인자를 펼칠 수 있다. 공통 글꼴/색상/여백을 사용하고 긴 JSON은 내부 스크롤로 표시한다.
- 비밀번호, 토큰 등 민감한 키와 URL 인증값은 표시용 사본에서 숨긴다. 생략된 긴 값은 생략 사실을 표시한다. 표시용 값을 실행 인자로 재사용하지 않는다.
- 스킬 지침/자료 읽기는 읽기 전용으로 표시한다. 스킬을 읽었다는 사실이 명령 실행이나 파일 반영 승인이 되지 않으며 기존 권한 정책과 반영 폼을 유지한다.

## 검증 범위

- MCP/권한/프로젝트/인자 표시 관련 회귀 28개 통과. 실행, 항상 허용, 취소, 응답 유실, 중단된 호출의 자동 재실행 차단을 포함한다.
- 스킬 문맥, 명령 준비/승인, 새 파일 생성 관련 회귀 30개도 통과했다. 표시 기능이 실제 실행 권한을 넓히지 않는지 함께 확인했다.
- 실제 macOS Electron의 승인 폼 → worker IPC → 공식 Playwright MCP → native 인앱 WebContentsView에서 페이지 열기, 입력, 클릭, DOM 결과 확인을 통과했다.
- 앱을 실제 종료/재실행한 뒤 저장한 항상 허용으로 다른 URL과 인자가 반복 질문 없이 실행됐다. 720px 폭에서도 폼과 승인 버튼이 잘리지 않는다.
- 완료한 작업 기록을 펼쳐 입력값 등 JSON 인자가 남아 있는 것도 실제 렌더링에서 확인했다(`completed-arguments.png`). 최종 승인 폼 응답은 열기 76ms, 입력 89ms, 클릭 87ms였다.
- 직접 MCP 검사에서 세션 재사용, 재연결, 인증 탭 차단, 다른 탭 보호와 문서 변경 후 오래된 참조 차단을 확인했다.
- `npm run build:electron` 통과. 설치 파일 배포는 수행하지 않았다.

증거: `verification/mcp-approval-2026-10-15/result.json`, `approval-arguments.png`, `approval-narrow.png`, `native-page.png`. 재현 실행기: `scripts/check-electron-mcp-approval.mjs`.

모델 응답은 고정 fixture이고 웹사이트는 로컬 시험 페이지다. 실제 Windows 설치판, 사내 로그인과 AI Pro/GLM 실모델 성공으로 확대하지 않는다. `approvalReturnMs`는 폼 제출 후 사라지는 시간이며 전체 도구 또는 모델 지연이 아니다. Renderer 스크린샷에는 native 웹뷰가 포함되지 않아 별도로 실제 WebContents의 픽셀과 visible/bounds, DOM을 확인했다.

공식 MCP와 기존 탭/문서 바인딩을 유지했다. 별도 브라우저 실행이나 앱 전체 디버깅 포트 공개 대신 기존 인앱 어댑터를 사용했다. 설계 근거는 `PLAYWRIGHT-MCP-2026-10-15.md`의 공식 패키지 검토를 재사용한다.
