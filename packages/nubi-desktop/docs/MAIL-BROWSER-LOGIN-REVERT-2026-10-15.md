# 메일 로그인 화면 원복

사용자 결정: 누비 자체 아이디/비밀번호 입력 대신 기존 회사 로그인 화면에서 직접 입력한다.

- 로그인 클릭 시 기존 세션을 먼저 확인한다. 유효하면 로그인 화면을 열지 않는다.
- 로그인이 필요하면 기존 인앱 회사 포털 탭을 연다. 누비 연결 모달은 먼저 닫아 입력을 가리지 않는다.
- 자체 자격 증명 IPC를 거부하고 숨은 자동 입력 경로를 연결에서 제거한다.
- 로그인 후 메일 페이지로 이동하지 않고 등록된 포털 홈에 머물러도 고정 메일 API로 공유 세션을 확인한다. 다른 SSO 페이지와 알려진 로그인 경로에서는 확인을 보류한다.
- 회사 페이지의 POST, 팝업 opener, 리다이렉트와 공유 세션은 기존 BrowserHost가 처리한다.
- abnormal-logout/logout 후 명시적 재로그인, 원문 저장 경로 안내, 5분 수집과 기존 메일은 유지한다.
- 로그인 실패는 기존 CX 오류 안내에서 다시 시도한다. 자동 인증 반복과 시작 시 로그인 창 열기는 하지 않는다.

검사: 로그인/세션 회귀 50개, 실제 컴포넌트 UI의 세션 재사용·폼 제거·오류 재시도, 격리 Electron의 POST 팝업·리다이렉트·로그아웃 복구를 확인한다. 회사망의 실제 SSO 성공과는 구분한다.
