# Wave 2 Task 10 — 대화 Markdown 내보내기

로컬 구현과 전체 게이트를 완료했다. commit/push/릴리스는 하지 않는다.

대화의 `…`에서 다운로드 아이콘으로 Markdown을 내보낸다. 기존 가로 아이콘 메뉴와 접근성 이름/툴팁을 재사용한다. 요청, 답, 챕터 위치와 실행별 접힌 도구 기록을 유지한다. 저장된 도구 인자 중 path/query/script/title만 내보내고, 실제 저장 형식인 arguments.text도 JSON으로 해석한다. 없는 인자는 추정하지 않는다. 메일 참조는 제목과 ID만 포함하며 원문/HTML/도구 결과는 내보내지 않는다. 인증 필드는 제외하고 인증값 패턴이 있는 명령/조회 줄은 숨긴다.

서비스는 저장하지 않은 내보내기 스냅샷을 반환한다. Electron이 사용자 저장 경로를 받고 UTF-8 파일을 쓴 뒤 SHA-256으로 재확인한다. 취소와 프로젝트 변경은 쓰지 않는다. 재읽기 불일치 때 사용자가 고른 기존 파일을 임의로 삭제하지 않는다. 원래 대화 저장소는 변경하지 않는다.
