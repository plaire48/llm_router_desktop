# 누비 Workspace Beta 1.2.10 테스트 배포

- Word 페이지와 표, PowerPoint 슬라이드와 메모, Excel 셀과 수식의 변경 미리보기를 설치판에 포함합니다. 원본 비교, 변경 강조, 직접 초안 수정과 Excel 계산 검증을 같은 승인 화면에서 사용합니다. Word와 PPT는 관찰한 속성을 바탕으로 표시하며 실제 Office 렌더링과 다를 수 있습니다.
- Excel의 수정된 셀과 PowerPoint의 수정된 개체에는 선택 여부와 관계없이 옅은 음영을 유지합니다. 원본을 잠깐 볼 때는 변경 음영을 숨깁니다.
- 미리보기를 접을 때 렌더링을 해제하고 다시 펼칠 때 스크롤과 검토 위치를 복원합니다.
- PDF 일반 텍스트 입력란을 대화에 연결해 읽고, 승인 후 변경하고 다시 확인합니다. 오른쪽 PDF를 연 뒤 스킬 관리에서 문서 편집기 연결 > 누비에서 편집을 선택합니다.
- 외부 PDF 앱 연결을 제거했습니다. PDF는 누비에서 열어 일반 텍스트 입력란을 수정하고 사본으로 저장합니다.
- 좁은 창에서 채팅 입력을 시작하면 오른쪽 미리보기를 접습니다. 문서 연결과 편집 내용은 유지됩니다.
- 같은 PDF를 다시 열어도 편집 버퍼를 유지합니다. 원본 파일이 바뀌면 미저장 내용을 덮어쓰지 않습니다.
- PDF 원본은 유지합니다. 확인한 변경은 PDF 사본 저장으로 새 파일에 저장하고 되돌릴 수 있습니다. 일반 본문, OCR, 서명과 주석 수정은 지원하지 않습니다.
- Word, Excel, PowerPoint의 기존 native 연결, 누비 PDF 편집 및 Obsidian 연결을 설치판에 포함합니다. Office 창과 문서는 사용자가 선택하고 기존 승인과 저장 계약을 유지합니다.
- 연결한 문서의 변경 검토, 적용 확인, 미저장 상태를 대화에 표시합니다. 저장 확인이 없는 결과를 저장 완료로 표시하지 않습니다.
- 선택한 첨부 스냅샷과 프로젝트 텍스트 파일의 정확한 숫자 범위를 대조합니다. 출처 버전이 바뀌면 중단하고 수치 불일치를 남깁니다. 단위와 업무 의미 검증은 별도입니다.
- 기존 브라우저, 메일, 위키, 파일과 터미널 기능을 유지합니다. 메모장 앱 연결은 제외합니다.

Windows 11 회사 PC, Office 2016/NASCA, 실제 Obsidian 앱, 회사 로그인과 메일 수신, 창 도킹과 애니메이션 품질은 설치 후 테스트 대상입니다. CI 설치 검사는 해당 환경의 업무 성공을 의미하지 않습니다.
