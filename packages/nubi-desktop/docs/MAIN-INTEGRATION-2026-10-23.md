# 완료한 변경의 main 반영

2026-10-23. 사용자가 지금까지 완료한 변경을 main에 반영하고, 앞으로도 개발 완료 뒤 원격 main 반영까지 진행하도록 요청했다.

## 대상과 범위

대상은 `plaire48/llm_router_desktop`의 `main`이다. 기존 main `7bc005dfe723a398c9cd1a24f86e83958ca51efd`에서 별도 작업본을 만들고 마지막 공유 소스 tree `ffac8612` 이후의 완료한 변경을 3방향으로 합쳤다. 원래 `llm_router` 작업 폴더의 제품 소스를 덮어쓰거나 Git checkout을 바꾸지 않았으며 새 전달 규칙만 AGENTS에 함께 추가했다. 라우터 저장소의 origin/main에는 푸시하지 않았다. 캐시, 인증값, 설치 파일과 verification 결과를 소스 커밋에 넣지 않는다.

공식 OpenCode 코딩 실행기, Python 도구 재개/서버 수명 보호, 확장 없는 외부 브라우저와 Samsung/CLIXML 후속, POP3 연결 직후 알림과 폼 닫기, 실시간 결정 폼/초안/하단 상태, 대화 너비, 모션 아틀라스와 공통 채움 진행 바의 완료한 소스를 포함한다. 기존 main의 코딩 지도, 명령 앞부분 승인, 되돌리기, 메일 포털과 POP3 아이디 기억, 화면 상태 보존과 CSS 정리도 함께 보존한다. 워크플로우와 A2A 비활성 계약은 유지한다.

루트와 Desktop `AGENTS.md`에 완료한 변경을 검증한 뒤 해당 제품 원격 main까지 반영하는 사용자 지시를 기록했다. 기존 자동 push 금지와 업로더 담당 제한은 이 명시한 전달 범위에서 대체하며, 강제 푸시/reset/clean/자동 stash와 미완료 변경 일괄 커밋은 허용하지 않는다.

## 충돌 처리

- OpenCode 편집은 exact를 기본으로 하고 명시한 `matching=opencode`에서만 원본의 관찰된 공백/들여쓰기 matcher를 사용한다. 문자열의 따옴표/대시를 다른 문자로 간주해 바꾸는 자동 fallback은 적용하지 않는다. 기존 `replaceAll`과 오류의 관찰된 가까운 줄 안내는 보존하며 모든 변경 구간의 현재 해시/읽기 범위를 확인한다.
- 원본 matcher가 끝 줄바꿈을 후보에서 제외하는 경우 요청한 실제 줄바꿈까지 한 번 소비한다. CRLF와 바로 다음 빈 줄 보존을 회귀로 확인했다.
- main의 유휴 장식 정지 목록과 새 진행 바의 활성 모달/숨김/모션 감소 정지를 함께 유지한다. 진행률을 시간으로 완료 처리하지 않는다.
- main의 POP3 아이디 기억과 새 연결 상태/취소 보호를 합쳤다. 공유 OpenWiki POP3 전송기의 인증 직후 관찰도 함께 포함해 실제 worker 경로에서 신호를 잃지 않는다.
- 기존 명령 승인 설명과 새 즉시 폼 닫기를 함께 유지한다. 실제 종료 출력 대기 검사도 보존한다.
