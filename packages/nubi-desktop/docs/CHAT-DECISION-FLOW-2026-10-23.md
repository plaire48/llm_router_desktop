# 채팅의 순서와 질문/승인 표시

대화 본문, 입력창과 질문/승인 폼은 좌우 패널 사이의 가용 너비를 채운다. 70rem 상한 대신 공통 너비 토큰을 100%로 사용하고 기존 좌우 여백을 유지한다. 본문, 공개 진행 발화, 계획 제목과 폼의 질문 문구가 같은 왼쪽 시작선을 사용한다. 선행 아이콘은 열 안의 공통 여백에 두며 스크롤 경계에서 잘리지 않는다.

`ConversationDecisions`는 질문, 도구/명령 승인과 파일 반영 제안의 대기 폼만 입력창 위에 연결한다. 실제 대기 수를 기준으로 하나만 보이고 복수면 `1/n`과 이전/다음을 제공한다. 나머지는 hidden/inert로 초안과 선택을 유지한다. 렌더링, 페이지 이동과 알림 클릭은 승인하거나 실행하지 않는다. 기존 호스트의 승인 ID, fingerprint, 비활성 조건과 오류 복구를 사용한다.

후속 사용자 요청: 제출한 폼은 작업 완료까지 비활성으로 붙잡지 않는다. 즉시 hidden/inert로 전환하고 대기 수에서 빼되 마운트를 유지해 초안/선택/오류를 보존한다. 대화에는 실제 처리 상태, 공개 작성 초안과 명령 출력을 이어 보여 준다. 실패하면 폼을 복원하며 확인되지 않은 실행을 성공으로 표시하거나 자동 반복하지 않는다. 작업 변경 신호와 현재 범위 재읽기를 연결하고 폴링은 복구 수단으로 유지한다. 문법 검사 범위 배지 대신 모델이 검증을 담당하며 구체적 미확인 항목만 남긴다. 상세 근거는 `../../../docs/research/2026-10-23-codex-progress-review-benchmark.md`다.

질문이 끝나면 원래 질문 메시지 위치에 닫힌 답변 기록을 남긴다. 명령은 기존 실행의 접힌 영수증으로 돌아간다. 작업 계획과 진행 기록은 `responseTiming.afterMessageId`를 기준으로 질문 대기 중에도 제자리에 둔다. 파일 변경 계획은 자신의 runId에 연결한다. 변경 파일은 실행별로 접고 명시적으로 펼칠 때만 목록을 조회하며 대화 변경 뒤 늦은 응답은 표시하지 않는다.

인접한 실패 단계는 한 진행 기록으로 묶고 기본으로 접는다. 실제 error/cancelled 상태와 진단 코드를 바꾸거나 완료로 승격하지 않는다. 검토 실패도 중립적인 요약을 접힌 상태로 표시하고 원인과 코드는 펼쳐서 읽는다. 같은 실행 오류의 알림은 대화 재진입 때문에 반복하지 않는다.

대기 폼의 재질은 기존 `--nubi-glass-control`, edge, shadow와 `blur(24px) saturate(140%)` 토큰을 사용한다. 단일 선택 질문은 기존 `GlassSurface`의 선택 면을 재사용한다. 텍스트는 굴절하지 않는다. 투명도 감소와 강제 색상/미지원에서는 기존 대체 재질을 사용하며 초안/선택/전송 기능을 유지한다.

## 확인

- 관련 Node 검사 27개와 기존 유리 spring/모션 검사 7개 통과.
- 실제 Electron renderer에서 제품 Workbench와 최종 CSS를 사용한 합성 대화 5개 장면 통과. 1280/440/360px에서 본문/진행/계획/질문 시작선, 한 폼, 초안 유지, 즉시 접힘, 계획 위치, 변경 파일 접힘과 WebGL 선택 면을 확인했다. 440px 글자 200%도 넘침 없이 전송 가능했다. 추가 검토 오류 1280/440px에서는 원래 오류 상태와 상세 코드를 유지했다.
- Chrome에서도 동일 흐름 5개 장면 통과. CDP로 투명도 감소/강제 색상을 켜서 대체 표시와 선택 유지를 확인했다. 실제 OS 설정 전달을 검증했다는 뜻은 아니다.
- 기존 질문/명령 승인 3개 너비와 알림 이벤트 bridge 검사 통과. 알림 전달은 모의이며 실제 명령은 실행하지 않았다.
- 변경 파일 목록과 실제 Monaco 비교 검사 통과. 기본 접힘, 펼치기/키보드/대화 변경 뒤 늦은 열기 차단/오류 후 재조회도 확인했다.
- 기존 채팅 화면 6개와 초기 입력창 5개 장면 통과.
- `npm run design:check`, `npm run build:electron` 통과. 마지막 정렬/계획 바인딩 보완 뒤 TDZ 검사와 renderer 재빌드를 수행했다. 기존 Windows Bash CJS import.meta 경고와 macOS의 PowerShell 검사 생략은 남는다.

화면과 결과: `verification/conversation-decisions-2026-10-23/`, 실제 Electron renderer는 하위 `electron/`에 저장했다. 사용자의 현재 대화나 연결 계정을 사용하지 않았다. 실행 중인 앱을 재시작하거나 설치판을 업데이트하지 않았다. 이 기록은 실제 제공자/사내 SSO/Windows/설치판 검증이 아니다.
