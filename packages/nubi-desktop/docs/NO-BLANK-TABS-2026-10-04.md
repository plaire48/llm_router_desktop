# 오른쪽 새 탭 제거

- 사용자 요청: 오른쪽 사이드바의 새 탭 제거.
- 도구 메뉴에는 터미널과 파일만 표시한다. 브라우저 메뉴의 새 탭도 제거한다.
- 빈 `about:blank` 페이지는 탭 목록에 표시하지 않는다. 브라우저 아이콘에서 주소를 입력하면 실제 페이지를 열며 열린 페이지의 전환과 닫기는 유지한다.
- 기존 CX 메뉴와 Electron WebContentsView를 재사용한다. 새 의존성은 추가하지 않는다. 인증/링크, 격리된 세션과 기본 단축키는 유지한다.
- 확인 범위: `npm run build:electron` 성공. 4320 예시 화면에서 도구 메뉴가 터미널/파일만 표시하는 것을 직접 확인했다. 자동 테스트는 실행하지 않았다. 실행 중인 Electron 재로드와 실제 네이티브 페이지 이동은 확인하지 않았다.
