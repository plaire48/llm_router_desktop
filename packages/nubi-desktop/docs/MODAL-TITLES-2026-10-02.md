# Modal titles and shared starting insets

검색은 대화 검색 모달로 열고 제목과 검색 입력 앞에 돋보기를 표시한다. 검색 모달 안의 새 대화 + 버튼은 제거했다. 검색 버튼의 접근성 이름/툴팁도 대화 검색으로 맞춘다.

| 화면 | 제목 |
| --- | --- |
| 대화 검색 | 대화 검색 |
| 설정 | 설정 |
| 메일 연결/수집/정리 설정 | 메일 설정 |
| 스킬 등록/목록 | 스킬 관리 |
| 프로젝트 문서/검색 | 프로젝트 자료 |
| 제공자/모델 연결과 선택 | 모델 선택 |
| FabriX 자격 증명 | FabriX 연결 |

| 비활성 Computer Use | 앱 연결 (비활성 유지) |

기존 DetailPanel과 SearchInput을 재사용한다. 모든 deck-dialog 모달의 헤더 상단/좌우 시작은 공통 토큰으로 기본 24px, 600px 이하 16px이다. 제목 줄은 공통 34px 높이를 확보하고 제목 h2의 기본 margin을 제거한다. 본문과 하단은 같은 좌우 시작을 공유하며 본문의 위아래 여백은 16px이다. 모델 모달의 개별 여백 예외를 제거하고 자식 화면의 뒤로 버튼도 공통 제목 시작점으로 이동한다. 추론/스킬/도구의 작은 비모달 팝오버는 기존 별도 크기를 유지한다.

Desktop은 공유 모델/컨텍스트/FabriX 컴포넌트에 제목을 전달한다. 브라우저 확장 소비자는 기존 기본 제목을 유지하며 공유 소스를 복제하지 않는다. 삭제 대상/원본 보존 안내와 연결·승인 계약은 유지한다.

확인 범위: 소스 제목/모달 목록 점검과 Electron 빌드. 사용자 결정에 따라 테스트는 실행하지 않는다. 기존 2026-10-01 모달 검사 문서는 당시 결과이며 이번 수정의 실화면 검사 결과로 취급하지 않는다.
