# 프로젝트 시작과 위키 준비

사용자 결정 2026-10-04: 모델을 연결한 다음 중앙 화면에서 폴더 또는 Git URL을 선택한다. 왼쪽 폴더 버튼은 이 화면을 연다. Git은 사용자가 고른 상위 폴더 아래에 새 저장소 폴더를 만들며 기존 폴더를 덮어쓰지 않는다.

## 적용

- 이전 프로젝트 복원은 기존 대화와 위키를 읽는다. 위키가 없다면 모델 연결 후 시작 카드를 보여준다. 로그인만으로 복원된 폴더의 위키 생성을 시작하지 않는다.
- 폴더 또는 저장소를 명시적으로 열면 선택한 모델로 위키를 백그라운드에서 준비한다. 카드의 모델 선택은 기존 모델 모달을 재사용한다. 대화로 돌아가기와 파일 선택 취소는 현재 프로젝트와 초안을 보존한다.
- 기존 OpenWiki 고정 소스의 `repository_progress` 이벤트를 재사용한다. 문서 생성의 `pageIndex`는 시작하는 문서 번호이므로 완료 수는 `pageIndex - 1`이다. 파일 복사와 저장은 실제 readback 완료 수를 사용한다. 분석과 검토처럼 전체 작업량을 알 수 없는 단계는 퍼센트를 만들지 않고 시작 시각에 따른 정수 초 경과 시간을 표시한다.
- 하단의 기존 백그라운드 상태 영역에 위키 상태를 함께 표시한다. 위키 화면에는 단계별 진행 막대와 실제 처리 수를 표시한다. 단계별 퍼센트는 전체 완료율로 표현하지 않는다.
- 같은 프로젝트의 초기화 준비와 실행을 중복 시작하지 않는다. 프로젝트 전환 시 이전 실행을 취소하고 새 프로젝트가 이전 컨트롤러에 막히지 않게 한다. 취소와 중단은 자동 재개하지 않는다.
- Desktop에서 보이는 명칭은 위키로 통일한다. `openwiki/` 저장 경로, 패키지 이름과 API 식별자는 보존한다.
- 버튼 누름은 공통 토큰으로 99% 축소와 110ms 반응을 사용한다. 큰 카드의 크기는 고정하고 보조 화면 진입 이동을 18px에서 6px로 줄인다. 배경과 새의 유영은 유지한다.

## 방법과 도입 판단

기존 누비/CX 버튼, 입력과 모델 모달, OpenWiki의 실제 이벤트 계약, native Git 복제를 재사용했다. 별도 UI 라이브러리나 진행률 라이브러리는 추가하지 않았다. 단계별 선택으로 필요한 입력만 펼치며 실제 이벤트로만 진행을 표시한다. 공개 모델 인증과 파일 저장 승인 경계는 변경하지 않았다.

## 확인 범위

사용자 지시에 따라 Electron 빌드만 수행한다. 자동 테스트와 실제 계정 위키 생성은 별도 실행하지 않는다. 현재 연결된 메일을 유지하기 위해 실행 중인 백엔드는 재시작 승인 전까지 보존한다. 신규 경과 시간과 복원 동작은 새 백엔드로 재시작해야 적용된다.

Electron 빌드가 완료됐다. 별도 예시 데이터 미리보기에서 왼쪽 폴더 버튼의 중앙 화면 전환, Git 카드의 주소 입력 펼침, 기본 배치를 직접 확인했다. 로그인 실패의 지속되는 빨간 박스도 기존 공통 2초 토스트로 바꿨다. 예시 화면은 실계정 로그인이나 Git 복제, 위키 생성 성공의 증거로 사용하지 않는다.
