# 누비 Workspace Beta 1.2.4

1.2.3 공개 뒤 받은 피드백을 반영한 빌드입니다. 작업 기록 전체는 `docs/HOTFIX-1.2.0.md`에 이어서 적혀 있습니다.

## 고친 것

- **로그인 반영**: AI Workspace의 앱·Talk·문의 화면이 로그인 상태를 읽지 못해 항상 로그인 안내만 보이던 문제. 이제 어느 경로로 로그인해도 스킬·위키·앱·Talk·문의에 바로 반영되고, 스킬 마켓도 연결됩니다.
- **로그인 버튼 통일**: 상단 '로그인'과 화면 안 '사내 Github SSO 로그인'이 같은 동작(계정 패널을 열고 바로 로그인 시작)을 합니다.
- **GHES 사진**: 회사 로그인 세션으로 사진을 읽습니다. 포팅된 화면(Talk 작성자, 문의 목록, 멘션)의 사진도 앱 호스트가 대신 읽어 보여 줍니다.
- **기억 목록**: 프로젝트를 열지 않은 상태에서 '기억 목록을 읽지 못했어요'가 나던 문제.

- **Claude 연결 오류**: Claude가 도구 인자를 객체로 돌려주면 형식 오류로 재시도하다 실패하던 문제. 두 형식 모두 받고 재시도 여유를 늘렸습니다.
- **도구 호출 형식**: 모델이 같은 뜻을 다른 모양으로 보낸 인자(문자열로 쓴 목록, 하나만 쓴 값, 대소문자 다른 선택지, snake_case 이름, 빠진 빈 목록)를 도구 형식에 맞춰 고친 뒤 검사합니다. 추측이 필요한 값은 고치지 않고 돌려보냅니다.
- **변경 계획 정리 입력 형식**: 'unit test', 'modify' 같은 말, 문장으로만 쓴 요구사항, 다른 이름의 칸(file, why 등), 길이 초과 설명을 계획 형식에 맞춥니다.
- **새 파일 제안 입력 형식**: file_path, contents 같은 다른 이름, 줄 목록으로 보낸 내용, 빠진 이유(변경 계획의 같은 파일 이유로 채움)를 받아들입니다. 수정·패치 제안도 같습니다.
- **AI Pro 모델 목록**: Qwen3-Coder_rag가 계속 보이던 문제. 숨김 목록을 표시 이름으로도 비교합니다.
- **AI Workspace를 열 때 '진행 중인 작업을 마친 뒤 다시 시도해 주세요'**: 스킬 카탈로그 새로고침은 읽기만 하므로 작업 중에도 하고, 동시에 두 번 요청되면 하나로 합칩니다. 설치와 삭제는 계속 작업이 끝난 뒤에만 합니다.
- **기본 터미널 클릭 시 화살표 문자**: 셸 프롬프트에서는 마우스 추적 요청을 적용하지 않고 Alt 클릭 커서 이동을 껐습니다. vim 같은 전체 화면 프로그램은 그대로입니다.
- **Claude 잔여 한도**: Claude 응답 전에는 '아직 읽은 한도가 없어요'만 나오던 문제. Claude Code 로그인으로 5시간·7일·모델별 7일 한도와 사용 금액(달러, Enterprise)을 바로 읽습니다. 위쪽 claude.ai 블록은 없앴습니다.
- **Claude 컨텍스트 사용량**: 첫 응답 전에도 Models API의 모델별 최대 입력(예: 1,000,000 토큰)으로 계기를 보여 줍니다.
- **GHES 사진과 상태 이모지**: 회사 세션으로 사진을 받을 때 리다이렉트가 있으면 항상 실패하던 문제와 avatars 하위 주소를 막던 문제. 상태 이모지는 부분 응답도 쓰고, 회사 이모지 그림은 앱 호스트로 읽습니다.
- **'회사 계정을 확인하지 못했어요'**: 보관소 읽기 실패, 일시적 네트워크 오류, 게이트웨이 HTML 응답 등이 모두 이 문구로 끝나던 문제. 원인마다 할 일을 알려 주고, 일시적 실패는 자동으로 다시 확인합니다.

## 바뀐 것

- **페이지 이동**: 스킬, 내 스킬, 스킬 마켓, 공유 위키, Workspace 목록도 E2E Report와 같은 번호 페이지.
- **'~하는 중' 표시**: 마스코트와 음영 없이 앞에 원형 스피너만.
- **관계 지도 보조 목록**: 행 앞에 구역 색 점과 연결 수, 제목은 한 줄(호버하면 전체), 목록을 접고 펼칠 수 있음.

- **3분할로 돌아가기 아이콘**: 옆 사이드바 버튼과 같은 패널 아이콘.

- **사내 포털 로그인 시작 주소**: http://samsung.net. 메일 읽기는 기존 메일 주소.
- **앱 안 알림(토스트)**: 한 줄, 닫기 버튼이 같은 줄.

- **메일·첨부 원본 위치 변경**: 메일 설정 → 저장 위치 → 원본 위치 변경. 고른 폴더 아래 `nubi-mail-raw`로 옮깁니다(비어 있는 폴더만).
- **창 조절 버튼**: 대화상자가 열려도 색이 바뀌지 않아 호버 음영이 평소대로 보입니다.
- **상단 아이콘**: 다섯 개 모두 같은 크기와 간격.

- **MCP 연결**: 저장하면 바로 연결하고 도구 목록(설명, 입력값, 읽기 전용 여부)을 보여 줍니다. 다른 앱의 MCP 설정 JSON을 붙여 넣으면 한 번에 추가·연결되고, 작업 폴더는 폴더 선택으로 고릅니다.

- **부드러운 화면 전환**: 사이드바, 메일·위키·AI Workspace 화면, 오른쪽 창이 iOS처럼 모양을 바꾸며 이어서 움직입니다(움직임 줄이기 설정에서는 즉시).
- **진행 중 생각 표시**: 모델이 생각하는 내용을 '생각하는 중' 블록으로, 답변은 쓰는 대로 보여 줍니다(모든 모델).
- **Windows 알림**: 선택지가 있는 질문은 '열어서 답하기'로 앱 창을 열어 답합니다.
- **질문 양식**: 선택지는 단일 선택(기본)과 여러 개 선택으로 나뉘고, 선택지가 없으면 주관식입니다. 단일 선택 질문은 Windows 알림에서 바로 답할 수 있습니다.
- **계획과 단계 상세**: 작업 중에는 펼쳐 두고 결과가 나오면 한 번 접습니다. 이전 턴은 접혀 있습니다.
- **Claude 생각 표시**: Claude의 생각도 '생각하는 중' 블록에 실시간으로 보입니다. 답변은 원래처럼 쓰는 대로 나옵니다.
- **모달**: iOS 시트처럼 아래에서 올라오고, 닫을 때는 처지며 사라집니다.
- **누르는 느낌**: 버튼, 목록 행, 슬라이더 손잡이, 체크, 메뉴에 iOS처럼 눌렸다 튀어 오르는 반응(움직임 줄이기 설정에서는 꺼짐).
- **오른쪽 창 탭**: 터미널·파일·웹 탭을 작은 아이콘으로. 이름은 마우스를 올리면 보이고, 닫기는 아이콘 모서리에.
- **위키 배경**: 메일처럼 단색 면 위에 선으로만 나눕니다. 관계 지도 목록의 접기 버튼은 제목 줄 하나로 합치고 선택한 행의 연결 수가 잘 보이게 했습니다.
- **가벼워진 동작**: 바뀐 것이 없는 상태 갱신은 화면을 다시 그리지 않고, 끝난 위키 준비 상태는 드물게 확인합니다. 화면 전환은 조금 더 짧게.
- **시작 장면**: 설치 후 처음 실행할 때만, 새의 눈으로 구름 위를 천천히 날다가 점점 빨라져 해 속으로 들어가고, 빛이 퍼진 뒤 로고와 진행 막대가 나옵니다. 앱이 준비되면 막대가 채워지고 자연스럽게 넘어갑니다. 클릭하거나 키를 누르면 건너뜁니다. 앱이 시작 작업을 마칠 때까지 첫 장면에서 기다렸다가 재생해, 느린 PC에서도 순식간에 지나가지 않습니다. 이후 실행에서는 앱 배경 위에 로고와 진행 막대만 보입니다(새만 덩그러니 있던 대기 화면도 같은 모양으로).
- **처음 실행 안내**: 처음 한 번, 이동 레일, 모델 연결(또는 입력창과 모델 선택), 오른쪽 위 도구를 차례로 짚어 줍니다. 시작할 때 뜨는 메일 연결 창이 닫힌 뒤에 나오고, 카드는 짚는 곳 옆 빈 자리에 항상 창 안으로 놓이며, 화면을 어둡게 하지 않습니다.
- **로컬 서버 자동 열기**: 대화에서 띄운 서버 주소가 나오면 앱 브라우저에서 바로 엽니다.
- **앱 화면 보기**: 질문에 필요하면 누비가 자기 창을 찍어 이미지 모델로 확인합니다(앱 창만, 바탕화면은 아님). 앱 브라우저 페이지 확인은 원래처럼 됩니다.
- **말랑한 UI**: 모서리를 더 둥글게, 그림자를 더 부드럽게, 마우스를 올리면 살짝 뜨고 누르면 말랑하게 눌립니다.
- **오른쪽 위 아이콘**: 다섯 개가 한 줄로 같은 간격.
- **위키 설정**: 안쪽 여백을 줄이고 겹치던 '위키 문서' 제목을 '문서 목록'으로.
- **로딩 표시**: 위키와 스킬의 '불러오는 중'을 같은 모양으로.
- **메시지 입력창**: 입력할 때 생기던 파란 테두리와 그림자를 없앴습니다. 좁은 창에서는 아이콘만 보이고, 아주 좁으면 오른쪽 단추가 다음 줄로 내려가 겹치지 않습니다.
- **짧은 말풍선**: '안녕'처럼 짧은 메시지는 글자에 맞는 작은 말풍선.
