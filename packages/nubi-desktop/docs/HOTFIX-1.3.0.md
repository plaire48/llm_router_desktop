# 누비 Workspace Beta 1.3.0 시험판

1.3.0 후보를 설치해 시험하기 위한 사전 배포입니다. 이번 판은 Word 양식, 브라우저 가르치기, 메일 연결, 위키 안정성을 담습니다. Excel과 PowerPoint 양식은 1.3.1로 미뤘습니다.

## 바뀐 점

- 메일: 포털 로그인을 먼저 시도합니다. 로그인 뒤 세션 확인은 세 번까지만 하고, 그래도 안 되면 멈추고 POP3 연결 카드를 보여줍니다. 메일 아이디와 비밀번호는 사용자가 직접 입력하며 앱 메모리에만 둡니다. 동기화가 실패해도 앱이 혼자 여러 번 다시 시도하지 않습니다. 메일이 많을 때 목록과 검색이 따로 움직여 화면이 멈추지 않습니다.
- 위키: 도구 인자 전송 결함 두 가지를 고쳐 도구 오류가 0이 되었습니다. 의미 검토 실패는 페이지 건너뜀으로 처리하고, 긴 작성 대화는 중복 읽기를 접어 비용을 줄였습니다.
- 브라우저: 내부 브라우저와 연결한 외부 Chrome 탭에 같은 녹화 단추가 있습니다. 사람이 한 조작을 단계 카드로 만들고, 값은 저장하지 않고 칸만 남깁니다. 한 번 시험하고 승인하면 워크플로우 단계로 다시 실행합니다. 이때 모델을 부르지 않습니다. 공개 시험 20과제 중 19과제를 통과했습니다.
- Word 양식: 등록할 때 Word가 연 문서에서 내용을 가져옵니다. 글자 서식, 문단, 목록, 표, 그림, 도형, 차트, 수식, 머리글과 바닥글, 각주, 메모, 변경 내용, 입력 컨트롤까지 저장합니다(점검 항목 38/38). 요청과 자료로 칸을 채우고, 근거가 없는 값은 한 번에 묻습니다. 원본은 건드리지 않고 사본에만 쓴 뒤, 서식 보존과 머리글 변화와 남은 안내 문구를 검사합니다.
- AI Pro 생각 깊이: GLM 5.2는 high(기본)와 max 두 단계, Qwen3.8 27B는 low, medium(기본), high 세 단계입니다.
- 워크플로우: 저장한 브라우저 스크립트를 도구 단계(`browser.script`)로 실행합니다.

## 아직 안 되는 것

- Excel과 PowerPoint 양식은 1.3.1입니다. 이번 판은 파일을 읽어 저장만 하고 채우지 않습니다.
- Word를 직접 열어 가져오는 기능은 Windows Office 2016에서 아직 실측하지 않았습니다. 설치 후 첫 시험 대상입니다.
- 브라우저 녹화 카드의 '화면에서 확인'은 아직 꺼져 있습니다.

Windows 11 회사 PC, Office 2016/NASCA, 회사 로그인과 메일 수신(포털과 POP3), 외부 Chrome 연결은 설치 후 시험 대상입니다. CI 설치 검사는 해당 환경의 업무 성공을 의미하지 않습니다.
