# 누비 Workspace Beta 1.3.0 시험판

1.3.0 후보를 설치해 시험하기 위한 사전 배포입니다. 네 트랙의 품질 작업이 진행 중이며, 화면 연결이 끝나지 않은 기능은 아래에 따로 적었습니다.

## 바뀐 점

- 메일: 포털 로그인을 먼저 시도합니다. 로그인 뒤 세션 확인은 세 번까지만 하고, 그래도 안 되면 멈추고 POP3 연결 카드를 보여줍니다. 메일 아이디와 비밀번호는 사용자가 직접 입력하며 앱 메모리에만 둡니다. 동기화가 실패해도 앱이 혼자 여러 번 다시 시도하지 않습니다.
- 위키: 도구 인자 전송 결함 두 가지를 고쳐 도구 오류가 0이 되었습니다. 의미 검토 실패는 페이지 건너뜀으로 처리하고, 긴 작성 대화는 중복 읽기를 접어 비용을 줄였습니다.
- 브라우저: 내부 브라우저와 연결한 외부 Chrome 탭 모두에서 사람이 한 조작을 녹화해 단계 카드(값은 저장하지 않고 칸만)로 만들고, 한 번 시험한 뒤 승인하면 워크플로우 단계로 다시 실행합니다(모델 호출 없음). 공개 시험 20과제 중 19과제를 통과했습니다.
- 문서 양식: Word 양식을 등록하면 원본 사본과 함께 글자 서식, 그림, 표, 머리글, 각주까지 저장합니다. Excel(모든 시트, 수식, 서식, 그림, 차트)과 PowerPoint(슬라이드, 도형, 글자 서식, 그림, 표, 노트)도 저장합니다. Word 양식은 요청과 자료로 칸을 채우고, 근거가 없는 값은 한 번에 묻고, 사본에만 쓴 뒤 서식 보존과 남은 안내 문구를 검사합니다.
- 워크플로우: 저장한 브라우저 스크립트를 도구 단계(`browser.script`)로 실행합니다.

## 아직 연결되지 않은 것

- 브라우저 가르치기 패널과 녹화 버튼, 문서 양식 화면은 호스트 기능만 들어 있고 화면 연결은 다음 시험판에 들어갑니다.
- Office를 직접 열어 양식 전체를 가져오는 기능(Windows Office 연결)은 다음 시험판입니다. 이번 판의 양식 등록은 파일 읽기 기준입니다.
- Excel과 PowerPoint 양식 채우기는 1.3.1 예정입니다(저장만 됩니다).

Windows 11 회사 PC, Office 2016/NASCA, 회사 로그인과 메일 수신(포털과 POP3), 외부 Chrome 연결은 설치 후 시험 대상입니다. CI 설치 검사는 해당 환경의 업무 성공을 의미하지 않습니다.
