# 누비 Workspace 1.3.0 시험판 (10-23 빌드)

1.3.0 번호로 다시 낸 시험판입니다(사용자 결정 10-23). 10-22 1.3.0 이후 Claude와 Codex가 개발한 내용을 모두 담습니다.

## 바뀐 점

- 기능 정리: 워크플로우와 브라우저 녹화를 뺐습니다. 루틴은 대화 요청만 예약합니다. 메뉴가 줄고 시작이 가벼워졌습니다.
- 메일 받는 방식: 1. Knox Desktop은 실행 중인 Knox Desktop 창에서 열린 메일을 읽어 암호화해 보관합니다(원본 파일과 내려받지 않은 첨부는 읽지 않습니다). 2. POP3는 아이디와 비밀번호를 입력합니다. '아이디 기억'을 켜면 아이디만 OS 보호 저장소에 두고, 비밀번호는 저장하지 않습니다. 포털 연결은 뺐습니다.
- 프로젝트 연결: 연결, 자료 준비, 질문 입력이 한 화면에서 이어집니다. 위키가 이미 있는 폴더는 바로 연결합니다. 모델과 추론 정도는 같은 칩으로 고릅니다.
- 위키: OpenWiki 코어의 검색(FTS5/BM25)과 절 읽기를 그대로 씁니다. 메일 주제와 첨부를 위키 지식으로 정리합니다.
- 화면: Calm Liquid 브랜드 색, Lucide 아이콘, 모래시계 로딩, 공통 모션을 적용했습니다. 외부 브라우저의 실제 탭을 오른쪽에 보여줍니다.
- 대화: 프로젝트를 고르지 않아도 바로 대화를 시작합니다. 답한 뒤 남던 질문 카드와 입력값을 지우고, 질문 직전에 보낸 추가 지시는 답한 뒤 이어서 실행합니다.
- 코딩(opencode 방식): 코드 수정 매칭(CRLF 보존, 공백 차이 허용, 모두 바꾸기), 소스 찾기 정규식과 파일 패턴, 수정 뒤 타입 오류 알림, 큰 도구 결과 저장, 프로젝트 코드 지도, 서버가 바쁠 때 최대 7번 재시도.
- 변경 전으로 되돌리기: 수정 적용, 새 파일, 명령 실행 직전마다 시점을 남기고, '변경한 파일' 카드에서 되돌리거나 되돌리기를 취소합니다.
- 명령 '항상 허용': 앞부분이 같은 명령(예: npm run test)도 다음부터 확인 없이 실행합니다. 되돌릴 수 없는 명령과 삭제, 권한 프로그램은 넓혀 허용하지 않습니다.

## 아직 안 되는 것

- Knox Desktop 화면 읽기는 회사 PC에서 아직 실측하지 않았습니다. 설치 후 첫 시험 대상입니다.
- 어제 1.3.0과 번호가 같아 자동 업데이트로 잡히지 않습니다. 설치 파일을 직접 실행해 주세요. 1.3.1을 설치한 PC는 1.3.1을 지운 뒤 설치합니다.
- 이번 설치 파일은 빠른 빌드입니다. CI는 기본 시험과 설치 파일 만들기만 했습니다. 설치, 업그레이드, 제거, 화면 시험은 직접 확인해 주세요.

Windows 11 회사 PC, Office 2016/NASCA, 회사 로그인과 메일 수신, 외부 Chrome 연결은 설치 후 시험 대상입니다. CI 검사는 해당 환경의 업무 성공을 의미하지 않습니다.
