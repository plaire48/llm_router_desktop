# 누비 Workspace Beta 1.1.7

## 개선

- 저장된 프로젝트를 클릭하면 마지막 대화와 초안을 바로 복원합니다. 중간 Git/폴더 연결 화면을 제거했습니다.
- 질문 폼의 연필과 예시 문구를 첫 줄에 맞췄습니다. Windows 알림에는 프로젝트와 대화, 실제 질문이나 승인할 작업을 표시합니다.
- 원문 출처의 시작/끝 줄을 강조하고 해당 위치로 이동합니다. 확장자별 파일 아이콘을 사용합니다.
- 채팅 너비를 창 크기에 맞추고, 유효한 변경 제안에만 반영/취소 동작을 표시합니다.
- 프로젝트별 Wiki 작성 상태와 경과 시간을 표시합니다. 해당 프로젝트의 위키 작성 중에는 채팅을 잠그고 다른 프로젝트 작업은 유지합니다.
- 공유 위키 표시 대상은 GitHub 사진/이름/공개 이메일 검색 후 사람을 선택하고 칩으로 관리합니다. 이는 앱 표시 대상이며 GHES 원본 권한을 변경하지 않습니다.
- GHES 프로필 사진과 상태 이모지를 표시하고 위키 기준 브랜치 조회를 보완했습니다.
- 내장 브라우저의 새 창과 POST 전달을 보존하고 읽기 실패 시 재시도 안내를 표시합니다.
- 최종 결과 검토의 JSON/도구 응답 형식 복구를 보완했습니다.
- 메일 연결은 사내 포털 로그인 흐름으로 전환하고 메일함 및 결재 조회를 추가했습니다. 보관된 기존 메일은 유지합니다. 메일 확인 필요 항목은 백그라운드에서 원인과 재시도를 확인합니다.

## 설치와 업데이트

Windows x64 설치파일을 실행하세요. 앱 이름과 저장 경로를 유지해 기존 설치판을 업데이트합니다. 사내 자동 업데이트 배포 방법은 INSTALL-AND-UPDATE-1.1.7.md와 Publish-NubiUpdate.ps1을 참고하세요.

## 범위

Beta의 첨부파일 내용 분석과 Desktop A2A는 지원하지 않습니다. GHES/포털 실계정과 실제 Windows 11 사용자 PC의 확인은 자동 검사와 구분합니다. 이 설치파일은 공인 코드서명이 없는 Beta입니다.

## 파일 보관함과 가독성

- EML, MHTML/MHT, MYSINGLE 폴더를 하위 폴더까지 가져와 Personal Wiki로 정리하고 검색/질문합니다. AUTO 폴더명으로 수신, 발신, 결재, 승인, 기안을 구분합니다. 동일 원문의 같은 분류는 중복 제외하며 보호된 파일은 안내합니다.
- Code 위키도 공유할 문서를 직접 선택합니다. 사람 검색의 이메일 괄호를 제거했습니다.
- 원문 출처는 기본 접힘으로 표시하며 작업계획과 확인한 자료 사이 여백을 줄였습니다.

- 시간대별 환영 문구를 직장인을 위한 짧고 따뜻한 인사 100개로 확대했습니다. 대화 작성 중에는 바뀌지 않고 새 대화에서는 직전 문구를 피합니다.

## 후속 화면과 검토 보강

- AI Workspace는 스킬, 위키, 앱, Talk 순서이며 선택 표시와 실제 콘텐츠를 일치시킵니다. Talk는 고정 사내 저장소의 글/댓글을 읽고 명시적인 게시 버튼으로 등록합니다. 게시 응답 유실은 원문 마커로 확인하며 동일 요청을 다시 작성하지 않습니다. 사내 실계정 게시 성공은 아직 검증하지 않았습니다.
- 위키 책 메뉴는 프로젝트/메일 Markdown 열람, 해시 충돌을 확인한 편집/저장, 문서 링크 그래프를 제공합니다. 메일은 기존 위키만 60,000자까지 편집하며 새 프로젝트 문서는 직접 추가할 수 있습니다. AI가 추측한 연결을 그래프에 넣지 않습니다.
- 긴 질문과 선택지의 가로 넘침을 막고 둥근 질문 폼과 체크 정렬을 통일했습니다. 긴 선택지는 호버/초점에서 확인합니다. 자유 입력이 비활성인 객관식도 답변 전송을 유지합니다.
- Personal 스킬의 편집/삭제는 한 줄 `…` 메뉴로 옮겼습니다. 관련 없는 에이전트 실행 때문에 등록/삭제를 일괄 차단하지 않습니다. 해시 보호, 삭제 전 확인과 복구 사본을 유지합니다.
- 슬래시 목록은 최대 10행을 표시하며 나머지는 스크롤/키보드로 탐색합니다.
- 변경 제안은 파일명, 추가/삭제 줄, 인라인 차이 미리보기와 비교/취소/반영으로 정리했습니다. 승인이나 실제 저장의 검증을 줄이지 않았습니다.
- 검토 JSON의 완전한 코드 블록과 도구 미지원 응답을 복구합니다. 복구 실패 시 검토 전 답변을 별도로 보존하며 작업 상태는 보류로 유지합니다. 실제 AI Pro 실패 건의 원인 확정/실계정 재현과 합성 검사는 구분합니다.

## 위키 바로 읽기

- 책 메뉴에서 현재 프로젝트의 마지막 문서를 바로 엽니다. 처음에는 home/index/README, 없으면 첫 문서로 시작합니다. 마지막 위치는 앱 세션 동안 프로젝트별로 기억합니다.
- 프로젝트와 메일은 상단에서 한 번에 전환합니다. 제목/경로 검색은 Enter로 첫 결과를 열며 관련 문서는 펼치기 없이 이동합니다.
- 문서 연결 그래프와 편집은 본문 옆 아이콘으로 엽니다. 링크 추가는 편집할 때만 표시합니다.
- 프로젝트/메일 전환 및 화면 재진입 때 미저장 초안과 충돌 보호를 유지합니다.
- Chrome 1100/440/360px에서 바로 열기, 재진입, 관련 문서, 검색, 초안 보존을 검사했습니다. 실제 Electron의 파일 저장/다시 읽기와 기존 프로젝트 전환 9개 검사도 통과했습니다. 회사 계정과 Windows 사용자 PC 확인은 별개입니다.

## 인라인 승인과 실행 기록

- 실행 승인과 취소를 대화 안에 바로 표시합니다. Windows 알림을 누르면 해당 폼으로 이동하며 클릭만으로 실행하지 않습니다. 관리자 명령은 별도 승인과 UAC를 유지합니다.
- 터미널 제목 줄에는 복사 버튼을 두고 복사 후 체크 표시를 보여줍니다. 명령과 실제 결과를 함께 복사하며 실패/종료 코드는 아래 실행 기록에 남깁니다.
- 이어서 보낸 메시지는 진행 내용이 늘어도 위치를 유지합니다. 읽으려고 위로 이동하면 자동 스크롤을 멈추며 최신 이동은 직접 선택합니다. 승인 카드가 내 메시지 위에 끼어들지 않습니다.
- 대화 본문의 문단과 목록 간격을 공통 토큰으로 조정했습니다.
- 대화형 PowerShell에도 UTF-8 입출력과 BOM 없는 UTF-8 파일 읽기 설정을 적용했습니다. 프로필/실행 정책/시스템 언어는 변경하지 않습니다.
- 첫 커밋 전 저장소의 Git 상태/추가 파일 비교를 지원합니다. Git 없는 로컬 폴더는 변경 상태를 알 수 없다고 반환하고 원본을 자동 초기화하지 않습니다. Git 접근/시간 초과 오류는 읽기 복구 지침을 제공합니다.
- 검토 실패 상세에 안전한 원인 코드를 저장하고 표시합니다. 형식 오류/응답 잘림/연결 오류를 구분하며 검토 실패를 작업 성공으로 표시하지 않습니다. 기존 실행을 재전송하지 않는 읽기 전용 복구를 유지합니다.

- 복사 버튼은 공통 24px 조작 영역/14px 아이콘 토큰을 사용하고 터치 환경은 44px를 유지합니다. 완료 체크도 같은 크기와 주변 글자 색을 유지하며 별도 파란 배경이나 테두리를 표시하지 않습니다.
