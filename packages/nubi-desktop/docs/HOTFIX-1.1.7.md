# 누비 Workspace Beta 1.1.7

## 개선

- 저장된 프로젝트를 클릭하면 마지막 대화와 초안을 바로 복원합니다. 중간 Git/폴더 연결 화면을 제거했습니다.
- 질문 폼의 연필과 예시 문구를 첫 줄에 맞췄습니다. Windows 알림에는 프로젝트와 대화, 실제 질문이나 승인할 작업을 표시합니다.
- 원문 출처의 시작/끝 줄을 강조하고 해당 위치로 이동합니다. 확장자별 파일 아이콘을 사용합니다.
- 채팅 너비를 창 크기에 맞추고, 유효한 변경 제안에만 반영/취소 동작을 표시합니다.
- 프로젝트별 Wiki 작성 상태와 경과 시간을 표시합니다. 해당 프로젝트의 위키 작성 중에는 채팅을 잠그고 다른 프로젝트 작업은 유지합니다.
- 공유 위키 표시 대상은 GitHub 사진/이름/공개 이메일 검색 후 사람을 선택하고 칩으로 관리합니다. 이는 앱 표시 대상이며 GHES 원본 권한을 변경하지 않습니다.
- GHES 프로필 사진과 상태 이모지를 표시하고 위키 기준 브랜치 조회를 보완했습니다.
- 내장 브라우저의 새 창과 POST 전달을 보존하고 읽기 실패 시 재시도 안내를 표시합니다.
- 최종 결과 검토의 JSON/도구 응답 형식 복구를 보완했습니다.
- 메일 연결은 사내 포털 로그인 흐름으로 전환하고 메일함 및 결재 조회를 추가했습니다. 보관된 기존 메일은 유지합니다. 메일 확인 필요 항목은 백그라운드에서 원인과 재시도를 확인합니다.

## 설치와 업데이트

Windows x64 설치파일을 실행하세요. 앱 이름과 저장 경로를 유지해 기존 설치판을 업데이트합니다. 사내 자동 업데이트 배포 방법은 INSTALL-AND-UPDATE-1.1.7.md와 Publish-NubiUpdate.ps1을 참고하세요.

## 범위

Beta의 첨부파일 내용 분석과 Desktop A2A는 지원하지 않습니다. GHES/포털 실계정과 실제 Windows 11 사용자 PC의 확인은 자동 검사와 구분합니다. 이 설치파일은 공인 코드서명이 없는 Beta입니다.
