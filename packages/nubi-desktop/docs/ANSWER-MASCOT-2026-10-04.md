# 답변 옆 누비 모션

모델명 왼쪽은 공통 `AgentMark`와 기존 새 이미지, `useIdleExpression`을 직접 재사용한다. 최신 답변만 움직이고 웃기와 날갯짓을 숨기던 Desktop CSS를 제거했다. 이전 답변에도 같은 눈 깜박임, 웃기, 날갯짓과 호버 인사를 적용한다. 모델명과 모델 선택 칩은 움직이지 않는다.

20초 동안 입력이나 마우스 움직임이 없으면 잠들고 실제 입력과 포인터 활동으로 깨어난다. 실제 재응답 또는 pending 메시지만 working 표정에 연결한다. CSS 모션으로 작업 완료나 진행률을 만들지 않는다.

motion-system 스킬의 일관된 모션과 감소 설정을 적용했다. 표정 프레임과 8초 주기는 기존 누비와 같고, 본문에서 새 자체의 이동 폭은 1px로 제한한다. OS 모션 감소에서는 애니메이션을 끄고 비활성 창과 열린 모달에서는 멈춘다. 공통 캐릭터 소스와 Browser/Office 모션을 변경하거나 새 패키지를 추가하지 않았다.

사용자 요청에 따라 자동 테스트와 실제 모델 호출 없이 Electron 빌드와 예시 화면의 모션을 확인한다. 실제 작업 상태의 working 전환은 별도 실모델 검증 범위다.
