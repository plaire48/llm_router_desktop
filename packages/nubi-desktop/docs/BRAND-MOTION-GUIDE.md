# 누비의 20개 브랜드 모션

색, 새, 아이콘과 움직임을 같은 브랜드 자산으로 관리한다. 기존 interaction atlas의 18개 유형에 이미 사용하는 물방울/모래시계를 더한 20개 항목이다. [색/버튼/아이콘 기준](NUBI-BRAND-GUIDE.md)과 같은 토큰을 사용한다. 아래 목록은 모든 화면에서 20개를 동시에 실행하는 요구가 아니라, 상황에 맞는 한 가지 표현을 선택하는 기준이다.

추가 제공된 원본 `design-reference/motion_interaction_atlas.html`에는 21개 데모가 있다. 제품의 기존 20개 상황 목록과 원본의 21개 데모 분모를 혼동하지 않는다. 일반 전환은 원본의 `cubic-bezier(.2,.85,.25,1)`을 사용한다. 레일/상단 문서 탭/세그먼트의 새 유리 선택은 `ui/liquid-glass/spring.mjs`의 220/25 물리 Spring과 이동 방향의 늘어남을 사용하며, 정지 시 프레임 루프를 종료한다. 아래의 일반 등장 시간 280ms는 이 물리 Spring의 정착 시간을 뜻하지 않는다. 물리 Spring은 새 요청을 받으면 현재 속도로 이어가고 모션 감소에서는 즉시 위치를 맞춘다. 3D 별/하트 변형이나 메타볼 데모를 업무 화면에 모두 추가하지 않는다.

## 공통 성격

작게 반응하고 부드럽게 도착한다. 입력/승인/다음 화면이 준비되는 시점은 지연하지 않는다. 기능 동작은 바로 반영하며, 본문 대신 비활성 표면이나 아이콘 도형만 보간한다. 애니메이션은 상태의 원인이 아니며 실제 단계, 성공, 중단과 복구 영수증을 따른다. 오류/승인 화면에서는 읽을 내용을 흔들거나 춤추게 하지 않는다.

등장/공간 연결은 공통 280ms 스프링, 퇴장은 180ms, 상태 변화는 180ms, 누름은 120ms다. 기존 24ms 순차 등장과 한 번에 최대 세 대상의 효과 예산을 유지한다. 모션 감소에서는 이동/확대/회전을 멈추고 짧은 페이드나 정적인 선택 상태를 남긴다. 동작 상태/문구/aria-current/aria-busy는 계속 제공한다.

| 2 | Animated Layout Reflow | 패널 확장, 진행 기록 크기 변경 | 레이아웃은 즉시 반영하고 옅은 브랜드 비활성 표면으로 연결한다. 글자를 늘이지 않는다. |
| 3 | Concentric Corner Morph | 보조 패널의 일반/확장 보기 | 바깥 곡률 = 안쪽 곡률 + 간격. 같은 곡선/간격 토큰을 재사용한다. |
| 4 | Magnetic Window Snapping | 지원되는 브라우저 도킹의 실제 드롭 후보 | 후보 영역에 맞춘 브랜드 안내 면. 비활성 기능을 이 모션 때문에 활성화하지 않는다. 실제 연결 전 성공을 표시하지 않는다. |

| 6 | Seamless Crossfade | 프로젝트 로딩 단계, 준비 완료, 결과/오류 안내 | 실제 단계/내용이 바뀔 때 한 번. 경과 시간·반복 조회·스트리밍마다 재생하지 않는다. 오류는 의미 색과 읽을 안내를 유지한다. |

| 16 | Spring Context Menu | 도구/대화 관리 메뉴 열기 | 트리거 쪽을 기준으로 확장. 툴팁/키보드 탐색/기존 확인 흐름을 보존한다. |

| 18 | 3D Parallax & Depth | 같은 시작 화면의 장식 영역 | 제한된 기울기/이동을 공유한다. 제목/본문은 고정하고 새 원본의 색과 표정을 유지한다. |

## 한 사용자 여정

프로젝트 선택은 짧은 순차 등장과 누름 피드백을 사용한다. 연결 모달에서는 공통 시트/페이드로 맥락을 보존한다. 프로젝트 열기는 밝은 정적 브랜드 배경에서 실제 단계를 페이드하고, 읽기/정리 단계 표시가 해당 위치로 이동한다. 준비가 되면 가림막을 정리하고 입력을 바로 열며, 새 질문이나 승인 대기를 성공으로 바꾸지 않는다.

메일/위키 목록을 고르면 같은 항목에서 오른쪽 원문으로 이어지고 목록/초안은 유지한다. 결과/오류는 현재 알림의 짧은 등장과 의미 색/정확한 문구로 알린다. 재시도/복구는 실제 작업이 다시 시작될 때만 진행 표시를 재개한다. 일반 데이터 갱신에는 장식 모션을 추가하지 않는다.

모달·프로젝트 전환·창 숨김이 시작되면 실행 중인 Atlas 표면, 아이콘 확대, 유리 포인터와 밀기 잔상을 정리한다. 가림이 풀리면 다음 사용자 상호작용부터 반응한다. 강제 색상 모드에서는 장식을 숨기고 실제 드롭 대상에는 시스템 색 윤곽을 남긴다.
