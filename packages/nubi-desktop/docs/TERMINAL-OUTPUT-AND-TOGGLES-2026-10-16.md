# 터미널 출력과 설정 토글

2026-10-16. 로컬 소스와 빌드 반영. 설치 파일 배포는 하지 않았다.

## 수정

- 실행 결과가 채팅의 `<samp>`에 원문 문자열로 들어가 ANSI 색상, 커서, OSC 제어 코드가 문자처럼 보일 수 있었다. `terminal-readable-text.mjs`에서 화면/복사/모델 미리보기용 텍스트를 분리한다. 스트리밍 중 미완성 제어 코드는 표시하지 않으며 잘못된 제어 문자열이 다음 오류 줄을 삼키지 않게 한다.
- 진행 표시의 CR은 별도 줄로 남기고 CRLF는 한 줄바꿈으로 처리한다. 원본 로그와 종료 코드, 실제 오류는 유지한다. 이 투영은 터미널 화면 에뮬레이터가 아니다.
- 실제 PTY와 xterm에는 이 필터를 적용하지 않아 색상과 커서 동작을 유지한다. 기존 UTF-8 스트림 디코더와 CLIXML 해석을 보존한다. 임의의 인코딩 추측이나 손상 문자를 삭제해 성공처럼 보이게 하지 않는다.
- 첨부 원본 보관, 외부 AI 안내 다시 보지 않기, 실행 후 AI 확인, DB TLS 설정을 `SettingToggle`로 통일했다. 기존 메일 자동 정리의 스위치와 공통 폰트/아이콘/여백/초점 스타일을 쓴다. 메일 행과 필터 값, 여러 대상 선택은 체크박스를 유지한다.

## 검증

- 프로세스/출력/터미널 관련 41개 단위 검사 통과. 1바이트씩 분할된 UTF-8 파이프에서 한글, 일본어, 악센트, 그리스 문자, 이모지, 표 테두리가 보존되고 원본 로그가 그대로 남는지 검사했다.
- 메일 화면 24개 조건(3개 폭 × 2개 글자 크기 × 4개 화면)과 추가 저장 위치 모달 검사 통과. 토글 상태 전환, 문구 변경, 키보드 초점과 경계 확인.
- 보안 안내의 취소/확인/다시 보지 않기 저장 및 재진입 검사 통과. 좁은 창/확대 모달 36개 조건 통과.
- 로컬 Electron 빌드 통과. 실제 Mac Electron/Bash PTY의 8개 흐름 통과: 다국어/ANSI, 승인한 동일 실행 연결, 다시 열어도 재실행하지 않음, Ctrl+C 뒤 입력, 12,000줄 출력 후 리사이즈/추가 입력, 마지막 출력과 종료 표시 순서.
- `verification/command-terminal-2026-10-15/result.json`, `verification/dialog-bounds/result.json`, `verification/mail-cx-final-2026-10-15/after.json`에 결과가 있다. 기존 검사 경로의 날짜는 유지했다.

Windows PowerShell 5.1/7, CMD, Git Bash의 실제 설치 환경은 이 Mac에서 검증하지 않았다. 이번 Mac 터미널 흐름의 AI는 테스트 모델이며 실제 AI 답변 품질이나 사내 인증 검증이 아니다. 이미 손상된 문자와 레거시 프로그램이 임의 코드페이지로 출력한 바이트를 무조건 복원한다고 보장하지 않는다.
