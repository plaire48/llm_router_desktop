# 시간대별 따뜻한 인사

Electron 시작 화면의 고정 인사가 기존 시간대 분기를 덮어쓰고 있었다. 사용자 요청에 따라 로컬 시간 기준 새벽/아침/점심/오후/저녁/밤의 여섯 구간, 총 30개 짧은 문구로 연결했다. 일하는 사람에게 부담을 주지 않는 반가움, 함께 정리하기, 잠깐 쉬어 가도 좋다는 표현을 사용한다. 성과를 단정하거나 업무를 재촉하는 문구는 사용하지 않는다.

기존 Welcome 컴포넌트와 새/타이핑/모션 감소 계약을 재사용한다. 새 대화에서 현재 시간대에 맞는 문구를 선택하고 바로 전 문구는 제외한다. 입력, 모델 선택, 상태 폴링 중에는 동일한 문구를 유지한다. 입력창은 질문을 반복하지 않고 ‘함께할 일을 적어 주세요’로 표시한다. 짧은 문구와 컨테이너 너비에 맞춘 글자 크기로 한 줄을 유지한다. 새 의존성이나 LLM 호출, 개인 데이터 조회는 필요하지 않다.

24시간 전체의 구간 선택과 30개 문구 및 연속 중복 제외를 확인했다. 격리된 Electron production 컴포넌트에서 6개 시간대와 1280/440px 화면, 입력 중 인사 유지, 새 대화 문구 변경, 한 줄 표시를 검사했다. 새 모션 회귀도 유지한다. 실제 사용자 앱은 macOS 키체인 접근 확인 대기여서 이번 인사의 실사용 앱 표시 확인과 로그인 재시작 복원은 별도 확인이 필요하다.
