# 열린 사이드바에 맞춘 대화 배치

최신 사용자 결정: 닫힌 사이드바 공간을 미리 확보하지 않는다. 왼쪽/오른쪽 사이드바가 생기거나 열리면 대화 영역을 실제 남는 너비에 맞추고, 닫으면 그 공간까지 대화를 넓힌다. 이전의 열림/닫힘에 무관한 고정 대화 너비 결정을 대체한다.

창의 기존 기본 크기 1480 × 960 DIP를 유지한다. 프로젝트 목록 268 DIP와 도구 줄 52 DIP, 오른쪽 보조 영역 420 DIP를 기본으로 두며 세 영역이 열렸을 때 중앙에 740 DIP가 남는다. 여유가 적으면 보조 영역을 280 DIP까지 줄이며 기본 배치에서 중앙에 최소 560 DIP를 확보한다. 전체 너비가 1160 DIP보다 작으면 기존 겹침 방식으로 전환한다.

넓은 창에서는 열린 프로젝트 목록과 보조 영역만 flex 흐름에 배치한다. 대화와 편집기를 재마운트하지 않고 CSS가 남는 너비를 배분한다. 사이드바 경계 드래그에도 남는 대화 공간이 따라 조절되며 최소 대화 여유를 resize hook에 전달한다. 사용자 지정 너비는 기존 localStorage와 pointer capture, 키보드, 더블클릭 복원 계약을 재사용한다. 명시적인 넓게 보기는 중앙 위에 겹친다. 사용하지 않는 오른쪽 영역을 자동으로 열거나 빈 열을 예약하지 않는다.

새 레이아웃 패키지를 추가하지 않았다. CSS flex와 기존 공통 resize hook 및 ResizeObserver를 재사용한다. 이번 확인은 Electron 빌드이며 실제 Windows 창 배치나 자동 UI 검사는 수행하지 않는다.
