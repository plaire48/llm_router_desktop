# Auxiliary terminal tabs

사용자 결정에 따라 보조 영역의 + 메뉴는 터미널, 파일, 새 페이지 세 항목만 제공한다. 터미널 행의 …에서 호스트가 제공하는 셸을 선택하면 별도 터미널 탭이 열린다. 셸 선택은 탭에만 적용하고 설정의 기본 셸과 에이전트 실행 계약은 유지한다.

파일과 웹페이지, 터미널은 같은 탭 줄과 공통 선택/호버 토큰을 사용한다. 터미널은 전체 보조 콘텐츠를 차지하며 파일 하단 패널을 만들지 않는다. 각 탭의 셸, 프로젝트 내부 경로, 명령 초안, 최근 입력과 출력은 탭 전환에도 유지한다. 실행 중 탭의 닫기는 막고 중지 후 닫도록 공통 CX 토스트로 안내한다. 유휴 탭은 가운데 버튼/Delete/Ctrl+W로 닫는다. 터미널 탭은 최대 12개다.

기존 xterm.js/Fit addon과 Processes를 재사용한다. 새 PTY 패키지는 도입하지 않았다. 공통 PowerShell 한글 입출력 계약, 프로젝트 경로 범위 검사와 수동 실행 영수증을 유지한다. 지속적인 셸 환경/대화형 stdin/TUI는 제공하지 않으며 입력한 명령은 매번 별도 프로세스로 실행된다. 명령과 cwd/출력은 자동 재전송하지 않는다. native Chromium 페이지는 + 메뉴가 열린 동안 가려 메뉴를 덮지 않도록 한다.

확인 범위는 소스 검토와 Electron 빌드다. 사용자 요청에 따라 테스트, 실제 셸 명령과 Windows 검증은 실행하지 않는다. Electron 빌드/실행을 실제 Windows 셸 호환성 성공으로 표시하지 않는다.
