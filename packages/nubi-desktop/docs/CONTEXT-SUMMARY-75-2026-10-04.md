# 컨텍스트 자동 요약 기준

Desktop은 모델 목록에서 확인한 최대 컨텍스트의 75%를 자동 요약 시작점으로 사용한다. 262,144 토큰 모델은 196,608 토큰이 기준이다. 최대 용량을 75%로 줄이지 않으며 도넛도 전체 용량 기준을 유지한다.

기존 큰 모델 정책은 응답 공간을 제외한 입력 예산의 90%를 사용했다. `context-policy.mjs`에서 Desktop 정책을 명시하고 공통 `contextBudget`이 이를 적용하도록 수정했다. 초기 대화 정리, 실행 중 정리와 사용량 모달이 같은 계산을 재사용한다. 더 낮은 실제 입력 제한이 있다면 이를 먼저 보호하고 화면에도 그 이유를 표시한다. 과거 기록에 남은 90% 값을 현재 요약 기준으로 다시 표시하지 않는다.

원본 SQLite 대화, 최신 요구사항, 승인/복구 기록과 도구 호출/결과 쌍을 보존하는 기존 Pi 및 누비 요약기를 재사용한다. 새 패키지나 요약 프레임워크는 추가하지 않았다. Browser/Office의 기본 요약 정책은 그대로 유지한다. 요약 실패나 문맥 초과의 기존 복구 계약도 유지한다.

Electron 빌드를 완료했고 예시 데이터 화면에서 `자동 요약 (75%) / 196,608 토큰` 표시를 직접 확인했다. 사용자 요청에 따라 자동 테스트와 실모델 장문 호출은 실행하지 않았다. 실행 중인 백엔드는 재시작 후 새 정책을 사용한다.
