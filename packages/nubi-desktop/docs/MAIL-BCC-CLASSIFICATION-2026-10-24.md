# Unclassified recipient categories belong to Bcc

The user defined the mail category “미확인” as “비밀참조”. Unknown, missing and invalid stored recipient categories now normalize to `bcc`. Confirmed To, Cc and sent-folder classifications keep their existing priority. This is a product classification rule: original To/Cc/Bcc addresses remain unchanged. Literal header matching can still return `unknown` internally so the existing account-address fallback can identify a confirmed recipient before applying the final Bcc category.

The mail list, source-read API, metadata paging, private full-text search, in-memory search and role sorting use the same rule. SQL projects old unknown/missing records into Bcc without rewriting source records or original files. Old saved `unknown` filters normalize to Bcc, with duplicate selections removed. A policy revision invalidates old metadata cursors whose role sort keys used the previous category. The column filter offers only 수신, 참조, 비밀참조 and 발신. Other meanings such as 날짜 미확인 and unread/confirmation status are unchanged.
