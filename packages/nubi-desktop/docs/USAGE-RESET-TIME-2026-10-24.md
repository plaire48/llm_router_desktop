# Last usage reset time

The app's token usage modal now shows the last local-counter reset date and time beside “전체 초기화”. It uses the PC's local time zone and includes the year and seconds. Narrow windows put the timestamp on its own line without reducing the shared caption size. Account quota/reset times remain in their existing account section.

DesktopUsage stores `lastResetAt` inside the same `usage:ledger` record as the new counters, and changes the visible ledger only after that write succeeds. The summary carries that field through the existing reset/status APIs and Workbench usage state. Reopening the modal, provider calls and restarting the app preserve it. A failed reset retains both the prior counters and timestamp; pending responses from before reset retain their existing accounting-boundary behavior.

Older ledgers have only `startedAt`, which can represent first use or an old reset. They therefore show “집계 시작” rather than a fabricated last reset. New ledgers do not invent an explicit reset, and missing/invalid date values show no invalid date. Existing stored usage is not reset by this source change. The Desktop passes a React scope label to the unchanged shared UsagePanel, reusing its current component, actions and semantic typography tokens.

Verification: the new timestamp expectations first failed against the old implementation. The final focused usage/account/context regressions passed 22 tests. The existing production-Workbench browser reset check passed at 1280/440/360 px with synthetic data, covering legacy display, success, preserved account quota, failed reset and close/reopen. A built macOS Electron inspection passed five scenarios using actual local usage reset/storage/IPC and a full app restart; only the reset-error scenario was injected at IPC. The native check caught a locale-format difference, after which hour/minute/second formatting was made explicit. Build and design identity checks passed. Screenshots were reviewed with the modal and surrounding Workspace. This does not verify a provider quota reset or Windows installation.
