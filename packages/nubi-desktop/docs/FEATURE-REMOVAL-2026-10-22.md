# 1.3.0 기능 정리

사용자 요청에 따라 워크플로우와 브라우저 녹화 기능을 제거한다. 메뉴가 많아지는 문제와 실행 시 불필요한 모듈을 로드하는 문제를 함께 줄인다.

- 워크플로우 메뉴, 편집기, 캔버스, 실행 화면, 가져오기와 실행 RPC를 제거한다.
- 워크플로우 런타임과 일반 에이전트의 단계 실행 분기를 제거한다. 전용 그래프 의존성 `@xyflow/react`와 하위 의존성을 잠금 파일에서 제거한다.
- 브라우저 녹화, 가르치기, 시험 재생, 저장 카드 UI와 녹화 호스트를 제거한다. 브라우저를 열어도 녹화 상태를 주기적으로 조회하지 않는다.
- 루틴은 대화 요청만 예약한다. 워크플로우 선택, 자동 전환 제안과 감독 실행 연결을 제거한다.
- 이전 워크플로우 예약은 목록과 자동 실행 대상에서 제외하고 수동 실행도 거절한다. 저장 기록과 사용자 파일은 자동 삭제하지 않는다. 이전 단계 대화를 일반 에이전트로 다시 실행하지 않는다.
- 일반 대화의 계획과 검토, 문서 작성, 메일, Wiki와 브라우저의 기본 연결 계약은 유지한다. 내부 도구 분류의 `workflowIds`와 개발 검증, CI workflow는 별도 기능이다.

삭제한 기능의 전용 검사만 제거하고 나머지 게이트와 성능 기준은 유지한다. 수정한 검사에서 워크플로우 장면을 제거하고 실제 남아 있는 화면을 계속 검사한다. `tests/removed-features.test.mjs`는 삭제한 RPC, 이전 예약과 단계 실행, 브라우저 녹화의 접근 차단을 확인한다. `node scripts/check-removed-features-ui.mjs`는 1280px와 440px에서 메뉴 제거, 요청 루틴 저장과 녹화 없는 브라우저 화면을 실제로 조작한다.

로컬 빌드와 합성 호스트 검사는 Windows 설치와 실제 회사 로그인 검증을 대체하지 않는다. 번들 크기와 속도, 메모리 사용량은 각각 측정한 범위로만 보고한다.
