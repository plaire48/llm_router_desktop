# 도구와 명령 실행 표시

현재 작업 줄과 하단 상태는 같은 호스트 도구 ID로 검색, 파일 읽기, 수정, 브라우저, 터미널 아이콘을 선택한다. 모델의 자유 문구와 인자는 아이콘 선택에 쓰지 않는다. Playwright MCP는 브라우저 아이콘을 쓰며 다른 미등록 도구도 공통 도구 아이콘과 사용 가능한 표시 이름을 갖는다.

진행 기록을 접어도 현재 작업과 공개 작성 초안은 계속 보인다. 기록의 각 묶음과 펼친 단계에도 같은 종류의 아이콘을 사용한다. 오류, 승인 대기, 취소, 보류와 복구는 기존 상태 아이콘과 내용을 유지한다. 현재 작업의 실제 프로세스가 실행 중이면 도구 호출 사이에도 명령 실행 중으로 표시한다. 다른 대화의 프로세스는 가져오지 않는다.

기존 공통 AgentTrace에 선택 아이콘 슬롯을 추가했다. 호스트가 슬롯을 주지 않는 확장 화면의 기본 상태 아이콘은 유지한다. 공통 Lucide 원본과 기존 간격/아이콘 크기 토큰을 재사용하며 새 의존성이나 CSS 애니메이션은 추가하지 않는다. 도구 종류와 진행 여부를 분리하는 기존 Desktop 상태/영수증 구조를 확장했다.

코딩 workflow 지침은 필요한 CLI 버전 확인, 설치, 빌드, 테스트와 로컬 서버를 적극 사용하도록 명시한다. 기존 propose_setup_action, 명령별 승인, 취소/미확정 복구와 실제 출력 확인은 유지한다. 원본 OpenCode 실행 루프를 새로 만들거나 모든 명령을 자동 승인하는 변경이 아니다.

공유 컴포넌트의 확장 검증에서 기존 openwiki-agent.js의 평가용 node:fs 정적 import가 브라우저 후보 빌드를 막는 것을 확인했다. 파일 로그를 Desktop의 평가 실행기 전용으로 옮겼다. 최신 도구명, 원래 글자 수, 최대 4,000자와 로그 실패 무시 계약을 유지하고 제품 어댑터는 Node 파일 모듈/평가 환경변수를 읽지 않는다. 제품 UI나 모델 완료 판정에는 로그를 연결하지 않는다.

## 검증

- Desktop 관련 단위 검사 21개와 공유 trace 회귀 17개를 통과했다. 다른 실행의 이벤트/프로세스와 원시 인자를 가져오지 않는지, 호출 사이에도 실제 프로세스를 표시하는지 확인했다.
- Electron 합성 Workbench에서 2560/1920/1280/760/440px의 도구 아이콘 전환, 폼 응답, 중복 제출 차단과 실시간 명령 출력을 확인했다. 진행 기록을 접거나 진행 표시를 꺼도 현재 도구와 공개 초안은 보인다.
- Chrome의 실제 production Workbench 렌더링으로 1280/440/360px과 200% 글자 확대, 오류 내용 펼침, 도구/메모 발생 순서와 같은 시작선을 확인했다. check-activity-readability의 오래된 SVG 로더와 오류 펼침/중복 텍스트 선택자는 현재 공통 컴포넌트 계약에 맞춰 보완했다. 초기 검사 실패 로그는 /tmp/nubi-tool-icons-readability.log 및 final/final2.log에 남겼다.
- 실제 빌드한 macOS Electron의 renderer/IPC/worker/원본 OpenCode 1.19.4와 합성 호환 모델을 연결해 소스 읽기 아이콘, 승인 대기, 명시적 반영과 CRLF 보존을 확인했다. 모델은 로컬 fixture이며 실제 모델 품질 측정이 아니다.
- 평가 로그 이동 후 최신 결과/4,000자 제한/원문 불변/로그 실패 무시를 포함한 관련 검사 8개를 통과했다.
- 확장 verify:identity는 단위 1,741개, 디자인, 후보 빌드와 두 사이트 회귀를 통과한 뒤 PDF 시험의 serviceworker 시작 대기에서 중단됐다. 전체 확장 검사 통과로 표시하지 않는다. 초기 후보 빌드 실패와 수정 후 시험 시작 실패는 각각 extensions/aipro-chat/verification/pre-release-2026-10-23T23-27-47-654Z 및 23-30-15-677Z에 보존했다.
- 명시한 Chrome for Testing 실행 파일로 공유 trace-journal 화면을 별도 확인했다. 실제 확장 IndexedDB 132개 기록의 페이지 조회, 320/360/1100px, 키보드 펼침, 새로고침, 소유권/삭제 검사가 통과했다. 별도 subagent-progress 화면의 같은 세 너비에서 대기/진행/전달, 실제 원문/이미지 읽기 상세, 긴 미확인 문구, 부분 실패/취소와 완료 후 복원 10개 검사도 통과했다. 이 결과는 전체 확장 검사와 실제 모델 성능을 대신하지 않는다.
- Desktop 디자인/identity 검사와 Electron 빌드를 통과했다. 기존 Windows Bash CJS import.meta 빌드 경고는 남아 있다.

검증 산출물은 Desktop verification의 realtime-actions-2026-10-23, activity-readability, activity-layout-2026-10-16, opencode-coding-shell-2026-10-23에 있다. 임시 프로젝트와 합성 모델 검사이며 Windows 실기기, 삼성브라우저/Office/실계정 연결과 설치판 검증은 이번 범위가 아니다.
