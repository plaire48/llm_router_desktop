# 2차 물결 Task 3: 읽지 않음과 대화 보관

2026-10-18. 현재 1.2.10 폴더에서 구현. 진행 중 설계 §8.8의 Claude 답변에 추가된 구체 조건을 확인하고 그 기준으로 맞췄다.

## 적용

- 보고 있지 않은 대화의 최종 답과 질문은 읽지 않음으로 저장한다. 대화를 열면 지운다. 창 비활성/다른 화면/프로젝트 이동 때 보고 있는 대화를 해제한다.
- 대화 메뉴에서 보관하고 보관함에서 복구한다. 검색과 본문, 명령, 출처와 작업 기록은 유지한다.
- 자동 보관은 기본 30일, 0은 끔이다. 최초 고정 목록 이전 전에는 실행하지 않는다. 고정 순서는 그대로이며 이후 호스트 목록(`setting:pinned-tasks`, 최대 50개)을 사용하며 `setPinnedTasks` 확인 후 localStorage 사본을 지운다. 기존 고정이 50개를 넘으면 최근 고정 50개를 유지하고 나머지 고정 해제를 안내한다. 대화는 삭제하지 않는다.
- 고정된 대화는 수동 보관도 차단하고, 보관된 대화를 고정하면 보관을 해제한다. 목록 행의 `pinned`는 호스트가 투영한다. 자동 보관은 동기화 이후 프로젝트를 열 때마다 실행한다.
- 진행 중, 질문과 복구 대기, 미완료 관련 작업은 자동 보관에서 제외한다. 복구한 대화는 사용 시각을 갱신해 다음 시작에 바로 다시 보관하지 않는다.
- 전체 대화 목록은 SQLite에서 목록용 필드만 투영한다. 기존 50개 본문 창과 오래된 선택 대화 조회를 유지하며, 오래된 목록 항목 선택 때만 본문을 가져온다.
