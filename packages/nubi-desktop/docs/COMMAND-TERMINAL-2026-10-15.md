# 명령 기록에서 대화형 터미널로

사용자는 PowerShell 명령 자체를 누비 안에서 직접 입력하고 실행하기를 원한다. 웹페이지 열기가 아니라 기존 native PTY 터미널을 같은 창에서 사용하는 흐름이다.

- 명령 실행 기록 옆의 `터미널` 버튼으로 해당 작업 위치에서 대화형 터미널을 연다. 과거 명령을 재전송하거나 자동 실행하지 않는다.
- 채팅의 `/terminal`은 모델 호출 없이 터미널을 연다. 로그인 전에도 기존 파일 → 새 탭 → 터미널 메뉴를 사용할 수 있다.
- 새 터미널의 기본 셸은 프로젝트 설정의 CMD, Git Bash, PowerShell 선택을 따른다. 설정 저장 시 상위 화면에도 즉시 반영한다. 호스트도 프로필이 생략된 요청에서 저장된 설정을 우선한다.
- 사용자가 종류 메뉴에서 셸을 직접 선택했으면 그 선택을 우선한다. 이미 열린 세션을 설정 변경 때문에 종료하거나 다른 셸로 바꾸지 않는다. 같은 결과의 버튼을 반복해 누르면 살아 있는 동일 셸/위치의 탭으로 돌아간다.
- 에이전트 명령은 기존 정확한 승인, 실행 기록과 복구 경로를 유지한다. 사람이 직접 입력하는 PTY를 모델의 자동 실행 또는 관리자 권한 우회 경로로 제공하지 않는다.

검증 실행기: `scripts/check-command-terminal.mjs`. 실제 Electron과 node-pty를 사용하며 모델은 로컬 fixture다. PowerShell/CMD/Git Bash의 실제 Windows 동작과 macOS Bash 실행 증거를 구분한다. 기존 UTF-8 초기화, mouse tracking 보호, 선택/복사와 Ctrl+C를 유지한다. 새로운 라이브러리나 셸 에뮬레이션은 추가하지 않았다.

결과: 관련 자동 검사 24개 통과, Windows 전용 실행 1개는 macOS에서 건너뛰었다. Electron 빌드 통과. 실제 macOS PTY에서 로그인 전 메뉴 진입, `/terminal`, 한글 입력, 변수 유지, 작업 경로, 명령 기록에서 열기와 중복 실행 없음, Ctrl+C 후 다음 명령 실행을 확인했다. 증거는 `verification/command-terminal-2026-10-15/result.json`과 `terminal.png`다. Windows 설치 파일은 생성하거나 배포하지 않았다.

## 무출력 대기와 설정 변경

사용자가 추천 기준을 선택해 일반 에이전트 명령에 5분 무출력 확인을 적용했다. 총 실행 시간이 아니라 마지막 stdout/stderr 수신 시간을 사용한다. 타이머 하나로 다음 확인 시점을 예약하며 화면 폴링이나 추가 패키지를 도입하지 않는다.

- 5분 동안 새 출력이 없으면 기존 채팅 질문 폼과 Windows 시스템 알림 경로에 선택지를 전달한다. 프로세스를 강제로 종료하지 않는다.
- `계속 기다리기`는 같은 프로세스를 유지하고 확인 간격만 다시 시작한다. 출력 시각을 조작하거나 AI 연결을 요구하지 않는다.
- `중지하고 원인 확인`은 실제 종료 영수증을 기다린 뒤 보존된 출력으로 기존 복구 하네스를 호출한다. 자동 재실행 권한을 주지 않는다. 일반 중지나 작업 취소는 자동 분석/재개하지 않는다.
- 새 출력이나 종료가 도착하면 질문을 해제한다. 늦은 답변은 실행하지 않는다. 다른 질문/진행 중 모델 호출은 덮어쓰지 않고 재시작 후 실행 여부는 미확정으로 남긴다.
- 개발 서버(`start`)와 직접 입력하는 PTY는 제외한다. 관리자 실행은 UAC 및 종료 영수증을 따르는 별도 경로이며 이 일반 명령 감시의 검증 범위가 아니다. 별도로 지정한 `timeoutMs`의 제한 종료는 유지한다.
- 설정한 셸을 준비와 승인 실행 시 모두 확인한다. 승인 대기 중 기본 터미널이 바뀌면 기존 명령은 실행하지 않고 새 셸 문법으로 다시 준비한다. 명령 수정 후 실행도 같은 규칙을 따른다. 관리자 PowerShell의 명시적 UAC 계약은 유지한다.

`tests/process-idle.test.mjs`는 짧은 주기로 실제 Bash 프로세스의 침묵/출력 재개/종료/중지/재진입을 검사한다. 모델 원인 분석은 fixture 응답이며 실제 Windows 알림 표시는 별도 실환경 확인 대상이다. 기존 결정 알림 어댑터와 질문 폼을 재사용한다.

후속 검증: 명령 승인/복구/서버/셸 설정/알림/UAC 관련 90개 통과, Windows 실제 PowerShell 검사 1개는 macOS에서 건너뜀. 서버 수정 명령에도 감시 제외를 유지하는 사례를 추가하고 대기/복구 21개를 다시 실행해 모두 통과했다. 최종 Electron 빌드 통과. localhost 서버 검사는 샌드박스 포트 제한 밖에서 재검사했다. Windows 설치 및 실제 OS 알림은 이번에 실행하지 않았다.
