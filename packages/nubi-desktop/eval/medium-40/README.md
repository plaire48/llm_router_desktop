# 중간 난이도 40문항 고정 평가

## 실행 계약

- Bash, Personal 메일, 스킬, Code 위키 각각 10문항. 독립된 자료 2개 이상을 결합하고 예외, 최신 변경, 단위, 미확인 상태를 판단한다.
- 실제 누비 ProjectService와 Agent, 연결된 Claude Code Opus 5.5 / medium을 사용한다. 정답과 평가기는 Agent 작업 폴더에 넣지 않는다.
- 합성 메일 5개와 무관 메일 1개를 실제 PersonalMail 검색/원문 읽기로 조회한다. 실계정 POP3 수신이나 자동 위키 생성 검사가 아니다.
- Bash는 catalog 실행 후 실제 반환된 ID로 자료 2개를 각각 읽는다. 도구는 원자료만 출력한다. 명령별 승인과 결과 후속 분석을 검사한다.
- 스킬은 관련 기본 스킬과 그 스킬이 요구하는 source-boundaries를 읽고 입력 사실을 변환한다. 실제 사내 스킬 목록 검사는 아니다.
- Code 위키는 3페이지의 정책을 종합하고 출처를 제시한다. 위임 또는 직접 읽기는 기록하되 경로 자체로 점수를 올리지 않는다.
- 자동 검사는 사실, 원문/실행 영수증, 출처, 원본 보존을 확인한다. 표현 차이와 사실 연결 오류는 결과 원문을 추가 검토하고 자동 점수를 소급 변경하지 않는다.
- 실행 전 사례/평가기/하네스와 제품 소스 해시를 고정한다. 1회 전수 평가이며 반복 신뢰성, Windows, 사내 서비스 전체 품질과 구분한다.
- 정확한 값과 결론이 첫 부분에 있는지, 불필요한 과정 설명이 앞서는지는 별도 가독성 검토에 기록한다.
