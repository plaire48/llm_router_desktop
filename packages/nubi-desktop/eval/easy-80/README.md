# 쉬운 Agent 평가 80개

Claude Opus 5.5, 요청 추론 medium. Bash / 메일 / 스킬 / Wiki 각각 20개, 최초 1회씩.

실제 모델과 제품 Agent를 사용하며 입력은 고정된 합성 업무 자료입니다. 정답 및 채점 코드는 에이전트 작업 폴더 밖에 둡니다. 사내 계정과 Windows 동작 검증은 별도입니다.

## 통과 기준

- Bash: 목록 조회 후 해당 ID의 계산을 서로 다른 실제 Bash 프로세스로 실행하고 결과를 맞춥니다.
- 메일: 실제 Personal Wiki 검색과 원문 2개 이상 읽기, 출처 2개 이상, 사실 일치를 검사합니다. POP3 수신과 위키 생성은 이 평가에 포함하지 않습니다.
- 스킬: 관련 스킬을 발견하고 읽은 기록, 지침의 필수 형식, 정답을 검사합니다. 실제 메시지를 보내거나 스크립트를 실행하지 않습니다.
- Wiki: 두 근거 문서의 조회 기록과 인용, 정답을 검사합니다.
- 모든 과제: 원본 파일 보존, 실제 응답 전달, 오류/미실행 구분. ready 표시만으로 통과하지 않습니다.

## 실행

```sh
node eval/model-session.mjs --provider claude --model claude-opus-5-5 --effort medium --socket /tmp/nubi-easy80/model.sock
node eval/easy-80/run.mjs --socket /tmp/nubi-easy80/model.sock --concurrency 4 --out verification/eval-live/easy80-opus55-medium-20261012
```

각 과제는 별도 저장소와 작업 상태에서 실행합니다. 동시에 최대 4개를 실행하므로 지연 시간에는 제공자 자원 경쟁이 포함됩니다. 중단 후 같은 과제/채점기/소스/모델/동시성일 때만 --resume으로 미실행 과제를 이어갈 수 있습니다. 매 완료마다 report.json을 원자적으로 저장하며 미실행 과제도 80개 분모에 남습니다. 최초 결과와 수정 후 재검사 결과는 별도 디렉터리에 보존합니다.
